# 增益类阶梯结果 v0.1（设计第 1 步：恒等锚自洽性，2026-09-29）

用户"批准"增益类控制例设计后按 §4 校准镜像路线执行的第 1 步。本步只回答一个问题：
**冻结契约 `gain_control_cases_v0.1.json` 构造的控制例数组，在恒等增益（即衰减雷达图本身）下，
其恒等锚是否自洽**——不涉任何增益算子的恢复行为（那是第 3 步效果表），不推导任何新阈值。

## 产物与纪律

- 脚本 `scripts/study_gain_ladder_v0_1.py`：以 SHA-256 断言载入冻结契约
  （`c027798904a4506bf…`），全部预注册值（五档 −3/−6/−10/−20/−40 dB、三结构、NC 双态）
  只来自契约；任何锚失败即中止。
- 输出 `artifacts/research_checks/2026-09-29_gain_ladder_r1/r2.json`：93 条记录
  （3 族 × 31 = 每族 1 对照 + 5 档 × 3 结构 × 2 NC 态），**r1/r2 两遍构建字节一致**
  （SHA-256 前缀 `6e9ffa1eb3a435c4`）。
- 无求解器、无测试族 {C5,C8}、无阈值推导；质量标签参考=原始未衰减事件
  （constructed_reference，与背景类阶梯相反方向）。
- 执行修复留痕：首跑锚断言误用 `battery()` 已舍入值（9 位小数，误差 ~5×10⁻¹⁰）
  对比 1e-12 相对容差，必挂；改为断言未舍入原始量后通过。这是断言实现 bug，
  契约与数组构造未动。

## 恒等锚自洽性（三族全部通过）

| 锚 | 断言 | 实测最大偏差 |
| --- | --- | --- |
| control (0 dB) | a=1, D_e=0 | 精确 |
| event_only → a ≡ k | 事件窗内 ⟨z,s⟩/‖s‖² 等于线性因子 | 0.0（机器精度） |
| nc_untouched → nc_ratio ≡ 1.0 | NC 窗能量比 vs 原始 | 0.0 |
| nc_attenuated → nc_ratio ≡ k² | NC 窗能量比 vs 原始 | <1e-12 相对（未舍入量） |

三族（S2X / S2TZX 坡地、C3mX 水平）读数完全一致——衰减构造不依赖几何，
这与背景类阶梯"几何决定安全边界"形成对照：增益类损伤是**乘性**的，结构上
对各族等价；差异将出现在恢复端（第 3 步）。

## 刻度读数（恒等增益下）

1. **event_band 坡道带不出现在测量窗内**：坡道带（±20 ns 升余弦）全部位于事件窗
   （费马到时 ±10 ns）之外，而本阶梯的 a / D_e / H / ρ 电池只在事件窗内取值，
   故 event_band 在恒等阶梯上读数与 event_only 逐位相同（a≡k、H=0、ρ=1，
   D_e=1−k）。**欠额刻度（坡道带使恢复量低于名义档）在恒等阶梯上不可见**，
   它只能由第 3 步效果表中真实恢复算子填充坡道带时的残余来测量。这是设计
   文档预期之内的——阶梯管"构造对不对"，效果表管"恢复好不好"。
2. **time_global 的 NC 一致性精确成立**：time_global 把 t ≥ min(t_ev)−10 ns 全部置 k，
   NC 窗（250–400 ns）自然落在其中，nc_ratio ≡ k² 逐位成立（−3 dB 档 0.501187、
   −40 dB 档 0.000100）——"时间全局衰减下 NC 同步衰减"的构造语义与锚定义无冲突。
3. **截幅刻度**：恒等增益下 peak_ratio 全表 = 1.0（衰减只降不升，无任何截幅），
   与设计文档一致——**截幅阈值在恒等阶梯上无数据，必须等第 3 步效果表**
   （目录外 +40/+60 dB 大动态指数曲线）提供截幅点火样本后，按完整校准流程
   由用户确认冻结。不得沿用任何现有数字。

## 第 1 步结论

冻结契约构造的控制例数组自洽、可复现、与几何无关，阶梯尺度有效。按用户批准的
节奏，**本步结果先行呈报，待用户确认后进第 3 步（增益效果表）**：候选=恒等 /
G2 / G4 + 目录外大动态 +40/+60 dB 指数曲线，预期验证 G2/G4 档距空白 30–50 dB、
截幅罚点火、nc_attenuated 下"事件定向放大"劣于"一致恢复"三个预注册发现。
第 4 步敏感性与第 5 步权重推导（dB 恒等式同法）各需用户确认；截幅阈值冻结需用户单独确认。
