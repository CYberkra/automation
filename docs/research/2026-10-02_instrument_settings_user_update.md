# 仪器设置：用户补充与功率单位更正

日期：2026-10-02。承接[PDF 与控制器源码研究](2026-10-02_instrument_source_followup.md)。本记录只归档用户提供的信息、已有资料的口径及未确认项，没有新增测量、参数拟合或仿真。

## 已知信息与证据状态

| 项目 | 当前口径 | 来源与证据状态 |
|---|---|---|
| 扫频范围 | 20–170 MHz | 用户本轮明确提供，与此前项目决定及 PDF 测试设置范围一致 |
| 频率步长 | 0.3 MHz | 用户本轮再次明确提供；不采用 PDF 中不自洽的“1 MHz”条目 |
| 频点数 | 均匀采样且包含两端时为 501 | 由 `(170−20)/0.3+1=501` 推导；尚未从营山原始仪器频率向量核验 |
| 36 档功率 | 按资料为 36 dBm，约 3.98 W | 用户更正“36 W”为口误，并明确要求功率按资料为准；PDF 第 20 页列 36 dBm |
| 谱窗 | 疑似 Hann | 用户原话“应该是 hann 窗”；尚无当时仪器状态文件或设置截图，不能记作已确认 |
| 时间范围 | 0–700 ns | PDF 第 20/22 页及营山标准 CSV 头部支持；营山原单道时间列及端点约定仍待核验 |
| IF 带宽 | 10 kHz | PDF 第 20 页报告值；未取得对应营山采集时的仪器状态读回 |
| 显示域线索 | S21 Real | PDF 第 22 页截图直接显示；对应营山历史导出链仍是待核对的来源假说 |

功率换算使用 `P[W]=10^((P[dBm]−30)/10)`，36 dBm 对应约 3.981 W。此值保留为资料中的标称发射条件，不解释为已经校准的天线辐射功率、EIRP 或 VNA 端口设定值。营山已有 20/30/36 dBm 三档文件，本次更正不把整批测线统一改为 36 dBm。

## 尚未确认的设置与结论边界

- 营山实际频率向量、原始复数 S21、原仪器单道导出及提取/合并脚本。
- 时域变换模式（带通冲激、低通冲激或低通阶跃）、Hann 窗的历史实际启用状态。
- 校准是否开启及使用的校准集、设备时延补偿值、电延迟/端口延伸、门控是否开启及其时间范围。
- 平均设置、采集时准确软件版本及标准 CSV 的上游处理状态。

用户补充使理论有限带宽变换的候选更具体：后续可用 20–170 MHz、0.3 MHz 网格，并将 Hann 明确标为假设，隔离变换旁瓣与其他拖尾来源。已有[五谱窗构造检查](2026-10-02_instrument_source_followup.md#4-为什么这会改变我们对振铃的处理)没有因此升级为历史设置证明或实测标定。当前仍不能由这些设置单独分离天线、线缆、收发耦合和地下回波，也不改变 v0.6 尚未通过真实仪器响应验收的结论。

## 本次归档与下一步

本次仅更新文档及接续入口，核对频点推导、功率换算和文档差异；没有重读原始测线、连接仪器、运行求解器或训练，没有修改冻结契约、奖励阈值或执行门。

下一步优先追索采集时的仪器状态/设置截图及对应原单道导出，核实变换模式、谱窗、校准时延和门控，再确定观测链重建方案。本记录不是启动新实验的执行批准。
