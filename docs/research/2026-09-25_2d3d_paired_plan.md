# 2D/3D 配对差分调研与下一步建议（2026-09-25）

> 性质：调研 + 设计草案。**不是执行契约**，未冻结任何 attempt，当前 gate 仍为 false。
> 触发：用户提出"另一台机器配置高、之前跑 3D；本机配置低，要不要试试 2D 和 3D 差多少"。

## 1. 仓库内证据现状

- **从未做过 2D 与 3D 的配对数值对比**。产物注册表中 M00 系列为纯 3D 校准链，YZ 系列为纯 2D 链，没有同场景配对运行。
- 现有 2D/3D 论断只有两类：(i) gprMax 官方文档层面的定性声明——2D Hertzian 源是无限线电流源、3D 是局部偶极子，几何扩散与源归一化不同，**未校准的绝对幅度不能直接比**（dimension_strategy 第 21 行，出处 `input_hash_cmds.html`、`migration_v3_v4.html`）；(ii) 静态单元计数/内存预算。
- 维度策略既定安排：2D 做批量初筛，3D 只做少量代表性场景验证。**"2D 比 3D 差多少"正是这条策略缺的那块定量证据**——值得做。
- 配对前必须先解决源归一化：2D 线源 SpatialScale（yz2d 已实测 0.025m 的处理方式）与 3D 偶极 Δl/源矩不可直接对齐；airborne_3d_budget 第 58 行已提出此约束。

## 2. 外部文献证据（本轮新增，阅读范围标注）

| 来源 | 阅读范围 | 与本项目相关的要点 |
|---|---|---|
| Vu Tuan Dung（KIT 学位论文，2D GPR FWI） | 摘要与章节节选（检索返回文本） | 2D 模拟固有线源（柱面扩散），实测/3D 为点源（球面扩散）；用 3D→2D 变换（Forbriger et al. 2014 远场单波数因子；源自地震 Bleistein 1986/Ursin 1990）把点源数据换成等效线源后再做 2D 反演；反射波变换后波形相似度好，但**变换后结构内部数值不可靠**，电导率比重构介电常数更难。 |
| SEG Wiki: Geometric spreading correction | 条目页 | 球面扩散 ∝1/r 与柱面扩散 ∝1/√r 的标准修正背景。 |
| Holliger & Bergmann（偶极天线辐射 FDTD） | 摘要 | GPR 近场可达约十个波长，远场近似在 GPR 大部分数据中不成立——提醒我们 15m 航高、20m 深度恰在近场—远场过渡区，2D/3D 差异不能只用扩散公式外推。 |

含义：文献支持"2D 与 3D 的差异主要是几何扩散 + 源特性 + 近场效应，且存在修正方法但修正后幅度仍不完全可靠"。这正好是我们配对实验要**定量测量**的东西（在本项目频段 20–170MHz、15m 航高、0–20m 深度的具体条件下）。

## 3. 本机硬件核验（2026-09-25 实测）

| 项 | 本机 | 旧高配机（历史记录） |
|---|---|---|
| GPU | RTX 3060 Laptop（约 6 GiB 显存；WMI AdapterRAM 溢出截断，按型号规格） | RTX 4090 Laptop 16 GiB |
| 内存 | 15.8 GiB 总量 | 约 63 GiB |
| Python | 3.10.9（E:\python） | 3.12.14 + 自建 PyCUDA/CUDA 13.3 |
| gprMax V4 环境 | **不存在**（无本地 env，E 盘无 V4 源码） | `artifacts/local_checks/gprmax_v4_gpu_env`（属旧机） |

- 本机**当前无法运行任何 gprMax 求解**：缺 V4 源码、缺 Python 3.11–3.13、缺 PyCUDA/CUDA 工具链。
- 既有预算模板（空闲 RAM ≥24 GiB、Job 提交 ≤20 GiB）在本机**物理上不可能满足**，新契约必须为本机重写资源上限。
- 规模估算（按 M00 实测约 88–92 B/单元、主机 commit ≈ 核心数组 + 开销推算）：
  - 3D 侧显存上限按 ≤4.5 GiB 核心数组 → **≤约 5,000 万单元**。例：12.8×12.8×19.2 m @4 cm = 320×320×480 ≈ 4,900 万单元，或 15×15×20 m @5 cm ≈ 2,700 万单元更稳。主机 commit 估 6–9 GiB，16 GiB 内存下可行但偏紧。
  - 耗时粗估：M00（1.106 亿单元、4156 步）在 4090 Laptop 上 262.7 s；3060 Laptop 带宽约为其 0.6 倍 → 3,000 万单元同级步数约 130–180 s。**完全可负担**。
  - 2D 侧参考既有批次：YZ 平层 2.5cm 约 15 s/次，几乎免费。
- 结论：**本机跑一个"小而诚实"的 2D/3D 配对是可行的**，瓶颈不是算力而是环境重建（需 V4 源码 + Python 3.11+ + CUDA/PyCUDA 构建）。

## 4. 配对实验设计草案（未冻结）

- **场景**：与既有 YZ 平层链同族——空气 + 粉质粘土覆盖层 + 砂岩半空间；可加一个局部湿润异常作为可选第二档。15m 航高、1.3m 横向基线按已确认几何。
- **3D 侧**：上述 ≤5,000 万单元小域，4–5cm 格距（170MHz 在 εr≈9 介质中约 12 单元/波长，仅达官方起步准则，精度限制必须写进结论）；普通边界，时窗按 20m 双程 + 余量（约 600–800ns 待核算）。
- **2D 侧**：同 YZ 剖面、同格距的 TMx 模型（成本可忽略，可同时跑更细格作 2D 内部收敛参照）。
- **比较量**（规避绝对幅度陷阱）：
  1. 目标—背景**配对差分**的波形形状/相位/到时差（各自维度内部差分，消去源矩）；
  2. 深度衰减曲线的**归一化趋势**（比值与斜率，不比绝对 dB）；
  3. 可选：按 Forbriger/Bleistein 形式的 3D→2D 变换后再比幅度，检验变换在本频段/几何下的残差。
- **明确不声称**：2D 绝对幅度可代表实测；5cm 3D 网格已收敛；配对结果外推到复杂地形/倾斜界面。
- 与既有深部研究的关系：这是**维度效应**的标定，不替代 dy12.5/dz3.125mm 垂向细化收敛问题；两者结论分开记录。

## 5. 三条执行路径

| 路径 | 内容 | 代价/风险 |
|---|---|---|
| A（推荐） | 本机重建 V4/CUDA 环境 → 冻结小契约 → 本机跑完整配对（2D+3D 都小） | 需获取 V4 源码（用户拷贝或从 GitHub 官方仓库下载 4.0.0）并构建 PyCUDA；一次性环境成本 |
| B | 3D 侧留给高配机下次跑，本机只做设计、2D 侧和配对分析脚本 | 跨机等待；分析链可以先建好并用旧 M00/YZ 数据做干跑 |
| C | 只冻结设计不执行，继续算子误差预算（纯数组，无环境依赖） | 维度证据继续空缺 |

无论哪条路径，**算子误差预算（纯 NumPy）都可立即在本机并行推进**，不依赖环境重建。

## 6. 建议的下一步

1. 本机立即做：算子误差预算设计（无环境依赖）。
2. 用户决定路径 A/B/C。若选 A：用户提供 V4 源码或授权从官方 GitHub 下载 4.0.0，并允许安装 Python 3.12 + CUDA/PyCUDA 构建链（数 GB 磁盘）。
3. 环境就绪后按第 4 节冻结正式契约（含本机专用资源上限），再执行配对。
