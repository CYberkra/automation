## 1. 权重推导（不从候选表现倒推）

草案 §2.1 的提案标量形有三个待定权重 w_c / w_d / w_b。本步用 **dB 单位恒等式**把三项全部化到同一量纲，系数由构造等于 1：

```
R_bg = Δcontrast_dB                      正向：事件/负控底噪对比提升（实测）
       − 20·log10(1/(1−D_e))             保真罚：D_e 按 20log10 幅度恒等式换算为 dB 等效
       − max(10·log10(Nb_ratio), 0)      噪声放大罚：负控窗能量比正部（功率比取 dB）
```

- **w_c = 1**：对比提升本身就是 dB 实测值。
- **w_d = 1（构造性）**：−1 dB 阶梯级（A=D_e=0.1088）经 −20·log10(1−D_e) 恰好映射为 1.0 dB——换算系数由幅度恒等式决定，不是拟合。
- **w_b = 1**：等 dB = 等物理尺度；奖励 = **净事件-干扰改善**。这同时按构造编码了草案 §2.2"亮度≠SNR"：纯增益 Δ对比 ≈0 且须付 Nb 罚，得分必然低于恒等。
