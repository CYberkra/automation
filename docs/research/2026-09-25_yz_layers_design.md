# 二维有损平层对照（执行前设计）

两次CUDA double，复用YZ空气参考：YZ_ROCK为z≤24m砂岩εr9、σ0.001 S/m；YZ_COVER在其上部z21–24m覆盖3m粉质粘土假设层，εr16、σ0.01 S/m。非磁、频率不变参数，仅为研究假设，不是现场测量。尚无异常体、坡地或20m深反射目标。

保持YZ/TMx、24×44m域、2.5cm格、15m高度、Y基线1.3m、800ns窗、官方impulse与501点SFCW；40格固定HORIPML与已完成空气/PEC一致。材料接触侧/底PML，固定空气PML的效果必须从独立参考误差评估，不假定无反射。输入使用官方默认界面材料处理，可能有离散界面偏差。

每组CUDA0 double、8线程、15分钟/6GiB Job/1GiB输出限额、最少8GiB RAM和2GiB VRAM；一组一次，无CPU回退与自动重试。复用已有空气，不再求解空气。

独立参考 `scripts/reference_yz_layers.py` 解TE相对平面的标量Ex谱积分（gprMax模式名是对不变X轴的TMx，不要混淆命名）。exp(+iωt)，q_j=sqrt(k_j²−ky²)选Im q≤0；r_ij=(q_i−q_j)/(q_i+q_j)，有效R=(r01+r12 exp(−2iq1d))/(1+r01*r12 exp(−2iq1d))。

反射E/I=−ωμ0/(2π)∫₀∞ R cos(ky b)exp(−iq0 H)/q0 dky，b=1.3m，H=30m。传播段ky=k0 sinθ；倏逝段ky=k0 cosh u，dky/q0=i du。分支点经变量替换消除，Gauss积分256阶，指数截止40。PEC镜像、匹配空气、零层厚、同材料退化、128/512阶和截止50均检查，最大残差1.79×10⁻¹⁰（要求1e−8），是积分自洽检查不是全面物理认证。

后处理取模型−空气以隔离反射，报告全频带幅度/相位/复数误差与200/400ns渐消敏感性；不拟合时间或缩放。400ns尾窗只作本平层对照敏感性，不得移植到含20m晚到目标的模型。无预设FDTD通过阈值，若偏差较大先查边界/界面和离散色散，不直接扩大批量研究。
