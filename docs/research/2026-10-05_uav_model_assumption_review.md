# 无新增实测资料时的模型审查：先证伪我们的建模判断

日期：2026-10-05。用户明确当前没有更多实际资料，并质疑为何实测可见而仿真效果很差。承接 `f072844` 方案，本轮核查已有文档、项目配置与官方验证范围，并运行独立连续介质解析检查；**无新FDTD、训练或实测拟合**。

## 核心修正

用户的实测晚期条带是需要解释的观测事实，不能用一份未对齐的简化模型否定它。也不能反向认定所有UAV场景都应得到相同条带；问题应转为：**我们的前向模型、接收观测量与比较推理是否可信？** 不再把取得更多实测资料作为自检前提。

已确认的错误包括：末端Hilbert峰污染；把不同统计量比较成固定dB差距；将长测线全段相关提升当作原有道形状改善。另有以下过强推论需撤回：

1. **“官方验证通过→本模型不是模型问题”不成立。** gprMax悬空偶极官方比较为2GHz、无损εr9半空间、h/λ0=0.1/0.2/0.35的归一化方向功率图；这不认证我们的20–170MHz、色散层、弱回波、具体域/网格/差分和CSV链。可支持求解器在声明场景正确实现悬空传播，不能签认本模型。
2. **“文献使用成像→原始剖面必须看不出界面”不成立。** 成像用于空间定位/聚焦，不证明机载原始B-scan必然没有可见晚期条带。文献与本模型是否定量同工况也尚未核验，不能据之证明48.8dB是普遍机载代价。旧文献报告中的“必须成像”“定量吻合、不是模型错误”仅为当时过度推断。
3. **“界面/理想源直耦很小→设备无法探测”不成立。** 理想总场比不是接收端标定动态范围或实测SNR。无噪声线性模型中，小的响应并不等于没有响应；颜色显示、相干分量与数值可辨性需分别检查。二维线源还不能提供真实天线的绝对电平比。
4. **“左右布局肯定改善”也不能预设。** 配置核查已确定项目横向1.3m布局与当前二维沿线布局不同；它是优先受控因素，不是已确定主因。低频近场中不能只用远场方向图推断直耦。

## 已完成的独立解析检查

采用MIT 6.013讲义10.2节完整Hertzian偶极电场，在均匀空气中、固定源电流元、相同极化接收分量，计算轴向/侧向接收比。包含1/r、1/r²、1/r³项，不能只保留远场辐射项。设u=kr，幅比为：

`2*sqrt(1+u²)/sqrt((1-u²)²+u²)`。

| 频率 | 1.3m/空气波长 | 轴向/侧向场幅比 |
|---|---:|---:|
| 20MHz | 0.0867 | +8.17dB |
| 50MHz | 0.2168 | +6.45dB |
| 95MHz | 0.4120 | −1.05dB |
| 170MHz | 0.7372 | −6.90dB |

因此横向基线在固定极化下，可能在低频增大直耦、在高频减小直耦；“轴向远场零辐射”不等于1.3m处零耦合。此结果**没有地面、有限天线或端口，也不是本机FDTD验证**，只约束后续布局解释。

另一个必须核验的源假设：固定长度的理想三维电流元在同电流下辐射功率∝f²。20→170MHz的相对功率变化为18.59dB。**“实际源归一化后单位电流频响”不自动等于“等发射功率的设备响应”**。这个18.59dB不是已发现的实测差距或补偿量，也不能套到二维线源；恒端口功率、恒辐射功率、恒电流与恒电压分开声明。不可直接给历史谱乘1/f就称硬件修复。

脚本：`scripts/check_uav_dipole_assumptions.py`；结果：`artifacts/research_checks/2026-10-05_uav_dipole_assumptions_r1/summary.json`。静态2:1和大kr的2/kr极限检查通过，源码哈希写入结果。复现使用不存在的新输出目录：

## 修改后的下一步：不依赖新增实测资料

在原12道布局实验之前增加**本机前向模型自检**，先生成静态输入/资源契约，再执行有界标杆；本轮未启动：

1. **自由空间精确解。** 三维理想偶极、1.3m收发距离，两种基线×两种水平极化；按实际Yee位置与电流元长度对齐解析场，逐频检查复幅度和相位、实际源归一化/半步时间、互易性及坐标旋转对称性。不用模值一致代替复数一致。解析解不依赖设备数据。
2. **空气—平地—平层传播。** 先用明确的无损材料检验到时、反射极性/幅度和分层传播，再单独引入电导和Debye项。点源参考应为适用的分层格林函数/谱积分，不能用正入射平面波Fresnel幅比直接签认有限高度点源。弱差分的最早物理路径、源区影响与跨场景数值底另行核查。
3. **接收与频谱口径。** 同时保存实际源电流/电压、相应响应单位和频率权重；区分电场、接收电压、端口S参数与显示量。单位电流/等辐射功率仅为分别声明的机制分支，不凭图像选一个当真实硬件。复用已有谱可先做CPU敏感性，不篡改原始结果。
4. **通过后才做原12道布局对照与深度实验。** 偏差必须用独立误差预算判读；若标杆不一致，先修源/坐标/时相/边界/实现，保留失败证据，不继续扫描材料解释实测。

预期交付是“哪些假设已被否定、哪里与解析解不符、每个因素怎样改变响应”，不是强行找到唯一场地材料。硬件与真实电性未知会限制营山定量标定，**不会阻止检验模型自洽、修复实现错误或演示声明场景下合理的机载回波**。也不承诺任意无损/理想基准的表现就是现场效果。
