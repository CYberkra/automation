## 3. 事件窗推导规则（全部【自算】）

### 3.1 自算双程到时公式

与 [A0 三维校核契约提案](2026-09-26_a0_3d_validation_contract_proposal.md) §1.3"自算双程到时"**同法**（其原文：空气段 30 m/c = 100.1 ns + 覆盖层双程 6 m/(c/4) = 80.0 ns + 砂岩双程 14 m/(c/3) = 140.1 ns ≈ 320.2 ns）。

对族 C{h}（覆盖层厚 h m）与中心深度 d m（自地表起算，d > h）：

```
t_air   = 2 × 15 m / c              = 30/c                       （天线 z45 → 地表 z30，双程）
t_cover = 2 × h / (c/4)             = 8h/c                       （覆盖层 εr16 → v = c/4）
t_rock  = 2 × (d − h) / (c/3)       = 6(d−h)/c                   （砂岩 εr9 → v = c/3）

t_TGT(h, d) = (30 + 8h + 6(d−h)) / c = (30 + 2h + 6d) / c
```

覆盖层底界面（d = h，砂岩段为 0）：

```
t_COV(h) = (30 + 8h) / c
```

常数：1/c = **3.3356409519815204 ns/m**（c = 299 792 458 m/s）【自算】。

**垂直入射近似声明**：Tx/Rx 基线 1.3 m 引起的斜程增量 = 2·√(25² + 0.65²) − 50 = 0.0169 m → **0.056363 ns**【自算，按 D10m 锚点、对称于基线中点】，远小于 80 ns 半宽，故按垂向双程计算，不作斜程/折射修正。OFF 档的偏斜路径**不作自算**（见 §5.2）。

### 3.4 ±80 ns 半宽的论证

半宽不是由任何处理结果拟合出来的，按下列四条独立理由**沿用既有约定并论证其充分性**：

1. **沿用既有约定（主理由）**：dep3d 设计书对 D20m 采用的实波形诊断窗为 **440–600 ns**，即围绕自算双程到时 520 ns 取 **±80 ns**；[A0 三维校核契约提案](2026-09-26_a0_3d_validation_contract_proposal.md) §1.3 差异点第 4 项明确"建议按**同一 ±80 ns 规则**围绕 D10m 自算双程到时取 240–400 ns"。【沿用】本文把同一规则推广到全部族 × 深度档，不做逐例调整。
2. **覆盖目标自身垂向尺度**：目标顶/底反射相对中心的时间偏移 = ∓3t/c【自算】：T0.25 → **±2.5017 ns**、T0.5 → **±5.0035 ns**、T1 → **±10.0069 ns**。即便最厚档 T1，目标体自身跨度也只占半宽的 12.5%，±80 ns 足以容纳目标全厚度响应而不截断。
3. **容纳数值/维度引起的到时偏移（量级参照，不用于定中心）**：跨网格档包络峰到时差约 −17.24 / −15.67 / −17.11 / −19.12 ns（E5）；2D/3D 包络峰到时差 −71.02 / −53.72 ns（E7，D20m 类、不同族不同格距，仅作最不利量级）。这两类系统偏移的**最大量级（约 71 ns）小于 80 ns**，故 ±80 ns 能把事件中心保持在窗内。
4. **不追求事件隔离**：±80 ns 是"围绕事件中心的固定邻域"，**不是**"与其他事件不重叠的最小窗"。本文据实承认该半宽在多数相邻档位上**不产生隔离**（§4.7），并把它作为"事件不可隔离"的证据记录，而不是通过缩窗去制造隔离——缩窗会把第 3 条的系统偏移排除在窗外，属于沿数值行为反向调窗，本文不采用。

> **待 kimi 验收的备选（本文不采用，仅登记）**：是否需要**增设**一套更窄的辅助隔离窗（如 ±20 ns）用于"窗内污染诊断"，由验收与用户敲定后另立。即便增设，主窗仍为 ±80 ns，二者不得混用。

### 3.5 尺寸档与电性档**不改变**窗中心（声明）

- **尺寸档（W1/W2/W4 × T0.25/T0.5/T1）**：窗中心由**中心深度 d** 决定，尺寸只影响目标体的垂向跨度（§3.4 第 2 条），不影响中心到时；横向宽度不影响垂直双程路径（横向中心固定为基线中点 y16，斜程增量已并入 §3.1 的 0.056 ns 项）。故同族同深度下 W1/W2/W4 与 T0.25/T0.5/T1 **共用同一窗**。
- **电性档（E12/E20/E28、S0.005/0.02/0.05）**：自算双程到时按**围岩（砂岩 c/3）速度**定位到目标中心，目标体内部波速不参与路径计算——这是 A0 提案 §1.3 同一方法的固有约定。故同族同深度下全部电性档**共用同一窗**。
- **声明**：这是**定位约定**，不是物理到时标定。它不声称目标体内部传播速度已知，也不声称电性档响应的到时完全相同；它只保证"窗不因档位假设而移动"，从而满足 v0.2 §2 的冻结要求。

## 4. 事件表本体

### 4.1 `event_id` 命名规则

```
覆盖层底界面： EV-C{h}m-COV
目标事件：     EV-<母模型 ID 去掉 "B2D-" 前缀>
               例：B2D-C3m-D10m-W4m-T0.5m-E20-S0.02 → EV-C3m-D10m-W4m-T0.5m-E20-S0.02
零对比负控：   EV-C{h}m-D10m-NC-W1   （几何匹配目标窗）
               EV-C{h}m-D10m-NC-W2   （全时窗）
远偏移负控：   EV-C3m-D10m-OFF-W1    （on-path 目标窗）
BG 负控：      EV-C{h}m-BG-NEG-D{d}m （族 BG 上按深度档的目标窗）
```

规则：【提案】① 前缀 `EV-` + 族键 `C{h}m` 保证按族分层（E1/E5：不跨族平均、不跨族差分）；② 目标事件 id 与母模型 ID 一一对应，可直接回溯 `cases.json` / `groups.json`；③ 电性写作 `E{εr整数}-S{σ}`，尺寸写作 `W{w}m-T{t}m`，深度写作 `D{d}m`，与规格书 §1.0 母模型命名逐字段一致；④ 负控用 `-W1/-W2` 区分窗型，不用数字序号，避免与档位混淆。

| 2 | `event_id` | 原样 |

| 6 | `group_id` | 原样 |
| 7 | `axis` | `sample` |

**规范化规则**：UTF-8 编码；换行一律 LF；除 `event_id`/`mother_model_id`/`group_id` 保留原样外，其余字段值小写；每个字段值去首尾空白；ns 数值统一 `%.6f`（半角、无千分位、无科学计数法）；**串末不加分隔符**。

**本文不计算、不填入任何哈希值**（冻结阶段按上述规则生成并登记 SHA-256）。【待敲定】

## 5. 负控窗设计

### 5.1 NC（零对比）：不依赖处理结果，用"几何匹配"定窗

**问题**：NC 例的差分恒零（E1），其包络峰到时、谱峰在分析脚本中记为 **null**（差分恒零时无定义），因此**没有任何处理结果可供定窗**——这不是缺陷，恰恰是必须自算的理由。

**方案**【提案】：

- **W1（几何匹配窗）**：NC 例的几何与其族内 `D10m-W4m-T0.5m` 目标例**逐字段相同**（规格书 §1.4：几何存在、仅 εr/σ 与围岩相同）。故 NC 的验证窗**直接取该族 D10m 目标事件的窗**，即 `EV-C{h}m-D10m-NC-W1` 与 `EV-C{h}m-D10m-W4m-T0.5m-E20-S0.02` 的窗**逐位相同**。语义："若几何/网格本身产生伪响应，它必然落在这个窗里"——这正是 E1 要证伪的命题，且完全不依赖任何输出。
- **W2（全时窗）**：掩码全 1，覆盖整条预声明时窗（1200 ns）。语义更强：验证"逐样本恒零"，与 E1 照录的判据（"在 200/400 ns 两个尾窗与时域逐样本恒为零"）一致。
- 二者**并存、不互相替代**：W1 是事件尺度的负控（对应 v0.2 §4 的 `N_b`），W2 是全时域确定性验证。
- **零参考处理**：NC 差分为零时，`N_b = mean(Z[M_b]²) = 0`，**不加任意 epsilon 伪造能量比**，不做零参考 NRMSE；dB 记 null（与 E1 照录一致）。不得把"比值 0"读作"抑制成功 100%"。

### 5.2 OFF（远偏移）：窗 = on-path 目标窗；明确不是零差分负控

**方案**【提案】：`EV-C3m-D10m-OFF-W1` 取 **C3 族 D10m on-path 目标窗 [240.221531, 400.221531] ns**。语义：OFF 要回答的问题是"当目标不在收发基线正下方时，算子是否在**目标应在的时间窗**内制造伪响应"，因此窗必须对准 **on-path 位置的目标到时**，而不是 OFF 目标自身的位置。

**明确不做的三件事**：

1. **不自算 OFF 目标的斜程到时**。OFF 目标中心在 y21 m（盒 y19–23），Tx/Rx 在 y15.35/16.65，路径明显偏斜且跨三种介质（需 Snell 折射追踪）；本文不做该计算，也不声明 OFF 响应的到时。
2. **不用实测到时定窗**。粗档结果文档已记录 OFF 例包络峰到时 319.3617971959073 ns、带内能量比 3.0406928886248514e-08（−75.17027441582566 dB）。此处引用**只为说明 OFF 差分非零**；本文**不**以此值定义、校验或移动 OFF 窗。
3. **不把 OFF 当零差分负控**。OFF 保留了电性对比（εr20/σ0.02），只是横向移开，其差分**非零**。它只能作"无目标假阳性对照"（E8），不能当作 NC 的替代品，也不得与 NC 结果合并。

**单列要求**：OFF 带 `side_pml_margin_below_13m` 例外（侧向余量 8.0 m < 13 m），结果不并入目标行、不参与任何跨例平均【依据】E8、规格书 §1.4。

### 5.3 BG 目标窗负控（增补提案，待验收）

族 BG 内**不存在任何目标**，因此在"该族某深度档的目标窗"内，目标角色**确实不存在**——这是 v0.2 §2"负控：明确指定窗口/事件角色中没有应保留响应"的直接实例，且同样完全由几何定义、不依赖输出。用途：为 `N_b`（v0.2 §4）提供窗口，并与增益风险诊断共用（增益前后负控窗绝对能量与能量比，分母非零时才报比值）。

**注意**：BG 负控窗可能与覆盖层底界面窗重叠（见 §4.7），窗内可能含界面响应；故 `N_b` 按 v0.2 §4 只报"绝对残差 + 输入基准"，**不称目标虚警率**，也不当作纯干扰窗使用（§2.2）。

### 5.4 不定义纯干扰窗 ⇒ `R_c` 一律不计算

见 §2.2：本批无独立依据的纯干扰窗，故 v0.2 §4 的干扰残余 `R_c` 在本次评价中**全部不计算、不填 0、不以任何窗代替**。
