## 1. 构造式（设计 §3 批准形态，系数全部由 dB 单位恒等式定为 1，无候选拟合）

```
R_gain = min(Δrec, due) − (due − Δrec)⁺ − 10·log10(1/(1−clip_ratio)) − max(10·log10 nc_ratio, 0)
```

| 项 | 恒等式论证 | 防什么 |
|---|---|---|
| 收益 min(Δrec, due) | 恢复 dB 封顶于已知施加损失；1 dB 真恢复 = 1 dB 收益 | 过补偿换分（"亮度≠恢复"的数值化） |
| 欠额 (due−Δrec)⁺ | 欠 1 dB 恰扣 1 dB，欠 3 dB 与欠 40 dB 同尺（设计 §3 原文） | 深档蒙混 |
| 截幅 10log10(1/(1−clip_ratio)) | 被毁能量份额的 dB 当量；系数 1；**门仍用 clip_frac（冻结 τ_clip）**，此项只管门内罚款 | 门内软截幅 |
| NC max(10log10 nc_ratio, 0) | 与 R_bg 的 N_b 项构造完全相同 | 选择性放大 |

可行门（v0.2 冻结）不过 → 整例 infeasible，无标量（与 R_bg 同纪律）。

## 2. 结构恒等检查（脚本断言，全部通过）

- **契约导出 oracle 在每格恰得 +due**：−3/−20/−40 dB 档读数 3.0/20.0/40.0 dB
  （min 顶到 due、欠额 0、nc=1.0 项 0、clip 0）——标量天花板恒等成立；
- **恒等诊断（不可行，仅记录）**：identity 的 R_gain 恒等于 −due（drec=0、欠额 due、
  其余项 0）——"什么都不做在深档得深负分"方向正确；
- 冻结门下可行行 72/864 = 仅 oracle（与第 4 步基线一致）。
