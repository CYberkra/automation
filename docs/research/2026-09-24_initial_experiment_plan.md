# 首版自动配置的初步实验计划

日期：2026-09-24｜版本：0.1，可审查草案｜未启动正演或训练

## 1. 目标、证据与范围

科学问题：在公开文献支持的非显性滑坡相关仿真场景中，能否依据输入 B-scan 自动选择**背景抑制与增益**配置，在保护地下响应、控制干扰放大和计算开销的条件下，优于独立选定的固定流程？

本计划先检验“自适应配置是否有价值”，再决定模型。不是滑坡识别，不要求生成地质解释，不评价实际营山探测深度。现有测线/钻孔继续留用，当前不参与建模、评分或阈值设计。

依据分四类：前轮 GPR 算子与评价论文；滑坡结构文献；本轮材料/薄层与可辨识性核查；项目自己的可证伪设计。下文的样本数量、候选参数、阶段门槛形式均为**项目建议**，不是文献公认标准或用户已批准的计算预算。[结构与链路复核](2026-09-24_structure_and_chain_rigor.md)给出来源及边界。

## 2. 可证伪假设

| 编号 | 待检验命题 | 什么结果会反驳或限制它 |
|---|---|---|
| H1 | 同一固定背景配置难以同时适合平缓层、局部体及纯干扰场景 | 固定/规则配置已达到有限候选集合的相近效果，或所谓自适应收益只是测试调参 |
| H2 | 配置选择能改善干扰抑制，同时约束结构损伤 | 平均改善依赖删除平缓/弱反射，或最差相关类别持续退化 |
| H3 | 有界增益可实现声明的补偿目标，并限制放大代价 | 只使图更亮；参考不支持该补偿；深部噪声放大而波形保真无益 |
| H4 | 某些非等价顺序有可利用差异 | 只有代数等价流程、浮点误差或重复增益产生“收益”；固定顺序已足够 |
| H5 | 轻量选择器可以接近有限集合内的可行最优选择 | 独立场景下不优于强传统基线，或选择成本超过节省的计算/人工成本 |

H4 不通过时取消顺序学习；H1/H5 不通过时保留固定/规则方法。这些也是研究结果，不为继续 ML 人为弱化参照。

## 3. 统一数据契约

正式处理输入为 `time_real`、带符号 `[sample, trace]` 数值数组。每例保存：

- `case_id, mother_id, scene_family, split, seed`，场景母模型及所有派生关系。
- 电性材料与来源等级、有效频段、几何、实际网格、边界、源接收器与分量、时窗、求解器版本/构建、原始 dtype。
- 时间/样本轴、横向轴、单位、源波形与观测量、已有背景/增益状态；当前缺失项明确标未知。
- `reference_kind`、保护事件/窗、负控窗、参考的形成规则与不确定性；`geometry_present` 与 `reference_evaluable` 分开。
- 每个算子参数/版本、处理前后数组和哈希、去除分量、增益曲线、异常/回退理由及耗时。

先按母模型分组，再裁窗/加干扰；背景模板、目标开关、网格变体、噪声种子和增益变体全部随母模型同组。已知模板在分组间共享时，记录并另做未见模板验证，不能把模板复用误认成完全独立采集。

## 4. 阶段 P0：代数和评价反例

**本轮完成 10 项最小检查**，入口 [check_processing_algebra.py](../../scripts/check_processing_algebra.py)，结果 [JSON](../../artifacts/research_checks/2026-09-24_processing_algebra.json)。这些检查只验证公式与数值行为，尚未形成正式算子库。

下一步可扩充的控制设计：`X=a(t)S+C+N`，其中 S 包含平缓、倾斜、弯曲、断续与局部响应，C/N 的构造及尺度已知，a 为已知正值衰减。分别记录 C/N 在衰减前或后加入，避免把两个不同观测模型混为一谈。合成脉冲是数组测试信号，不宣称为本系统 SFCW 波形。

评价反例要求：全零不能成为成功背景算法；反号或移位不能因包络相似获得保真满分；常数增益不能获得真实 SNR 提升；真实断续不能被强行补成连续；无信号参考的 NRMSE 标不可定义。完成后才把相应指标用于配置标签。

## 5. 阶段 P1：少量正演的数值有效性检查

### 5.1 建议案例与运行数

先准备五个理想场景，暂不随机扩张：

| 模型 | 结构 | 核查问题 |
|---|---|---|
| M00 | 均匀空气中的源与接收器 | 源波形、输出分量、轴与基本到时 |
| M01 | 平坦均匀半空间 | 空气直达与地表反射关系，浅层不整体清零 |
| M02 | 平坦双层介质 | 深层平缓反射，保护与均值误删 |
| M03 | 平坦地表、光滑起伏地下界面 | 地下到时变化与网格阶梯效应 |
| M04 | 层状结构加局部二维截面体 | 地层与局部响应共存；二维结果只代表横向不变体 |

预算草案：5 个模型 × 3 个收发位置 × 3 种数值设置（基准、网格细化、扩大边界缓冲）= **45 次 A-scan 正演**。先从 M00/M01 的基准锚点开始，逐项通过再展开，45 不是自动批量启动指令。精度敏感性和必要的额外细化另计，不藏入此数。

### 5.2 材料与采集假设

- 首次机制检查可设理想、各向同性、非磁、常数 εr/σ。候选 εr=4/9/16、σ=0/0.001/0.01 S/m 仅为有序电性对比的**待审查假设点**；先逐因素改变，不做全笛卡尔积，不贴“实测某土层”标签。
- Peplinski 模型不直接用于当前标称低频。50 MHz 文献作为参数研究线索；单频实部、表观介电常数和全带复介电谱不能互换。[复核 R03–R04]
- 首批源/频带契约尚待定稿。允许准备明确命名的宽带脉冲机制试验，但不能称为已匹配设备的 SFCW 数据；不用未经核实的“501”推导频点。
- 后续 SFCW 合成另行声明频点、源谱有效支持、复数相位、窗及导出链。源谱接近零处不能稳定反演系统响应；单次脉冲结果不自动证明逐频 CW 或实际设备等价。
- 固定航高和源接收器布局先作假设，不新增校正模块。理想接收电场与天线端口电压、功率/dBm 不混同。

### 5.3 数值有效性条件

记录全有效频带中的最短材料波长、结构最小尺度及其网格表示。每波长约 10 个单元只能作为起始建议，不能替代收敛。改变网格时保持物理几何和源接收位置尽量一致，保存离散后误差；薄层未被网格表示则停止该例。

同时检查源频谱、到时、主事件符号/幅度、边界反射、细化差异、原始精度和非有限值。边界对比保持目标到收发器相对位置，不能靠移动目标混淆归因。测试 ROI 必须在检查候选算法前固定。[gprMax 官方建模指南](https://docs.gprmax.com/en/latest/gprmodelling.html)

停止/修订条件：目标事件与边界伪影无法区分；细化改变事件存在性或候选排序；输出动态范围低于可接受数值精度；材料或源频带没有支持。容差先依据解析极限、参考强度和预期最小处理差异写入案例验收卡，冻结后再做处理比较，不事后迁就结果。

## 6. 阶段 P2：场景覆盖与参考定义试验

### 6.1 首批开发母模型

建议六族，各 3 个不同几何/电性母模型，共 **18 个开发母模型**。这批用于发现问题，不是正式训练/独立测试集，也不能据 3 例估计某类的稳定性能。

| 族 | 内容 | 必需对照 |
|---|---|---|
| F0 | 无深部目标/近零电性对比 | 不存在与存在但不可辨分开标注 |
| F1 | 平缓单界面 | 干净输入应可跳过；完整均值扣除误删 |
| F2 | 倾斜界面 | 方向及到时改变，不能用固定水平模板评分 |
| F3 | 起伏界面 | 真曲率与离散阶梯效应分开 |
| F4 | 强弱层共存 | 弱层损失不能被强层平均分掩盖 |
| F5 | 层加局部体/真实断续 | 局部响应与公共地层分别保护 |

示例计数：每个母模型一个基础场景及至多一个定义明确的特征关闭场景，按 41 道计，为最多 **36 个 B-scan / 1,476 次 A-scan**。F0 或其他重复参考可复用/省略，但必须按实际源接收布局判断。41 道只是预算占位，横向采样满足响应变化要求后才冻结；不是设备道距或推荐采样标准。新增航高、天线、材料/边界等物理条件会增加独立正演次数，不能只称免费增强。

### 6.2 参考不能自动统一

- 完整正演原始数据用于物理波形检查；不假定其有唯一的全图干净参考。
- `F1−F0` 保存为明确物理变化的响应，记录共同层可能抵消以及多次波变化。不得用只剩局部体的差分训练删除共同地层。
- 只有事件隔离与参考规则成立的窗口，才计算该事件的误差。重叠严重时改为对照诊断或标不可评价，不强行打分。
- 可以把已验证的物理响应作为受控混合成分，但其新混合结果必须标为**正演支持的数值混合**；尤其来自不同介质的场不能直接视为同一介质的完整 Maxwell 解。
- 导电/无损正演对用于检查增益能力边界，不能默认后者就是前者的可恢复 clean。

### 6.3 三维校核安排

二维只能筛选。待有限横向局部体、侧向散射或天线方向性成为结论依据时，至少准备相应三维代表例及无局部体对照，并重新估算资源。不得把二维无限延伸体的幅度、衰减或排序直接推广为三维 UAV。当前不报三维运行时，也未启动三维模型。

## 7. 最小候选集合与公平基线

### 7.1 可审查的起始集合

背景候选：identity；均值扣除比例 λ∈{0.25, 0.5, 1}；去除前 k 个奇异分量，k∈{1,2,3}。共 7 种。秩候选需要足够矩阵维度；奇异值近简并时记录子空间/排序不稳定风险，不解释为物理成分数。

增益候选：identity；固定共享曲线 `g(u)=2^u`；`g(u)=4^u`，u 是声明窗口内从 0 到 1 的归一化样本坐标。共 3 种。它们是有限有界 TGC 探索点，不是物理衰减系数，也不是推荐设备默认值；严格保持单位和完整增益曲线。尚无依据支持自动无限增益、反复增益或饱和截幅。

先以背景→增益形成 7×3=21 个配置。仅对 3 个非 identity SVD 与 2 个非 identity 增益增加反向顺序，共 **27 个标识配置**。identity 重复和均值/固定共享增益的交换流程不再另立标签。候选在特定输入上等效时再标等效集合，监督不能强迫选某个任意编号。

顺序比较统一保真尺度：正向保存真实中间量 `Z=B(X)` 与 `Y=GZ`；反向保存 `GX` 与 `Y=B(GX)`，另计算 `Z_audit=G⁻¹Y` 供去增益后的尺度对比。`Z_audit` 只能叫审计量，不能冒充实际的增益前中间结果。此规则限于已知、严格正值且无截幅的 G；否则需要另立可比协议。

这些数值是机制试验建议。范围、候选增删和增益上限在开发/验证阶段定稿，测试集冻结后不再修改。RPCA/WNNM、局部背景、自适应秩或受限 AGC 如有必要可作为同范围内的后续基线，不为追求网络收益刻意排除它们。

### 7.2 比较顺序

1. identity 和预先固定的简单流程。
2. 在开发/验证母模型上统一选择的最佳固定配置。
3. 可部署的统计规则/传统自适应方案；选择规则仅可访问输入和合法元数据。
4. 有参考的离线有限搜索；若读取测试真值，只能是最终诊断上界，不能部署或反馈训练。
5. 输入特征→每个配置的效果/风险预测或排序的轻量选择器。
6. 仅在以上证据显示必要时，比较小型 CNN 编码器；不直接生成“干净地层”。

在提出 ML 优势前，需补全第 3 项的具体实现与独立调参预算，不能只打败单一手选参数。未知合法参考时，不能为算出 oracle 而擅自引入全图 clean。

## 8. 指标、选择标签与模型准入

详细公式沿用[评价协议](2026-09-23_v1_evaluation_protocol.md)，本轮补充以下执行约束：

| 评价对象 | 主报告 | 关键限制 |
|---|---|---|
| 背景输出 Z | 合法参考的 NRMSE/幅度比例、零延迟相关/极性、预定事件到时偏差；纯干扰区残余能量 | 单独报告平缓/弱层损失；不存在纯干扰参考时不冒称真实 SNR |
| 增益输出 Y | 声明补偿参考误差、增益最大值/曲线、已知噪声放大、幅度关系 | 固定显示尺度；AGC/归一化不能冒称保幅；保留 Z |
| 负控 | 预定义空事件窗的能量/极值与其尺度、失败案例 | 此为评价诊断，不新增检测产品；“目标不存在”和“不可辨”分开 |
| 自动配置 | 相对固定/规则基线的逐母模型差异、可行配置命中、支配/退化情况、耗时和回退率 | 配置分类准确率不等于信号处理收益；有限 oracle 不等于全局最优 |

训练标签优先保存**每配置多维结果表**，不立即压成算法名称或一个总分。设配置 c 的保护损失为 `Lprotect(c)`、干扰残余为 `C(c)`、增益风险为 `Ag(c)`，先在开发/验证数据上确定可接受集合：

`Cfeasible = {c : Lprotect(c) ≤ τprotect 且 Ag(c) ≤ τgain，且所需参考有效}`。

阈值由评价反例、参考误差及明确任务容忍度决定；本轮未冻结。可行集合内先保留多目标非支配配置；确需单一输出时再冻结优先级/效用和并列规则。不存在可行解时允许标记失败或保守回退，不能偷偷放宽约束。identity 是合法选择，也不保证满足所有干扰指标。

模型输入不得含仿真母模型标签、真实分量、目标位置、评价 ROI 或最优配置分数。允许的特征可研究归一化奇异值谱、道间一致性及固定时间分段统计，但它们不能独立证明哪些成分是背景。输入依赖归一化只可用于模型特征，不能改变正式保真评价的幅度尺度。

架构准入：只有在合法参考上发现稳定的逐例配置差异，且输入特征具有可验证预测能力，才训练选择器。若轻量模型足够则停止增复杂度。两阶段有限配置无需先采用 RL；AdaptiveISP 仅提供模块/参数决策的跨领域思路，其检测奖励、可微算子和网络结构不能直接充当本任务依据。[跨领域证据](2026-09-23_cross_domain_ml_evidence.md)

## 9. 划分、统计与正式试验冻结

18 母模型仅用于开发。正式样本数根据试验观察到的母模型间差异、需要区分的最小改善和计算预算再定；当前不给缺少方差依据的“足够训练数”。

正式开发/验证/测试在生成派生数据前分组。至少另设未见界面参数、材料条件或背景模板的压力测试，不把同一母模型的不同噪声窗当独立泛化。测试母模型生成规则、指标、候选库、阈值和代码版本预先保存哈希。

报告以母模型为单位的配对差异及各场景分布。区间估计按母模型重采样；母模型太少时只报个例/描述结果，不用像素数量制造狭窄置信区间。若训练含随机性，记录全部种子并安排预定重复；不择优报告一次训练。测试后改动必须开启新版本和新验证，不继续称原测试独立。

## 10. 资源估算与停止规则

当前可计数但不可报实际耗时：P1 45 次锚点正演，P2 最多 1,476 次 A-scan；二者均是待执行方案。27 个处理配置只增加处理成本，不自动增加正演次数。原始标量分量输出量近似 `Nrun × Nt × bytes_per_sample`，另加模型、元数据与缓存；内存必须包括材料、PML、场量及色散辅助数组，不能只算六个电磁场。

运行成本用首个成功锚点校准：单元更新量近似 `Nrun × Ncells × Nsteps`。等比例细化网格时，二维和三维的成本增长还含时间步变小；不能按单元数线性外推所有硬件时间。正式预算用实测每步开销、初始化耗时和可用内存重新计算。

停止条件包括：物理/数值检查失败；参考标签不合法；收益仅来自更大增益或不同色标；关键结构持续受损；固定/传统方法已足够；模拟范围不足以支撑宣称。当前费用、远程计算与大批量执行均未获本轮研究自动授权。
