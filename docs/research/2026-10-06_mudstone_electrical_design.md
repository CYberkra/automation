# 泥岩电性研究初值与九号线采集方向

2026-10-06。用户明确选择剖面横坐标25–220m，从220向25采集，并要求调研、敲定泥岩电性。本单元只固定材料研究初值和采集区段；没有FDTD求解、训练、实测波形拟合或旧H5材料覆盖。

**决定：泥岩采用95MHz介电实部12、20–170MHz实部端点总差3、单极Debye时间8ns、直流电导率0.003S/m的研究初值。电导率量级和弛豫时间参考公开岩样研究，中心12和总差3是我们明确选择的假设，未拟合为营山泥岩真值。** 粉质黏土/砂岩保留既定配方，来源与低损耗假设边界见[原材料设计](2026-10-06_cover_rock_material_design.md)。

## 文献依据与不能迁移的部分

来源、阅读范围和下载哈希见[台账](2026-10-06_mudstone_electrical_sources.json)。本轮未取得本场地泥岩复介电谱；下述材料状态均是外地岩样。

1. [Römhild等2019，Table2及SIP方法](https://onlinelibrary.wiley.com/doi/full/10.1002/nsg.12073)：只取LA/OL完整普通泥岩样，不混入富碳黑色页岩或粉碎样。七个岩塞的直流电导率为0.00049–0.00883S/m；实验为NaCl溶液真空饱和，且有层理各向异性。我们取0.003S/m是这个量级内的研究选择，不是统计均值或现场盐度标定。其频率是0.0001–100000Hz，泥岩分解还排除了1000Hz以上耦合段；不能把毫秒级SIP弛豫时间塞进本项目MHz介电Debye。
2. [Wagner等2013，式33、图4及Table4](https://agupubs.onlinelibrary.wiley.com/doi/full/10.1002/jgrb.50343)：法国COx黏土岩实测1MHz–10GHz，改变饱和度。次级过程时间为7.6–20.8ns，支持考虑带内的极化色散和吸收。它使用分数阶GDR，分母是`(jωτ)^a+(jωτ)^b`，不是普通Debye的`1+jωτ`；Table4的`1−a`也不是可随意替换的Debye参数。我们借鉴8ns的量级，**没有把作者表拟合为单极，也没有把12/3写成作者实测值**。COx不是营山紫红色泥岩，同一岩性名不足以传递矿物/含水条件。
3. [Fam和Dusseault1998](https://cdnsciencepub.com/doi/10.1139/t98-014)测量20MHz–1.3GHz的三种页岩及层理方向；本轮只取得出版方摘要/元数据，完整数值谱未取得。用于确认频段与方向依赖的研究存在，不补造Debye表。
4. [NASA1976报告TableI](https://ntrs.nasa.gov/api/citations/19760025659/downloads/19760025659.pdf)给出的三个页岩样在100MHz的ε′为4.03/4.83/3.48，tanδ为0.16/0.17/0.13。状态是收到时原样，不能称为明确干样。这个反例说明“泥岩一定比砂岩ε高”不是通用规律；我们的12>9只是当前对比假设。由tanδ推得的MHz有效电导包含极化损耗，不能再当独立σDC与Debye重复叠加。

油页岩、海水洗过的海相切屑浆体、单位有疑问的仿真材料表都不作为默认泥岩电性依据。仅凭文献岩性无法给本场地严格置信区间；本轮也不从“想看清界面”倒推介电对比或低损耗。

## 固定配方及推导

[mudstone_design_v0_1.json](../../configs/research/mudstone_design_v0_1.json)是本单元新记录，未改旧覆盖/砂岩设计文件。

| 参数 | 固定值 | 属性 |
|---|---:|---|
| 95MHz ε′ | 12 | 研究中心值，非实测 |
| ε′20MHz−ε′170MHz | 3 | 两端总差，不是±3或Δε |
| τ | 8ns | 单极简化，极化损耗峰约19.89MHz |
| ε∞ | 11.739510249300162 | 由上述实部约束计算 |
| Δε | 6.200368247790598 | 由上述实部约束计算 |
| σDC | 0.003S/m | 研究初值，独立于极化损耗 |
| μr/磁损耗 | 1/0 | 各向同性、无磁损耗假设 |

采用`exp(+jωt)`约定：`εeff=ε∞+Δε/(1+j2πfτ)−jσDC/(2πfε0)`。令`a(f)=1/[1+(2πfτ)^2]`，`Δε=3/[a(20MHz)−a(170MHz)]`、`ε∞=12−Δε·a(95MHz)`。两项实部约束不唯一确定τ，8ns是明确选择；12和3也不形成“典型泥岩范围”的证明。

材料命令是参数表达，单独不构成可执行仿真契约：

```text
#material: 11.739510249300162 0.003 1 0 mudstone
#add_dispersion_debye: 1 6.200368247790598 8e-9 mudstone
```

α=`−Im[(2πf/c)√εeff]`；场幅1/e为`1/α`，场幅dB为`−20αL/ln10`。2.8m示例是ZK08的上段泥岩厚度，往返路径5.6m，**不是全线恒定厚度或18.5m全泥岩传播**；仅计算吸收，未计扩散、界面透射/反射和覆盖层。泥岩顶面的回波在反射前没有穿过整段泥岩，不能给顶界面机械扣除−25dB。1.7m下段夹层的同口径95MHz吸收为−15.33dB。

95MHz的总有效电导约0.00957S/m，高于输入σDC0.003，因为包含极化吸收；降低σDC不代表消除全部损耗。诊断用仅改σDC的0.001/0.009S/m两份变体，以及同中心ε′12/σ.003的非色散对照，均已单列，**不认证为干/湿状态、完整不确定度界或物理clean**；没有冻结这些对照的求解批次。

当前配方在95MHz的局部正入射电场反射系数幅度：覆盖层→泥岩约0.0386，泥岩→砂岩约0.0751。因此粉质黏土—泥岩在这一假设下本来就是弱反射；较深夹层还受上覆吸收，不能要求B-scan所有彩色分区同样显眼。这些是局部平界面解析量，不能替代斜坡、多层干涉、航空照射的B-scan或实测SNR。

暂给各段泥岩同一电性；风化程度、含水、裂隙、层理各向异性未知，不能凭剖面图自动赋不同σ和Debye。覆盖层既定低损耗配方也仍未现场认证，新泥岩不能替它补足证据。
