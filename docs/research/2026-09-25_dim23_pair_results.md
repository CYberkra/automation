## 配对差分结果（官方 SFCW direct 后处理，501 频点 20–170MHz，200ns 尾窗）

各维度内部 TGT−BG 差分（消去源矩与背景）；**未做任何跨维度绝对幅度对比**。

| 量 | 2D（TMx） | 3D |
|---|---:|---:|
| 差分时域峰值（各自源归一化，不可互比） | 6.62×10⁻⁴ V/m | 1.72×10⁻⁶ V/m |
| 差分包络峰到时 | 305.80 ns | 315.55 ns |
| 差分谱峰频率 | 148.4 MHz | 170.0 MHz |
| 谱峰处相位 | 105.36° | −40.88° |

理论双程到时（15m 空气 + 3m 覆盖层 + 7m 砂岩，εr16/9）约 320ns，两侧包络峰均落在其附近。

跨维度形状对比（仅到时/相位/归一化趋势）：

- 包络峰到时差：2D 比 3D 早 **9.75 ns**（305.80 vs 315.55）。
- 时域差分波形（3D 插值到 2D 时间轴后）最大归一化互相关 **0.716**，最优时移 +0.71 ns——主峰波形形态相似但远非一致。
- 归一化谱形状相关 **0.902**；谱峰频率差 −21.6 MHz（3D 更偏高频端，3D 在 170MHz 封顶）。
- 归一化幅度趋势差（2D−3D，各选频点）：20MHz +17.6dB、50MHz +9.9dB、80MHz +5.6dB、110MHz +4.1dB、140MHz +1.5dB、170MHz −0.7dB——**3D 差分谱显著更偏向高频、低频端衰减更快**，与点源球面扩散（1/r，频率无关传播因子）对线源柱面扩散（1/√r）以外还叠加近场/有限目标尺寸效应的预期方向一致。
- 相位差对频率的线性拟合残差 std 达 708°——带内相位差不是单纯时移，**2D 与 3D 的差分相位不可互相迁移**（拟合等效时移 −147.8ns 只是形式量，无物理意义；残差受低幅度频段相位噪声放大）。
- 探索性 3D→2D 几何扩散变换（远场因子 1/√(i2πf)，常数省略、仅比形状）：与 2D 归一化谱形状相关由 0.902 提升到 **0.954**。方向符合文献预期，但近场区与常数未定，只作探索性证据单列。

## 结论与限制

1. 在本几何/频段/材料族（20–170MHz、15m 航高、10m 深 2×2m 湿润异常、平层粉质粘土/砂岩）下：2D 与 3D 的目标差分**到时差约 10ns（约 3% 双程时间）量级**；主峰波形相关 0.72；归一化谱形状相关 0.90，经远场 3D→2D 变换后 0.95。
2. 差异主导项：3D 差分谱相对 2D 明显高频化（低频端低 17.6dB@20MHz），与线源/点源扩散 + 2D 目标沿 x 无限（柱面散射）vs 3D 2m 有限目标的散射差异一致；**差分相位两侧不可互用**。
3. 明确不声称：5cm 3D 网格已收敛（170MHz 仅 8.8–11.8 单元/波长）；2D 绝对幅度代表实测；结论外推到其他几何/材料/倾斜界面。2D 无限目标与 3D 有限目标的差异是被测量而非误差。
4. 对维度策略的含义（限本场景族）：2D 初筛给出的**到时与目标有无判断**与 3D 相差约 10ns 量级、谱形高度相关，可用于排序/初筛；但**幅度—深度趋势与相位不能从 2D 直接搬到 3D**，涉及增益/衰减补偿定量结论时需 3D 代表性校核。

## 下一步建议

- 若要把维度差异用于处理链设计，先在 2–3 个代表场景做 3D 代表性校核（本批方法可直接复用），而不是扩大 2D 结论。
- 3D 网格收敛（10cm→5cm→2.5cm 或垂向细化）尚未做；任何定量幅度结论前需要。
