## 1. 定位与依据

- S1/S3 进入奖励协议有两个前置（scope_limits 照录）：① 参考事件窗构造——**已完成**，`configs/research/s1s3_reference_window_contract_v0.1.json` 冻结（SHA `831326d8…`，四族费马窗 ±10 ns，实测−费马 max|δ| ≤ 3.62 ns）；② **容差重校准——本提案**。
- 冻结容差 v0.2（τ_A=0.20 / τ_D=0.95 / ε_Nb=1.5 / τ_clip=0.002）的依据是 **t3 三族机制阶梯**：τ 放置于计量阶梯刻度之间（非候选倒推，Cawley–Talbot 合规）。该依据只覆盖 t3 族（S2X/S2TZX/C3mX）；S1/S3 窗内容不同（尤其 S3=出露 grazing 回波），v0.2 的"依据覆盖范围"不含新族——这就是重校准要补的证据。
- 本提案把 t3 阶梯**逐字移植**到四族新窗上，产出响应曲线与 v0.2 放置核验；**主路径不改任何 τ 值**，仅当实测证据显示某族响应与 t3 实质不同时，才按同一套机制刻度规则提族专属值（另需用户过目）。

## 3. 容差处理双路径（主路径不改值）

**主路径——验证后沿用（预期）**：在四族响应曲线上核验 v0.2 各 τ 的放置锚全部再现——

- identity 锚：D=0 / A=0 / H=0 / ρ=1 / N_b=1（四族 33 道全过）；
- τ_A=0.20 坐阶梯级间：最轻档 −1 dB 的 A≈0.057、极性反转 A=2 分列两侧（量级结构，非数值复刻——阶梯刻度非候选倒推的原则不变）；
- τ_D=0.95：delete 档 D=1 在其上、弱档在其下的排序结构保持；
- ε≥1 结构性下限：ε×0.5 使 identity 转挂的性质在新族复现（已知结构性结论，新族验证后登记）；
- τ_clip=0.002：置于 1e-3（直达波邻域）与 5e-3（全记录摧毁）档之间，计量断言逐档达标。

全部核验通过 → **v0.2 全局值沿用，不产生新契约**，产出"验证记录"登记入 decision_log 与 registry（这是最小改动、证据充分的结局）。

**备选路径——族专属值（仅证据驱动）**：若某族响应实质不同（例如 S3 grazing 窗的 delete/amp 响应与 t3 界面窗明显偏离，使 τ 的阶梯间放置不再成立），按同一机制刻度规则为该族提值，**新契约文件**（addendum，v0.2 原文不动），另请用户过目后冻结。不允许从候选算子表现倒推（Cawley–Talbot 条款照录）。

## 4. S3 特殊标注（语义不改，如实报告）

S3 事件窗的内容是**出露区 grazing 回波**（2026-09-29 窗契约冻结期修正一的结论），非迹下局部界面的镜面反射。界面带类损伤档（amp/polarity/shift/delete）作用的对象仍是"该窗内的记录内容"，机制计量语义不变；但响应曲线的绝对量级可能与 S1/t3 不同（子波内容、带宽占比不同），报告与（万一的）族专属值提案中必须以此标注，**不得把响应差异单独归因为"倾角"**（覆盖层厚度/出露位置随档改变，t1t3 提案 §7 照录）。
