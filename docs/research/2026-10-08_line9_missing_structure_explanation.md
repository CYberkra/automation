# 为什么三个 B-scan 没有呈现预期地层脉络

日期：2026-10-08。基线c7b3c06。仅复用三个结果包及428道审计，不新增求解、不修改原材料/几何、不训练。前序完整波形证据见[三个包复审](2026-10-07_line9_three_packages_review.md)。

## 判断

目前最有证据的解释是：**深部主反射在当前材料设定下很弱，强早时场的带限旁瓣又覆盖了深部显示区；此外，用户看到的高程剖面与地形跟随的时间域B-scan并不使用同一个纵坐标。** 不把结果统称为航空GPR不可避免，也不将原因全部归给PML。

后处理数值可以复现，只说明该变换实现自洽，不能证明选用的频窗、点/线源观测量与实际天线/仪器导出链相同。此前将PML路径、航高或单一材料变化过早作为总解释，证据均不足。

## 1. 真实反射弱于模型彩图给人的直觉

地质图颜色分明，不代表电磁反差强。按三包实际Debye参数、复折射率n=√ε和正入射场反射系数R=(n₁−n₂)/(n₁+n₂)，95MHz时：

|界面|场反射幅度系数绝对值|20log₁₀绝对值|
|---|---:|---:|
|空气→粉质黏土|0.5373|−5.40dB|
|粉质黏土→泥岩|0.0386|−28.27dB|
|泥岩→砂岩|0.0751|−22.49dB|

上覆传播还要另外衰减。95MHz每穿过1m材料再返回的场幅损耗：覆盖层约1.62dB、泥岩约9.02dB、砂岩约4.70dB。降低空气航高不会减少这些地下损耗。

从每道实际体素界面重建穿越厚度，叠加材料双程吸收、各上覆界面的下行/上行Fresnel透射和底部反射，得到**局部水平层平面波一次反射预算**：

|包|95MHz底部砂岩主反射/地表反射，场幅dB|
|---|---:|
|pkg1 / AGL8m / v5|−96.2至−94.3|
|pkg2 / 实际AGL10.2–12.5m / v3|−72.3至−53.0|
|pkg3 / AGL1m / v3|−72.3至−60.9|

这些不是实测SNR或全波场检出值，也未计几何扩散、天线方向图、直耦、多次反射及侧向散射；是解释当前参数为何容易产生弱深部响应的解析预算。材料是研究初值，并无本场地介电谱证明其量级适用于实测。

低频传播有利，例如pkg3在20MHz的同一预算约−49.4至−42.7dB；但只取20–39.8MHz，原频点仅剩67点，Gaussian理想单回波半幅全宽约96.8ns，多个界面会重叠。全频带名义宽度不能自动当成衰减后的深部有效带宽。

## 2. 可见的规则横纹主要不追踪真实界面

前序用0–100ns保留、100–120ns平滑降零的native早时分量，独立重建后仍在旧320–497ns区重现深部条纹；三包低频复数相关分别0.99950、0.98482、0.99730，100ns切分亦相近。这个窗晚于所保留的本地早时回波。强响应经有限频带变换会把旁瓣延伸到后续显示时间，不能把晚处每条横带都赋予地下深度。

本轮重新查看Gaussian/Hann/矩形对照：Hann降低规则振铃后，仍未出现已经确认的连续底部砂岩轮廓。因此只换频窗可以减少遮挡，不能保证原深部信号足够强。时间分割会改变频谱，不能把剩余分量当纯目标，也不能把相关系数当能量贡献百分比。

## 3. 模型整体坡度不会原样映射成地形跟随的走时坡度

pkg3已完成的13.8m区间内，地表模型高程24.075–24.8m，覆盖层底高程16.75–17.55m，看高程图两者都倾斜。但两者之间覆盖层厚度只有7.25–7.35m，即仅变化0.10m。天线跟随地表约1m，其覆盖层底的95MHz近似双程时只变化167.77→170.07ns，约2.3ns；相较全频Gaussian约13ns主瓣，图上接近平带是可以预期的。

这只解释覆盖层为何不呈现原高程坡度，**不能解释所有深部结构消失**。pkg3底部砂岩近似走时仍变化257.93–289.68ns，约31.7ns；若能可靠分离并有足够有效带宽，应检验其是否随该趋势变化。当前主反射身份尚未确认，不能用“B-scan不是模型”回避这一缺口。

还须对齐实际测段：三个包只完成38.6m、28.2m、13.8m，不是全195m测线；pkg1/v5与pkg2、3/v3几何不同。不能将整幅模型的全部起伏与任一小段B-scan比较。

## 4. 已知错误与尚未锁定的因素

旧图固定覆盖7m＋泥岩7.3m及pkg2的+80m地形索引已经证实与实际H5不匹配；它们误导解释，但不改变原始求解场，故修正标线不应被期待自动修复波形。

FP32弱场可信度、侧向/顶部PML、二维线源与实际有方向性且有收发隔离的三维天线差别仍需独立对照。PML路径可能进入目标窗，并不能证明反射幅度主导。原始三包都使用相同地下材料、同类二维源和总场重建，降低航高后继续共有的问题并不会全部消失。

## 接下来要证实什么

优先取1m包的一两个同站位、同宽域模型，以FP64做底部砂岩保留/移除的配对对照，比较native晚时场及复数SFCW差分，以确定底部响应的强度与形态。若消融能隔离出沿真实参考到时变化的回波，则主要是弱反射/旁瓣遮挡；若仍没有，再做仅降低地下损耗的诊断，以及独立边界加宽对照。所有改变都要单列并保持其他条件，不能把低损耗诊断模型直接冒充真实场地材料。本轮没有执行这些新正演。
