# 算子契约评价的输入材料 v0.1：2026-09-26 仿真机制证据整理

日期：2026-09-26。状态：**机制级输入材料初版**，供 27 项算子契约（[`configs/research/operator_catalogue_v0.1.json`](../../configs/research/operator_catalogue_v0.1.json)）在[评价与标签协议 v0.2](2026-09-24_evaluation_and_labels_v0.2.md)下的评价设计引用。

本文只做**整理与映射**：把 2026-09-26 已完成的仿真证据按"对算子评价意味着什么"归位，不改变任何证据的资格，不新增仿真运行，不生成标签、阈值或契约 JSON。所有数值均照录自来源文档与其 `results.json`，不重算、不四舍五入改写。

标注约定：

- 【实测复算】分析脚本对已归档 HDF5 输出的复算值（非求解器声明）；
- 【方向性】对实测值的方向/机制解读，不构成资格升级；
- 【操作层事实】监督器实测（exit、墙钟、Job 峰值提交内存、vctip 处置事件）；
- 【沿用 v0.2】来自评价与标签协议 v0.2 或算子契约的既有规则，不是本轮仿真产生。

## 2. 对 27 项算子契约评价设计的输入

27 项候选结构（照录契约字段，不虚构）：`domain="time_real"`、`axes=["sample","trace"]`、`input_window="entire_predeclared_window"`、`gain_coordinate="u=i/(n_samples-1)"`、`candidate_count=27`；背景算子为 `identity` / `mean`（参数 0.25、0.5、1.0）/ `svd`（k=1、2、3），末增益 `end_gain` ∈ {1,2,4}，顺序 `order` ∈ {BG, GB}，另含 `gap_rtol=1e-08`、`numerical_rank_floor`、以及 `legal_count_is_input_dependent=true`（合法性与输入相关）、`local_mean_control_in_catalogue=false`（局部均值外部参照尚未并入目录）、`status="array_contract_checked_not_physics_validated"`。

下列约束分两类标注来源：**【仿真证据】** = 由第 1 节 E1–E9 引入；**【沿用 v0.2】/【沿用契约】** = 评价与标签协议 v0.2 或算子契约既有规则，本轮仿真不改变它。

### 2.1 背景与相干杂波抑制类（identity / mean / svd × 顺序 BG、GB）

| 约束 | 来源 | 对评价设计的含义 |
|---|---|---|
| 分层按族（C1/C3/C5/C8），不跨族平均、不跨族差分；族内只用同族同格 BG 作差分 | 【仿真证据 E1/E5】+【沿用 v0.2 §2、规格书 §6-P7】 | 评价表的主键是"族 × 网格档 × 场景角色 × 候选"，族间只能比方向、不能比绝对幅值；跨族共享背景（如用 C3 BG 去减 C8 目标）属禁止项 |
| 网格档分层（BASE / FINE2），不跨档相减、合并，不用跨档差当误差 | 【仿真证据 E5/E6】+【沿用 规格书 §7-8】 | 同一候选在粗档与细档上各自出一组指标；细档方向一致只支持"机制可用"，不构成精度认证，也不得用于给粗档指标定阈值 |

| 差分类评价可用族内 BG 作参照，但 `paired_contrast` ≠ clean 真值 | 【仿真证据 E1】+【沿用 v0.2 §3/§8】 | `ΔZ_a = T_a(F1) − T_a(F0)` 与 `ΔF` 的比较只作诊断项；共同保护对象（覆盖层底界面、围岩层界）的绝对检查不能由差分替代，差分一致也不能单独产生整幅质量赢家 |
| 数值分辨关注区只给风险诊断 | 【仿真证据 E4】+【沿用 v0.2 §3 `numerically_unresolved`】 | C8 族（尤其 D20m 两例）上不计算"抑制收益"类指标去判优；只记录候选是否额外损伤已声明事件，并把低量级记为不可评价原因 |
| 指标敏感性 vs 网格/维度变化量级 | 【仿真证据 E6/E7】 | 候选间指标差异若与网格诱导变化（相邻档 4.12% L2 / 3.88°）或 2D/3D 差（时域互相关 0.738/0.732、低频幅度趋势差 17 dB 量级）同量级，按 v0.2 §7 记 `undetermined`，不给优劣标签 |
| 输入形状与合法性 | 【沿用契约】 | 候选输入为 `[sample, trace]` 实数数组、整窗预声明、带符号、原轴原单位；`legal_count_is_input_dependent=true`，无效掩码输入仅允许全 identity；不新增频域分支、不做逐候选峰值归一化/重对齐 |

### 2.2 增益与衰减补偿类（end_gain 1/2/4 × 顺序 BG/GB）

| 约束 | 来源 | 对评价设计的含义 |
|---|---|---|
| **无已知乘性衰减真值 ⇒ 只给风险诊断，不给 `gain_quality` 理想标签** | 【仿真证据 E2：幅度随深度/覆盖厚度单调下降，但来自介质传播，不是给定的 `a` 曲线】+【沿用 v0.2 §6.2"完整电磁仿真或未知衰减"】 | 有损 FDTD 的衰减不是一条可预先给定的 `a⊙S0`；因此 `1/a` 补偿参考不存在，不得计算相对 S0 的理想 D/A/H。可保留：增益曲线、绝对残差、负控窗放大倍数、是否截幅、数值失败标签 |
| 增益前后各存一组结果；BG 顺序用增益前结果，GB 顺序仅作 `G⁻¹Y` 审计量单列 | 【沿用 v0.2 §4/§6.1】 | 增益不得掩盖背景删除：背景类标签在输入幅度坐标下判定，审计量不能称为"真实增益前中间量" |
| 整体亮度/能量上升 ≠ SNR 或探测深度提升 | 【仿真证据 E2/E4】+【沿用 v0.2 §6.1、AGENTS.md】 | 4 倍增益使同窗残差能量变 16 倍而不改变该点信杂比；C8/D20m 等低量级区的增益放大只作**风险诊断**（放大后是否制造伪证据、是否截幅），不得写为"探测能力提升" |
| 吸收压力族（C8、厚覆盖）与深部档（D20m）是增益放大的风险压力用例 | 【仿真证据 E4/E2】+【沿用 规格书 §1.1/§6-P6】 | 在这些档位上必须单独报告：增益前后负控窗绝对能量与能量比（分母非零时）、最大增益、曲线、异常、截幅；不生成"最佳增益倍数"标签 |
| 电导（吸收）轴与介电（阻抗/波速）轴分开记账 | 【仿真证据 E3：电导单因子 S0.005/S0.02/S0.05 不声称单调序】 | 增益类的评价不得用介电对比档（E12/E20/E28）的收益去抵消吸收档的风险；反之亦然。两类指标分表报告 |
| 深度/覆盖厚度单调方向可用于**分层**增益评价，不可用于外推最大深度 | 【仿真证据 E2】 | 增益评价按深度档与覆盖层厚度族分层出指标；不得据此给出"可探测深度"或"最大补偿深度"结论 |
| 增益坐标与窗内约定 | 【沿用契约】 | `gain_coordinate="u=i/(n_samples-1)"`、整窗预声明；增益曲线与实际步骤、耗时、失败原因一并保存 |

## 3. 明确的"不是"清单

本文及所引仿真证据**不是**：

1. **不是训练标签**：`training_labels_generated=false`、`training_eligible=false`（E9）。27 项候选的评价结果若未来用于学习，也只能是可用性 + 分项效果/偏序（【沿用 v0.2 §7】），不是"27 个编号的唯一类别"。
2. **不是 clean 真值**：`clean_truth_generated=false`；族内 BG 差分属 `paired_contrast`，只做配对变化诊断（E1）。不得把 `TGT−BG` 差分自动当作目标事件的绝对参考，也不得作为整幅干净地下响应。
3. **不是物理阈值**：`physical_acceptance_threshold=null`，带内能量比明确"not detectability, not SNR, not a physical threshold"（E9）。v0.2 的 D 上限、A 上限、负控能量上限、参考污染界限、最小有效收益仍为 null；代码中的数值只是数组夹具值。
4. **不升级 `reference_state`**：保持 `numerically_unresolved`；`physical_label_eligible=false`。细档方向一致（E5）与逐位零差复现只证明"同档运行间可复现"，**不证明收敛或精度**；ZFINE2 的 4.12%/3.88° 是相邻网格差，未做 Richardson 外推。
5. **不是网格收敛认证**：`grid_convergence_certified=false`；粗档物理充分性未认证，跨档比值不是误差度量（E5/E6）。
6. **不做 3D 外推**：2D/3D 比较含三类未排除混淆因素（E7）；决策 D1 明确 batch2d_v1 不含 3D，D3 的 A0 三维校核**尚未执行**（需另行冻结契约并经用户敲定）。在此之前任何结论不得表述为三维校核通过。
7. **不做实测外推**：结论限定于 batch2d_v1（BASE/FINE2）与 dep3d_gold_v1 场景族与所分析网格（E9 的 `conclusions_scope`）。材料参数（覆盖层 εr16/σ0.01、砂岩 εr9/σ0.001、目标族电性档）是研究假设，不是场地实测值；营山/雅安测线与钻孔不参与。
8. **不是可探测性或最大探测深度结论**：C8 低量级（E4）与深度单调（E2）均不作此类声明；OFF 档（E8）不是可探测性证据。
9. **不合并负控、不跨族/跨档差分**：`negative_controls_merged_into_targets=false`、`cross_family_differencing=false`、`cross_tier_differencing=false`（E9）。
10. **不是新的执行授权**：本文不生成输入文件、不生成契约 JSON、不改动既有文件；任何后续仿真（3D 校核、多道扩展、细档负控）须按规格书 §5 另行冻结契约并经用户敲定，已消耗 attempt 不复用。
