# 深部计算域的背景独立参考检查

目标组仍在求解期间，使用已完成FINE、ZFINE、YFINE背景输出进行CPU检查。几何均为15m离地高度、1.3m横向间距、3m覆盖层（εr16、σ0.01S/m）与砂岩（εr9、σ0.001S/m）；这些是研究假设，不是场地实测。

参考为已独立校验的二维层状反射，加解析无限线电流空气直达波；使用相同20–170MHz、0.3MHz频率表。每份FDTD按自己的原生dt、源/接收时刻通过官方SFCW处理，采用原固定200/400ns尾窗，不拟合幅相、不对齐。

采用200ns尾窗。三组的200/400ns尾窗变化除以层状反射范数约6.33e−8。均匀格距减半（FINE→YFINE）使这两个L2误差约降至四分之一，与二阶细化趋势一致。

重要限制：这里没有同格空气FDTD配对，扣除的是解析空气，所以剩余量包含直达波离散误差，不能叫“纯反射数值误差”。总场被强直达波主导，误差很小也不能证明20m微弱目标差分准确。这一检查支持背景场和频域处理链的一致性，不解除深部目标numerically_unresolved状态，不生成训练或物理标签。
