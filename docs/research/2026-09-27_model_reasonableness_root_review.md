# 当前模型合理性审查（2026-09-27）

结论：当前模型适合作为分层介质、局部电性异常和处理算子的受控机制基准；尚不能代表真实无人机沿航迹SFCW测线，更不能据此确认20m非显性滑坡的探测能力。本轮只读输入/代码并做解析计算，未启动求解、未改冻结模型或重跑S5。GPT-6 Luna/high核对本地模型，主agent独立核对输入、处理代码和官方V4文档。

## 已对应实际需求的部分

- BASE/MT/CO地面z=30m、源接收z=45m，满足15m离地高度；CO固定收发距离1.3m。
- BASE分析器 `scripts/analyze_batch2d.py:35` 调用官方SFCW处理，20–170MHz含端点501点，频率步长0.3MHz。
- `.in` 用 impulse 而非 Ricker。官方V4支持一次宽带脉冲求解后提取复数频响合成SFCW，不需要501次逐频FDTD；此处方法选择正确。[官方SFCW](https://docs.gprmax.com/en/latest/inc_SFCW.html)

## 优先问题

### 1. 二维多道采集不能直接对应真实飞行测线（高优先）

二维输入为 `#domain: inf 32 50`、TM、Ex：x不变，计算y-z截面。早期坐标约定x沿飞行、y横航迹。CO11让Tx/Rx一起沿y平移，保留1.3m基线，故是横航迹剖面代理；真实设备应保持横向基线并沿x飞行。将y直接改称飞行方向又会把收发基线变成纵向。MT33固定发射、33个接收位置，是变偏移距单炮集，也不是飞行B-scan。

二维可继续做低成本机制筛查，但其横向不变几何、线源传播、幅值衰减与有限三维目标不同，不能直接承担实际飞行数据验证。官方明确2D适用于一方向不变的模型。[V4二维模式](https://docs.gprmax.com/en/latest/features.html#two-dimensional-tm-and-te-modes)

证据：`configs/research/batch2d_v1_co/B2D-C3m-D10m-W4m-T0.5m-E20-S0.02-CO11-t05.in`；`scripts/analyze_batch2d_co.py:31-34`；`docs/research/2026-09-24_airborne_geometry_update.md:21`。

### 2. 后续评价数据域与设备SFCW数据域不一致（高优先）

`run_eval_batch2d_mt.py:96,156,204` 与 `run_eval_batch2d_co.py:126,208,257` 从H5读原始Ex后直接切窗、施加算子；这些原始宽带冲激响应指标不等于501频点SFCW重建后的指标。近期F0/Δ巨大比值也不能作实际雷达SNR。

CO诊断 `analyze_batch2d_co.py:56-60` 用FFT最近频格代替逐频复数DFT：20352点、dt=5.896635841874211e-11s时频格约0.833275MHz，501个频率请求实际只落到181个不同频格，存在重复计权；这不是官方501点复频响。该诊断尚未证明偏差大小，不能把它称为完整SFCW处理。BASE调用官方API的结果不受这一实现描述影响。

后续应复用既有H5与官方direct流程，保留源归一化、时间交错、复相位，明确频窗和重建时间轴，再设计新的开发侧评价；旧时间索引/阈值不得直接迁移，已消费测试组不重新调参。

### 3. 地质模型目前是平层加盒状异常，尚非滑坡地形

主例覆盖层εr=16、σ=0.01S/m；基岩εr=9、σ=0.001S/m；异常εr=20、σ=0.02S/m。它们是设定的研究参数，尚无现场含水率/频散/电性测量支持，不能认证为本项目粉质黏土和砂岩的真实参数。

D20例异常中心位于地下20m，宽4m、厚0.5m，沿x无限延伸。没有坡面、起伏基岩、风化过渡带、倾斜或弯曲滑移带。盒异常能检验散射机制，却不能覆盖非显性滑坡结构保真任务。也不应直接把高介电、高电导异常命名为滑坡。

按当前假设电性，仅计算均匀介质垂直往返的本征衰减：20m目标、3m覆盖层约42–43dB；8m覆盖层约76–78dB（20和170MHz端点）。计算公式 alpha=omega*sqrt(mu*epsilon/2)*sqrt(sqrt(1+(sigma/(omega*epsilon))^2)-1)，路径分别为覆盖层2C、基岩2(20-C)。不含几何扩散、界面传输、天线、系统噪声；既不代表总损耗，也不证明可探测/不可探测。说明覆盖层厚度和电导率是需要优先约束的变量。计算存于 `artifacts/research_checks/2026-09-27_model_reasonableness/analytical_checks.json`。

### 4. 天线与数值精度仍有资格限制

- Ex理想Hertzian源/场接收不是照片中的实物天线模型。极化未由用户确认，也未纳入实测天线响应、仪器动态范围和运动误差；因此不作绝对幅度/检测距离结论。
- 25mm网格对170MHz、εr=28的无损近似波长约有13.3格，可作采样初筛，不能代替长路径相位、网格、边界和记录尾部收敛检查。原始impulse包含带外分量，其全带指标也不自动享有170MHz精度资格。
- 1.2us FDTD记录不必等于0.3MHz对应的3.333us重建周期；真正条件是物理响应是否充分记录，尾部加窗不能掩盖晚到信号。[V4有效频带和时间窗](https://docs.gprmax.com/en/latest/inc_SFCW.html#frequency-and-time-window-validity)
- A0三维例仅10m深有限2×4×0.5m异常配对，5cm网格、8×10×50m域；与二维对照同时改变了维度、有限目标长度、域宽和网格。谱形相近不构成真实20m沿航迹精度认证。已有 `numerically_unresolved` 状态保留。

## 最小修正顺序

1. 先冻结“真实几何 vs 二维代理”坐标图与数据语义：二维结果明确标横航迹机制代理，实际验证需保留横向1.3m基线且沿航迹移动。
2. 优先用已完成H5统一官方SFCW复频响与重建数据，不新增FDTD；只做开发侧诊断，重新定义物理时间窗，不能沿用原始冲激域阈值。
3. 新版地质模型从平层基准逐步加入倾斜/起伏界面和连续异常带，电性按假设范围分层；有测量再标定，不堆砌未经验证的随机地质。
4. 只在规格明确后提出少量真实几何3D锚点及网格/PML/记录长度验证预算；不以大批2D结果替代3D证据，不立即启动新仿真。

现有结果保留为机制基准，不作废；本报告不解除G4、不认证clean标签、不训练。
