## 1. 动机与定位

### 1.1 现有目标体的已知简化

当前 FDTD 目标场景中的异常体一律是**轴对齐水平平板**（【依据】2D 锚点 `#box: inf 14 19.75 inf 18 20.25 target`，`.in:18`；3D 锚点 `#box: 3 3 19.75 5 7 20.25 wet`，`.in:17`）。这是一个已知的几何简化，不是对地下结构的完整描述。

AGENTS.md 对保护对象的要求明确包含倾斜形态：【依据】`AGENTS.md:123`——“当前按本场景相关公开文献和明确假设定义界面、弱反射及**倾斜/弯曲/断续结构**，保留局部响应和纯干扰/无深部目标作为必要对照”。同时要求分类型报告、不能用平均收益掩盖某类相关结构被删除（同上）。

在此要求下，水平平板场景无法回答一个具体问题：**当保留目标是倾斜界面时，均值道扣除、SVD/PCA 一类"把平缓/连续分量当杂波"的算子，是否会连同倾斜目标一起抹除**。倾斜情形与水平情形在这类算子下的响应可能不同，需要独立的几何输入来判断。

### 1.2 定位声明（措辞纪律）

- 本扩展的倾角档位是**工程假设性质的参数化扫描**，用于构造可控的几何变量，**不是场地实测倾角、不是滑坡形态反演、不是岩土参数估计**。【依据】`slices.json` `hard_limits[3]`：“不生成物理/训练标签；倾角档位为工程假设非场地实测”。
- 本项目范围内该扩展统一称为**"倾斜目标参数化扩展"**。本文及后续文档不得使用“模拟真实滑坡”“还原实际滑面”“接近现场情况”一类表述。倾角的取值理由是格点可整除（见 §2.2），不是地质统计依据。

## 2. 阶梯逼近方法

### 2.1 基本做法

gprMax 的 `#box` 只能表达轴对齐长方体，不能直接表达倾斜平板。【依据】生成器采用 FDTD 建模中的常规做法：把倾斜平板沿 y（沿测线方向）切成若干**等宽条带**，每条带仍为轴对齐 box，逐条带整体沿 z 平移，从而形成阶梯状包络。【依据】`scripts/gen_tilt_target_slices.py:1-16`。

计算全部在**整数格点**上进行：条带 y 边界与 z 偏移都是格距的整数倍，因此网格对齐是**构造性保证**，不依赖事后检查（【依据】`gen_tilt_target_slices.py:5-6, 80-86`）。

### 2.2 对称整数偏移规则

对偶数条带数 `n`、偶数步长 `s`（单位：格），第 `i` 条带（i = 0…n−1，沿 +y 递增）的 z 偏移为：

```
dz_offset_i = -(2i + 1 - n) * (s // 2)    [单位：格]
```

【依据】`gen_tilt_target_slices.py:9`。该式使偏移关于板心**反对称**，偏移序列成对出现（±1, ±3, ±5, …格），并沿 +y 方向递减，即"沿测线下倾"。四个变体的 `off_cells` 序列可在 `slices.json` 的 `slices[].off_cells` 中逐条核对，本文 §3 不复述每条（【依据】`slices.json` 相应 `slices` 数组）。

条带的 z 区间由对称构造给出（半厚 `t2_c = (T/2)/d`，单位为格）：

```
z0_i = z_center - T/2 + dz_offset_i * d
z1_i = z_center + T/2 + dz_offset_i * d
```

【依据】`gen_tilt_target_slices.py:82-83`，其中 `T = 0.5 m` 为竖直厚度、`d` 为格距。

### 2.3 有效角度公式

相邻条带中心线之间的 z 落差为 `s*d`，条带宽为 `w`，故阶梯的整体有效倾角为：

```
theta_eff = atan(s * d / w)
```

【依据】`gen_tilt_target_slices.py:13`。注意 `s` 与 `w` 同时出现在分子分母：同一 `theta_eff` 可由不同网格档下不同的 (w, d) 组合实现，这也是 3D 档条带宽不同于 2D 档的原因（见 §3 注）。

### 2.4 为什么名义 5°/10° 不可格点整除

名义 5°/10° 对应的 tan 值分别约为 0.087489、0.176327，要求 `s*d/w` 精确等于这些值；在 `s` 必须为偶数格、`w` 必须为格距整数倍的约束下，二者的比值无法精确命中这两个数。【依据】`gen_tilt_target_slices.py:16`（原文：“名义 5°/10° 不可格点整除，按纪律调整到可整除档并记录”）。

因此在给定网格与步长下取**最接近且可格点表达**的档位，并**如实报告有效角度而非名义角度**：

- `s=2, d=0.025, w=0.5`（2D S1）→ `s*d/w = 0.1` → `atan(0.1) = 5.710593°`（【依据】`slices.json` 2d_S1.theta_eff_deg；【自算】arctan 0.1 = 5.710593137…°，四舍五入到 6 位与之一致）；
- `s=2, d=0.05, w=1.0`（3D S1）→ `0.1` → 同上 5.710593°；
- `s=2, d=0.025, w=0.25`（2D S2）→ `0.2` → `atan(0.2) = 11.309932°`；
- `s=2, d=0.05, w=0.5`（3D S2）→ `0.2` → 同上 11.309932°。

即**名义角只作标签保留**（`theta_nominal_deg` 为 5.0 / 10.0），报告和后续配对分析一律使用 `theta_eff_deg`。

### 2.5 竖直厚度 vs 垂直厚度（已知近似，显式声明）

构造时每条带的**竖直厚度保持 0.5 m**，与水平平板一致；倾斜后板的**垂直（法向）厚度**变为 `0.5*cos(theta)`。【依据】`slices.json` `base_plate.note`。两档下的相对差异：

- 5.710593°：`cos(theta) = 1/sqrt(1+0.1^2) = 0.995037` → 差异约 **0.5%**（【自算】，与 `note` 一致）；
- 11.309932°：`cos(theta) = 1/sqrt(1+0.2^2) = 0.980581` → 差异约 **1.9%**（【自算】，与 `note` 一致）。

这是一个已知并显式声明的几何近似：**倾斜档与水平档的法向厚度（以及阶梯包络的实际体积）不严格相同**，跨倾角的绝对幅度比较因此受此近似影响，不作同等对待。y 向水平投影按构造保持 4 m（14–18 m / 3–7 m 不变），沿倾斜方向的实际板长相应变为 `4/cos(theta)` ≈ 4.020 m（S1）/ 4.079 m（S2）（【自算】）。

## 4. 对齐与约束校验（生成器内置断言）

| # | 断言 | 源码位置 | 含义与检查结果 |
|---|---|---|---|
| 1 | `abs(w_c*d - w) < 1e-12` | `:68` | **条带宽网格对齐**：条带宽必须是格距整数倍（构造性保证，非事后检查） |
| 2 | `n*w_c == round(L_M/d)` | `:70` | **条带数铺满板长**：n 条带恰好覆盖 4 m，无缺无重叠（四变体分别 8×20 格、16×10 格、4×20 格、8×10 格 = 160 / 80 格，【自算】） |
