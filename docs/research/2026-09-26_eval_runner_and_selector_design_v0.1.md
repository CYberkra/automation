## A. 评价运行器设计

### A.1 定位

运行器是**评价侧的唯一入口**：给定（归档仿真输出，冻结事件表，候选配置）三元组，产出"逐事件 × 候选"的一行记录与失败记录。它**不**做参考构建（参考构建是 G3/G4 的独立步骤），**不**做 ROI 搜索，**不**做阈值校准。

- 输入侧只读：`artifacts/simulations/2026-09-26_*/`（h5 原始输出，只读、【依据】AGENTS.md 原始资料只读）、`artifacts/research_checks/2026-09-26_batch2d_analysis_r1/results.json`（分析复算结果，只读）、事件表 JSON（**待冻结**）、`configs/research/operator_catalogue_v0.1.json`。
- 输出侧另存：新目录，输出路径须不存在（不覆盖证据）【沿用】算子契约 §8、AGENTS.md"历史输出不覆盖"。

### A.3 运行门禁（三条硬门禁，逐条照实写）

#### 门禁 1：事件表未冻结 ⇒ 不对仿真输出跑候选

v0.2 §2 要求窗在候选运行前冻结，且不得沿处理结果重新找峰或重画 ROI【沿用】。事件表提案 v0.1 处于"kimi 已验收、待用户敲定"，**尚未冻结为 JSON**（[事件表提案](2026-09-26_event_table_proposal.md) §7.1 第 6 步未执行）【依据】。故门禁 1 当前不成立。

#### 门禁 2（关键，纠正前次草稿的实质错误）：单道 `[n,1]` 输入下 27 项**全部**不可用

已核验 `scripts/research_operator_contract.py`：

- `apply_configuration` 的入口检查在 **:70–71**：
  `if domain != "time_real" or a.ndim != 2 or min(a.shape) < 2: raise ValueError("require_time_real_2d_sample_trace_with_each_dimension_at_least_2")`。
- 该检查位于**配置查找之前**（配置查找在 **:76** `matches = [c for c in catalogue() if c["id"] == config_id]`），也位于掩码检查（:80–85）与增益曲线构造（:87）之前。
- 因此，对 BASE 归档的单点接收 A-scan（`n_samples=20351`、`n_traces=1`，【依据】[粗档结果](2026-09-26_batch2d_v1_results.md) h5 元数据 / [事件表提案](2026-09-26_event_table_proposal.md) §3.6(c)），`min(shape)=1 < 2` ⇒ **27 项候选全部在 :70 被拒**，一个都进不到配置查找、掩码检查或增益步骤。这不是"某几项因 SVD 秩不合法而不可用"，而是**输入被整体拒绝**（`ValueError`，而非 `ConfigUnavailable`）。

**即使人为放宽 :70 的检查，退化仍然使候选无意义**【自算 + 依据】：

| 算子 | 放宽后的行为 | 结论 |
|---|---|---|
| `mean`（B1/B2/B3，λ=0.25/0.5/1.0） | :36 沿道轴 `mean(axis=1, keepdims=True)`；N=1 时 `μ_i = X_i1`，故 `X − λμ = (1−λ)X` | 退化为**整道标量缩放**，不含任何"背景估计"语义；λ=1 输出全零。评价它等于评价"整体缩放"，而 v0.2 §5 已明确整体缩放会失真地改善传统误差式指标 |
| `svd`（B4/B5/B6，k=1/2/3） | :39 `if k >= min(x.shape): raise ConfigUnavailable("svd_rank_must_be_less_than_minimum_dimension")`；`min(M,N)=1` ⇒ k=1/2/3 **全部非法** | 无一项可运行 |
| 外部参照 `local_mean_control` | :124 要求窗宽为 ≥3 的奇数且 `width <= a.shape[1]`；`n_traces=1` ⇒ 无合法窗宽 | 传统自适应基线 L 同样不可用（见 §B.2） |
| 增益（`end_gain` 2/4） | 增益曲线本身可定义，但 :70 门禁先触发 | 无法单独运行 |

**结论（写入显著位置）**：当前仿真数据形态下，27/27 候选 + 局部均值外部参照全部不可用，**不是"27 项中仅 3 项可运行"**。任何"先在单道上跑一部分候选探路"的想法都不可行：可跑的集合为空。这是 G2（仿真侧尚无多道 trace 轴数据）未解除的**直接后果**——27 项候选的核心语义（`mean` 沿道、SVD 低秩、局部均值沿道）全部定义在道轴上，单道数据没有道轴。解除路径只有一条：按 [证据材料](2026-09-26_operator_evaluation_sim_evidence_v0.1.md) §4-G2 另冻结一组多接收点/多道场景族并**经用户敲定后执行**；已消耗 attempt 不复用。

> 【提案】不为了"先跑起来"而放宽 :70 或为单道新增替代算子。放宽门禁只会产出整体缩放的结果，却被记成"背景抑制候选的评价"，属于制造假证据；为单道新增沿样本轴算子则属**新的动作库**，须重走契约、参考与评价（[传统基线](2026-09-24_cycle03_traditional_baselines.md) §4 末：不能让传统参照使用额外动作后再把旧 27 项的离线最优称为上限）。

#### 门禁 3：增益类必须保留增益前结果；负控不并入目标行

- BG 顺序使用实际增益前结果 `pre_gain`；GB 顺序只把 `G⁻¹Y` 作审计量单列，且**不得称为真实增益前中间量**【沿用 v0.2 §4、[算子契约](2026-09-24_cycle03_operator_contract.md) §4 表】。
- NC / OFF / BG-NEG 负控行**只报绝对残差与输入基准**，不并入目标行的任何收益平均；OFF 带 `side_pml_margin_below_13m` 例外，单列【沿用 E8、E9 `negative_controls_merged_into_targets=false`、[事件表提案](2026-09-26_event_table_proposal.md) §5.2】。

**另外两类"当前不可计算"必须显式登记**：

1. **`isolated_event` 资格不成立**：事件表 §4.7 已据实给出多数窗重叠（±80 ns 半宽不能隔离相邻事件，C1 COV–D2 重叠 139.986 ns 等）⇒ v0.2 §3 要求的"窗内污染与数值误差在界限内"无独立证据 ⇒ 全部事件维持 `paired_contrast` / `numerically_unresolved`，窗内指标只作差分诊断，不得解释为单事件保真。
2. **跨维/跨档绝对幅值不可比**：E7（2D/3D 时域互相关 0.738/0.732、低频幅度趋势差 17 dB 量级，且含三类未排除混淆因素）、E5（`grid_convergence_certified=false`、跨档不得相减/合并）⇒ 运行器只在"同一族 × 同一网格档 × 同一角色"内出指标；跨族/跨档只报方向，**不得写入指标表**，也不得进入任何汇总平均。

### A.5 输出必须照录 `hard_limits`

每条记录与 `run_manifest` 都带一个 `hard_limits` 块，**逐字段照录**归档 `results.json` 的取值，运行器不得改写、不得省略、不得"优化为更宽松的值"【沿用 E9、[粗档结果](2026-09-26_batch2d_v1_results.md)"硬限制"节】：

`absolute_accuracy_claimed=false`、`clean_truth_generated=false`、`conclusions_scope`、`cross_family_differencing=false`、`cross_tier_differencing=false`、`family_bg_required=true`、`fdtd_solver_invoked=false`、`grid_convergence_certified=false`、`grid_tier`、`grid_tiers_merged=false`、`in_band_energy_ratio_is`、`negative_controls_merged_into_targets=false`、`physical_acceptance_threshold=null`、`physical_label_eligible=false`、`reference_state="numerically_unresolved"`、`training_eligible=false`、`training_labels_generated=false`。

运行器另附**自身层**的运行限制（【提案】，逐条对应上表）：`r_c_computed=false`、`isolated_event_granted=false`、`cross_family_metrics=false`、`gain_reference_absent=true`、`pre_gain_persisted=true`、`single_trace_gate_blocked`（当前为 true，记录被挡候选计数 27/27）。

### A.6 可行性判定与偏序标签

- **可行性**：使用 `configuration_labels`（`scripts/research_evaluation_contract.py:95`）。`limits` 中的 D 上限、A 上限、负控能量上限、参考污染界限、最小有效收益全部为 null ⇒ 每个 gate 判为 `undetermined`（:120–122）⇒ 状态为 `undetermined`【沿用 v0.2 §7"阈值为 null 时必须为 undetermined"】。**当前不存在任何 `feasible` 候选，也不存在 `infeasible`（失败需要明确违反，缺失不算失败，也不补零损失）。**
- **偏序**：只有全部约束通过且所有目标都有值的候选才进入比较（:128–129）。当前该集合为空 ⇒ **不生成任何优劣边、不生成 `unique_admissible`**；按 v0.2 §7 记为 `partial_only`（保留有效分项，不生成完整最佳编号）。
- **偏序规则（将来可计算时）**：两候选 a、b 只有各目标都满足 `U_a ≤ L_b` 且至少一项严格小于，才记"a 优于 b"（v0.2 §7 的保守区间支配规则，由不等式直接定义）。区间 `[L,U]` 来自独立敏感性分析，不是拟合出的置信区间；不得用候选好坏反向调整区间或阈值。
- **不可用 vs 质量零分**：门禁 2 导致的 27/27 拒绝一律记 `unavailable` 并保留原因（`require_time_real_2d_sample_trace_with_each_dimension_at_least_2`），**不记成质量零分，不回退为 identity 后当作"identity 是最优"**【沿用 v0.2 §7、算子契约 §2】。

### A.7 失败与异常记录要求

每条记录必须能回答"为什么这一格是空的"【提案，沿用算子契约 §8"尚未完成的接口"】：

- `failure_reason` 枚举：输入拒绝（`unknown_configuration` / `require_time_real_2d_*` / `require_finite_real_floating_input` / `invalid_gap_guard` / `mask_must_be_boolean_and_match_shape`）与本配置不可用（`svd_rank_must_be_less_than_minimum_dimension` / `svd_cutoff_gap_unresolved` / `nonidentity_requires_dense_valid_window` / `nonfinite_output` / `numeric_failure`）分开记录——前者是输入问题，后者是候选-输入组合问题。
- 每格另记：请求配置 id、实际执行顺序、是否回退、回退原因；窗掩码哈希与窗内样本数（空窗须报错 `empty_evaluation_window`）；
- 资源：墙钟（候选级，非全批）、峰值内存、dtype（`compute_dtype="float64"`）、`input_dtype`；
- 异常：非有限输出、溢出（`np.errstate(over="raise", ...)`）、SVD 不收敛，均记枚举而非吞掉；
- 停止理由：整批中止时记录是谁触发、在哪一例、是否已落盘已完成的记录（不丢已完成部分）。

## B. 基线与有限搜索参照（先于任何 ML）

### B.1 为什么必须先做

AGENTS.md"ML 与评价"第 1 条、[跨领域证据](2026-09-23_cross_domain_ml_evidence.md) §4 层级 A、[传统基线](2026-09-24_cycle03_traditional_baselines.md) §4 一致要求：先用固定流程、规则与有限搜索确认自适应存在收益，再训练选择器；**不为证明 ML 有用而削弱传统基线**。本文 §C 的选择器因此排在 §B 之后。

### B.2 五类比较对象与当前可用性

| 对象 | 定义【沿用传统基线 §4】 | 当前可用性 | 阻塞原因 |
|---|---|---|---|
| identity `I` | 固定不处理，保真与收益参照 | **不可用**（同 27 项，:70 门禁） | G2 |
| 最佳固定流程 `F` | 在开发组内比较全部合法候选，按预先约定的保护约束与指标选一个配置 | **不可用**（候选集为空） | G2 + G3 + G4 |
| 局部均值基线 `L` | 开发组选窗宽与强度；运行时从当前窗估计局部背景 | **不可用** | `local_mean_control` 要求窗宽 ≥3 奇数且 ≤ `n_traces`=1（:124）⇒ G2 |
| 输入谱规则 `R` | 由输入奇异谱决定是否删除及删几项；门槛在开发组校准 | **不可用**（奇异谱在单道上退化为单一值） | G2 |
| 候选内离线最优 `O` | 评估每个合法候选后用参考选取，仅作选择空间上界参照 | 不可用，且**不得**在候选集为空时以任何方式近似 | G2+G3+G4 |

即：**B 段的全部五类对象今晚同样一个都跑不了**，阻塞点与 A 段同源——都是 G2。

### B.3 有限合法流程搜索的设计（顺序有向）

- 动作空间 = 27 项候选（含 identity 与"跳过增益"，`end_gain=1`）【沿用算子契约 §3/§4】。
- 流程为**有向、有前置条件**的短链：`B（或跳过）→ G（或跳过）`；27 项已把唯一有实际差异的反向顺序（SVD × 非 identity 增益的 GB）显式纳入目录，其余反向顺序因 `(GX)P = G(XP)` 的交换性**不重复作为学习/搜索动作**【沿用 v1_scope §4、算子契约 §4】。
- 允许：identity、跳过、提前停止、低置信度回退到保守流程并记原因；
- 禁止：循环重复加增益、无意义重复滤波、缺失元数据时执行不成立的几何校正、在看到候选输出后挑窗或重画 ROI【沿用 AGENTS.md"处理与信号保真"、v0.2 §2】。
- 搜索范围**冻结于开发组**（`group_id` 见 §C.5），测试期不再搜索；搜索结果（一个固定配置或一个规则）作为 F/L/R 的冻结产物连同其开发证据一起落盘。
- 评价侧一律走**同一个运行器**（§A）出分，不另写一套打分代码，避免基线与 ML 用不同口径比较【提案】。

### B.4 "自适应有收益"的判定设计

判定必须**预先注册**，且不得用 ML 的输出反向定义收益【提案，沿用传统基线 §5、v1_scope §5/§7.2】：

| 判定项 | 需要的证据 | 反例/不得接受的情形 |
|---|---|---|
| 存在稳定差异 | 在开发组内，不同母模型族/档位上，最优候选**不相同**且差异大于参考与数值不确定性量级（与 E6 的 4.12% L2 / 3.88° 网格诱导变化、E7 的 2D/3D 时域差比较） | 差异与网格/维度诱导变化同量级 ⇒ 记 `undetermined`，不算收益 |
| 自适应可被取得 | 一个冻结的固定流程 F 或规则 R 在**未参与其选择的**验证组上，逐事件保真不劣于 identity 且在至少一类必保事件（弱对比 E12、深部 D20m、薄层 T0.25m、小尺度 W1m）上更优；且负控 `N_b` 未恶化、增益无截幅/伪响应 | 只在强事件或全图平均上改善、却删除弱事件 ⇒ 不算（v0.2 §4"不按事件能量加权掩盖弱层"） |
| 选择本身有附加值 | 在相同动作集合与相同划分下，M（选择器）相对 F/R 的配对差异在**未参与训练/选参的组**上成立，且分结构族报告，不是平均收益 | 只在训练同族/重叠窗/派生变体上改善 ⇒ 不算（同组必同源） |
| 成本可承受 | 选择开销 + 处理耗时不超过人工选参基线；失败率、回退率、不可评价率另报 | 收益来自把难例判为"不可评价"从而不报 ⇒ 不算 |

**不许为 ML 削弱基线**：F/L/R 与 M 必须获得同等调参机会、同等动作集合、同等开发组；若 L（局部均值）带来额外收益，**先扩充动作集合并重跑所有参照**，不能让 ML 独享更强算子后把收益全归于学习【沿用传统基线 §4 末】。若 F 足够好，如实保留该结论并停止加复杂度【沿用传统基线 §5 末、v1_scope §7.2 第 3 条】。

## C. 配置选择器原型（"网络雏形"，纯设计）

### C.1 任务定义

- 输入：`[sample, trace]` 的带符号实数 B-scan（`time_real`、`entire_predeclared_window`）+ 与测试集隔离的输入统计量/元数据；
- 输出：**一个完整合法配置** = 背景算子选择（含 identity/跳过）+ 参数（λ 或 k）+ 增益（含跳过）+ 有差异的顺序；以及低置信度时的回退与"需复核"标记；
- **不是**端到端波形生成，不是去噪/成像，不是滑坡识别【沿用 v1_scope §1/§7、AGENTS.md"ML 与评价"：ML 是决策方法，不借"学习型恢复"加入延期任务】；
- **先预测完整配置的表现，再选择**（独立选"最佳背景法"+"最佳增益法"后拼接可能得到不好的组合）【沿用跨领域证据 §4 末段】。

**G2 未解除时的形态（照实写）**：当前没有多道数据，选择器的输入 `[n_samples, 1]` 与候选的动作空间**同时**不成立——27 项候选全部不可用，动作空间为空，"选择"没有可选项。因此 G2 解除前，选择器只能是一个**未实例化的接口**：定义输入/输出 schema、特征白名单、奖励纪律与划分规则（本节），不产生模型、不产生训练数据、不产生任何分数。

### C.2 特征/状态设计（逐条合法性论证）

总原则：特征只能来自**输入本身**与**与测试集隔离的元信息/统计量**；标准化参数只在训练组估计，**不得每幅待评图各自归一化**【沿用跨领域证据 §4 末 bullet、v0.2 §4"不做逐候选峰值归一化"】。

| 候选特征 | 合法性 | 论证与限制 |
|---|---|---|
| `n_samples`、`n_traces`、`dt`、网格档、`dtype`、有限值比例 | 合法 | 纯输入形态；用于可用性判定与耗时建模 |
| 奇异谱比值 `σ_k/σ_1`（前若干项）、截断间隙 `d_k=(σ_k−σ_{k+1})/σ_1`、数值秩计数 | 合法（且是 R 规则的同一输入） | 只看当前输入，不看 clean 真值/测试 ROI/处理后收益【沿用传统基线 §4-R】；但需先满足 `min(M,N)≥2`，单道下无定义 |
| 输入绝对幅度尺度、动态范围、样本轴能量衰减趋势（分段能量比） | 合法 | 增益风险的相关输入；**不得**把"增益后亮度上升"写成收益（v0.2 §6.1、E2/E4） |
| 输入符号/极性分布、零值比例、饱和/截幅迹象 | 合法 | 用于失败风险与回退 |
| 上游处理状态、已有增益状态、输入来源与哈希 | 合法（元数据） | 防止重复处理【沿用 AGENTS.md"处理与信号保真"】 |
| **冻结事件窗的位置/掩码** | **不作为特征** | 事件窗属评价侧定义与参考元数据；v0.2 §7 明确"参考元数据不是模型的输入特权"；把窗给模型等于把评价答案的一部分喂进去 |
| **任何候选输出或处理后统计量** | **禁止** | 等于用待处理结果选 ROI/调参（AGENTS.md"ML 与评价"） |
| **配对差分 `TGT−BG` 或 `ΔF`** | **禁止** | 是评价参考（v0.2 §8 只作诊断），且跨族差分被 E9 禁止；不得当输入特征 |
| **带内能量比 / 包络峰到时 / 谱峰** | **禁止** | E9 明确其"not detectability, not SNR, not a physical threshold"；且这些量本身由处理结果导出 |
| **母模型族 / `group_id` 标签** | **不作为特征** | 部署时不可得，且与按 `group_id` 的划分耦合成泄漏；同类同组规则见 §C.5 |
| **逐图归一化后的"SNR"类量** | **禁止** | 实测无 clean 真值时不得编造 SNR（v1_scope §5）；每图单独归一化后宣称信噪比提升属明令禁止（AGENTS.md"ML 与评价"） |

缺失特征处理：不可得的特征记 null 并给原因，不用常数填充成"信息"。

### C.3 奖励/指标设计（正向与负向，逐条注明来源）

**无默认加权总分**【沿用 v0.2 §1 第 3 条、§7；跨领域证据 §4】。以下分项**分表报告**，排序用 §A.6 的区间偏序，不加权求和。

正向（保真/保留）：

| # | 项 | 来源 |

| +1 | 逐必保事件的波形误差 `D_e`（不重缩放、不重对齐） | v0.2 §4 |
| +2 | 幅度保护 `A_e=|a_e−1|`（与 `D` 分开报，`D²=(a−1)²+H²` 不是三份独立证据） | v0.2 §4 |
| +3 | 弱事件单独保留：弱对比 E12-S0.005、深部 D20m、薄层 T0.25m、小尺度 W1m/W2m 逐项单列，任一项不通过即该候选不可接受 | E2/E3 + v0.2 §4"按事件约束" |
| +4 | 覆盖层底界面（共同层）绝对检查不被配对差分替代 | v0.2 §8、E1 |
| +5 | 形状/极性诊断 `H_e`、`ρ_e`（仅诊断，不当保真评分） | v0.2 §4 |

| # | 项 | 来源 |

| −1 | 负控残差 `N_b`（NC 恒零窗、OFF on-path 窗、BG-NEG 窗），绝对能量 + 输入基准，分母为零不伪造比值 | v0.2 §4、E1/E8、事件表 §5 |
| −2 | 增益风险：负控窗放大倍数、最大增益、曲线、截幅/溢出、数值失败 | v0.2 §6.1/§6.2、E4 |

**若将来冻结了合法单目标效用 U 与同一可行集合 A**，才可报告 `regret_i = max_{a∈A_i} U_i(a) − U_i(â_i)`【沿用传统基线 §5】；这是本项目定义的选择误差指标提案，不是已验证的雷达质量指标。缺乏合法参考的项不补零。

### C.4 训练标签纪律

- 标签只来自**真实算子运行的效果**：可用性 + 分项效果 + 可信的两两偏序；允许并列与 `multiple_admissible`，证据充分时才产生唯一编号【沿用 v0.2 §7、算子契约 §5】。
- **不许学"专家选了哪个编号"**：单纯预测算法编号的准确率不足以证明输出改善【沿用算子契约 §5、传统基线 §5】。
- **无 clean 真值**：`clean_truth_generated=false`；族内 BG 差分属 `paired_contrast`，只做配对变化诊断，不得当绝对参考（E1、v0.2 §3/§8）。
- **`reference_state=numerically_unresolved` 期间不得生成训练标签**：`training_eligible=false`、`training_labels_generated=false`、`physical_label_eligible=false`【依据 E9】。参考升级必须走 v0.2 §9 的四步校准（先校准参考 → 损伤阶梯 → 任务容差 → 敏感性检查），且阈值为 null 时可行性一律 `undetermined`。
- 数值秩底限、截断间隙 `gap_rtol=1e-8`、数组夹具中的 0.1 等**都是数值/夹具约定，不是物理阈值，不得写入训练目标**【沿用算子契约 §3、v0.2 §9 末】。

### C.5 数据划分

- 划分单位只能是 **`group_id`（母模型族，如 `B2D-C3m`）**；同一母模型的所有变体（深度/尺寸/电性档、网格档、负控、派生窗）**必须同组**【沿用规格书 §4.2、事件表 §4.2"事件窗不是分组单位"、AGENTS.md"先按地质母模型/完整测线/测区划分，再裁窗"】。
- 开发组用于：动作库、阈值校准（G4）、规则门槛、选择器超参与特征标准化；**测试集不得参与奖励、阈值、算子库或超参选择**【沿用 v0.2 §9 第 5 步、AGENTS.md"ML 与评价"】。
- 跨母模型族的样本量当前**不足以支撑任何泛化声明**：粗档 4 个族 × 深度/尺寸/电性档共 29 例（20 个目标算例），且都是单道；这是"机制证据"，不是训练集【依据 E5、START_HERE 2026-09-26】。
- 与营山/雅安相关的几何会泄漏实测测试标签 ⇒ 若启用实测须单列场地适配，不得同时称盲测泛化【沿用 AGENTS.md、G7】。

### C.6 模型体量与"网络雏形"形态（示意，不实现）

论证（【沿用】跨领域证据 §4 的层级表 A–E，该表是本项目设计建议而非论文已验证架构；本文未通读其引用原文，阅读范围见 §7）：

1. **A（固定流程/规则/有限搜索）**先给出"自动配置能否带来收益"的证据，无需神经网络；
2. **B（轻量 ML）**：B-scan 统计特征 + 线性/树/小 MLP，预测完整合法配置的表现（回归或成对比较），再做受约束选择——可解释、便于在小数据上检查特征与失败模式；
3. **C（小型 2D CNN + 统计汇聚 + 配置评分头）**只在 **B 无法表达有用差异**、且**顺序/多步确有实测差异**时才评估（当前 27 项目录里只有 SVD × 非 identity 增益的 GB 顺序有实际差异，其余因交换性等价）【沿用算子契约 §4、v1_scope §4】；
4. **D（低秩/稀疏展开网络）、E（大模型/GAN/任意长度 RL）**：首版不研究——去噪/成像在首版范围外，且没有证据表明当前短流程需要这些复杂度【沿用 v1_scope §1、跨领域证据 §4】。

示意（非代码，不含实现）：

```
features = f(input_X, metadata)              # 只允许 §C.2 白名单；标准化参数来自训练组
score[c] = model(features, candidate_desc)   # 为每个合法候选 c 预测 §C.3 的分项目标（不含加权总分）
choice   = argmax_over_admissible(score)     # 受约束选择：不可用候选被排除；低置信度 -> 回退 identity 并标记需复核
output   = apply_configuration(input_X, choice)   # 真实算子执行，不是网络生成波形
record   = run_eval(...)                     # 与基线共用 §A 的运行器出分
```

- 参数头按所选算法激活（λ、k、end_gain 各有合法范围），无效参数不参与损失【沿用跨领域证据 §4】；
- 不同但近似等效的参数不得被强迫回归成唯一标签；分类正确率或参数 MSE 不是最终效果【沿用跨领域证据 §4、算子契约 §5】；
- **今晚不写实现代码**（§D.3、§E）。

## E. 明确不做清单

1. **不做端到端波形生成**：选择器只输出配置，波形由真实算子产出；不训练"学习型恢复"网络。

4. **不让测试集参与奖励/阈值/算子库/超参**：划分以 `group_id` 为单位，同母模型/派生/网格档/负控同组。
5. **不做道方向评价**：G2 未解除，事件窗只在样本轴定义；不声称已评价 `mean`/`svd` 的道方向行为。
6. **不放宽 `min(shape)≥2` 门禁为单道"探路"**：单道下 `mean` 退化为整体缩放、`svd` 全部非法；不放宽、不为单道新增替代算子。
7. **不计算 `R_c`**：本批无合法纯干扰窗；不填 0、不以任何窗代替。
8. **不做 3D / 实测外推**：G1 未执行、G6/G7 未解除；结论限定于 batch2d_v1 BASE/FINE2 场景族与所分析网格。
9. **不跨族、不跨档差分或合并**：沿用 `cross_family_differencing=false`、`cross_tier_differencing=false`、`grid_tiers_merged=false`；负控不并入目标行。
10. **不生成物理阈值**：D/A 上限、负控能量上限、污染界限、最小有效收益维持 null；数组夹具值不写入验收配置。

12. **不声称自适应收益或选择器优越性**：S4/S5 的证据不存在。
