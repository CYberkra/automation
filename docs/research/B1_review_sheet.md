## 一句话定义

> 对每一条输入 B-scan，由轻量策略网络（约 1–2M 参数）逐阶段从算子目录 v0.2 的 30 项中选"算子 + 离散参数档"（或 STOP），使**冻结契约奖励**最大化——"逐输入自适应选型"取代现行"每场景族全局唯一选型"。

## 冻结后将锁定什么（冻结即不可再改，只能升版）

| 锁定项 | 内容 |
|---|---|
| MDP 结构 | 状态=当前B-scan+EC通道（阶段计数/算子历史）；动作=30项目录×离散档∪{STOP}；T_max=4；γ=1.0 |
| 动作空间来源 | 仅由冻结目录枚举生成；identity 锚恒在；不可行动作按算子契约掩码 |
| 奖励定义 | R = R_contract − λc·cost；R_contract 只由容差契约 v0.2 + 权重契约 v0.2 计算；硬约束违规钳制到 identity 锚之下 |
| 参数纪律 | 只用目录已标定的离散档，**永不引入连续参数头** |
| 数据纪律 | 训练只用开发族 {C1,C3}；测试族 {C5,C8} 零接触至一次性评价 |
| Goodhart 护栏 | 5 条（契约参数禁倒推、阈值只随机制阶梯更新、锚逐 episode 在线校准、坍缩熵报警、测试族一次用完） |
| 扩展规范 | §3.5 新族入场五步（目录升版→标定→scope_limits→动作空间扩列→求值规则覆盖） |

## 冻结后仍可调的（不锁定）

- λc（推理期旋钮，高精度/低时延切换无需重训）
- 网络细节超参（层宽、学习率等，走训练配置契约另行冻结）
- T_max、目录内容（均可按升版流程演进，旧权重续用不重构）
- 训练规范候选增强项（负载均衡损失、分叉报警等，C3 阶段再定）

## 冻结 ≠ 启动训练

冻结 B1 只锁定"任务是什么"。启动训练还需：A1 G4 签认（总开关）＋ A2 S1/S3 容差重校准 ＋ B2/B3 采样设计与仿真预算 ＋ B4 奖励链验收 ＋ C1 PyTorch 环境锁定。**本次签认不产生任何仿真或训练动作。**

## 验收标准（冻结后评价训练成果的尺子）

测试族一次性评价中同时满足：① 显著优于 identity 基线；② 不低于现行协议首跑全局赢家（S2X/S2TZX→B9、C3mX→B7）同族奖励；③ 选择频率无坍缩报警。任一不满足记 undetermined，不判负、不迭代测试族。

## 依据摘要（为什么这么设计）

- 逐输入贪心选型：AdaptiveISP（NeurIPS 2024）实测 1.2 ms/阶段、多数输入 2–3 阶段饱和；
- 离散档 + RL 分工：ML-ReinBo 与认知雷达波形目录同构；
- 动作空间扩列续训：Action-Adaptive Continual Learning（2025）文献背书；
- 契约奖励替代任务代理：规避 Goodhart 过优化（RLHF 文献中任务代理是最高危形态）；
- 详见已注册的两份调研报告（registry 键 `crossdomain_metrics_survey_2026_10_01`、`pipeline_extensibility_survey_2026_10_01`）。
