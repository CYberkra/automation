# 理想平界面 GPU 对照 V4-INTERFACE-01

用户已授权自行设计和 GPU 仿真，本轮继续落实为一个算例，无自动重试或扫描。不是现场地层模型。

- 输入：`configs/research/airborne_interface_v1/M01_T800.in`，hash 由当前 gate 锁定。
- 24×24×24 m，5 cm 网格，480³ 单元；HORIPML 六面20格。地面 z=4 m，下方 εr=9、σ=0、μr=1 的假设均匀半空间延伸到边界；不含粘土覆盖层或20 m深目标。
- Tx=(12,11.3,19)，Rx=(12,12.6,19) m；X向理想电流元、Ex接收是假设极化。高度15 m、横航向基线1.3 m。官方 impulse 源，官方 SFCW 501点20–170 MHz/0.3 MHz。
- 800 ns 记录。直达几何时间约4.336 ns，镜面路径几何时间约100.163 ns；不是离散脉冲峰值的精确预测。
- εr=9 时170 MHz介质波长约0.588 m，每波长11.76格：仅过常见10格设计起点，不是网格收敛。空气中20 MHz第一菲涅耳区半径粗估10.60 m，已接近侧面PML内界面约11 m；横域限制必须列入结论。
- 4 m地下几何厚度包含1 m底部PML，不能用于20 m探测结论。若20 m地下均为εr9，近垂直来回传播粗估约500 ns（空气100 ns+地下400 ns）；因此本轮400 ns后渐消绝不能沿用到那个目标模型。
- CUDA0/double，沿用已核验V4环境和有界Windows Job：30分钟、32 GiB host committed memory、启动空闲RAM32 GiB/VRAM12 GiB、输出1 GiB；1次、0重试、禁止CPU回退。5cm同尺寸空气实跑约21 GiB host/10 GiB设备；本轮非色散材料预计接近，仍以实际监控与硬停止为准。

分析预声明：与已完成T800全空气逐样本相减，不再求解空气；核对相同dt、源、长度及几何。官方直接频率变换分别处理两者后相减，并核对线性一致性。主展示800 ns窗/约400 ns尾渐消（开始约400 ns，晚于地表路径）；另留无渐消、200 ns渐消敏感性结果。保存原始HDF5、日志、身份和执行决策、每频点复数数据、原始差分曲线与报告。早于最短反射路径的差异和100 ns附近响应仅作因果/机制诊断，不设置事后拟合阈值，也不以空气解析解评价地下总响应。
