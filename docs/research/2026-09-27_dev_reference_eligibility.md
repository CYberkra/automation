# 开发组参考资格审查（C1/C3）

范围限于开发组 C1/C3 的 MT 与 CO 既有事件表、评价记录/manifest、参考不确定性预算及协议/源码。仅筛选共享记录中的开发侧行，未重新评价 C5/C8，未加载波形数组或重跑评价。逐槽资格清单及所用文件 SHA-256 见[机器表](../../artifacts/research_checks/2026-09-27_dev_reference_eligibility/results.json)。

从已有评价记录按 identity 候选去重得到 69 个 event×geometry×case 槽：MT 41（38 实际运行、3 缺该多道案例），CO 28（6 运行、22 缺该常偏移案例）。按族为：MT/C1 11（9/2）、MT/C3 30（29/1）、CO/C1 9（0/9）、CO/C3 19（6/13）；括号内为运行/缺案例。事件表中 COV 按族展开到多个实际 case，清单保留了每一个 case 与唯一记录键；缺案例行没有参考数组，不能标为可评价。身份行中所有可运行记录的 waveform metric 均因 `reference_state=numerically_unresolved` 且 `paired_contrast` 门禁而不可用。

| 对象/角色 | 当前类型/状态与已有来源 | 允许用途 | 资格边界 |
|---|---|---|---|
| 完整 F1 场景窗口 `x_window` | 评价器从单个 case H5 截取整窗；事件表虽然为目标/COV 标 `paired_contrast`，但评价调用实际把 `x_window` 作为 waveform metric 的 reference。状态仍为 `numerically_unresolved`。 | 输入/道集及已记录的数值诊断；本评价器的波形指标仍不可用。 | 这不是独立干净响应 `S`；不能把 D ladder 的 `identity(X)` 当作目标真值。也不能从 event-table 的类型字段推断已物化 `F1−F0`。 |
| 目标开关差 `ΔF=F1−F0` | C1/C3 同族 BG/target 配对可用于变化诊断；既有报告记录目标差分能量/背景能量比和目标方向性。 | 配对变化量比较，例如协议 v0.2 §8 的 `ΔZ` 对 `ΔF`；负控恒零可核对同族同格同源配对的确定性。 | 差分只说明改变了什么，不等于 F1 中完整干净地下响应；实际 MT/CO evaluator 未把 `ΔF` 传给 waveform metric。COV 是应用到多个 case 的窗角色，没有对应的 cover 开关对，不能仅凭其 `paired_contrast` 元数据认定存在 COV 差分参考。 |
| `nc_zero` / `bg_absent` / `off_path` 指定窗口 | 事件表把这些行标作 `negative_control`；其中只有实际有 case 的槽能作数值诊断。全局 `R_c` 明确为 `not_computed_no_legitimate_pure_clutter_window`。 | 指定角色/窗口的绝对残差或分母非零时的能量比。 | 局部目标缺席不等于整幅场景无地质响应；事件行即使有 N_b 数值，也不会因此成为纯负控。不得并入目标质量分或使用零参考 NRMSE。 |
| 独立绝对事件参考 | C1/C3 没有 `isolated_event` 授权；没有通过核验的 `complete_clean` 目标事件数组。 | 无已获准的绝对事件保真用途。 | 因此 69 槽中绝对事件保真资格均为 false；物理验收阈值仍为 null，训练资格不开放。 |

协议 §3.1 允许把 `ΔF` 升格为事件绝对近似参考前，要求四项证据同时成立。本次只做证据盘点，不作升级：

| 必要条件 | 现有证据 | 判定 |
|---|---|---|
| 事件解释成立 | 冻结事件窗由自计算双程时间及固定 ±80 ns 规则定义，候选前冻结；构造模型的目标材料与几何已知。事件时间定位有依据，但未证明窗内混合场只对应一个可独立归因的物理事件。 | 对建模事件定位有支持；绝对事件归因未建立。 |
| 窗内 F0 相对 Δ 足够小 | 已有报告中的 `Δ/BG` 带内能量比和 NC 同源配对恒零证明差分构造可复现、响应量级可描述；这些量不是预注册的时域 `||M F0||/||M Δ||` 污染界限。污染界限在协议中仍为 null。 | 未建立。变化/背景比值存在，不等于 F0 污染足够小。 |
| Δ 不含需另分的显著混叠变化 | 当前 Δ 是目标开关引起的全场变化；现有 NC 恒零只排除该空对照的伪差分，不能把目标插入后的相互作用与其他重叠电磁响应分离。 | 未建立。 |
| 网格/PML/源采样敏感性低于预设误差预算 | C1/C3 的 BASE↔FINE2 家族锚点证据给出差分谱形状相关 0.999549/0.999418、峰时差 −17.24/−15.67 ns；跨档幅度比只作方向量。无 Richardson 外推/网格收敛认证，也没有相对于冻结污染预算的源/PML敏感性通过界限。 | 有方向性格距敏感性证据；误差上界及通过条件未建立。 |

需要特别避免三种等同：事件表声明的 `paired_contrast` ≠ evaluator 实际传入的 Δ 数组；谱域变化/背景能量比 ≠ 窗内 F0 污染比；有非零数值 ≠ 物理参考资格。参考预算的相关系数等来自形状类频谱比较，不能称为各事件窗 time-real NRMSE 认证。缺失行属于案例未提供，不是候选或物理算法失败。

下一步最小证据补足建议：优先仅用已有 C3 CO BG/TGT 常偏移配对及冻结窗口，做只读 `||M F0||/||M Δ||` 污染诊断，并分别列出 event-window 变化中仍无法归因的重叠项；这不需要新 FDTD。即使该比值小，也只补充协议四条件中的一项，不能自动授予 `complete_clean` 或 `isolated_event`。随后再决定是否需要独立的源/边界/网格敏感性预算。本文不批准任何仿真或阈值变更。

验收：Luna负责证据梳理和报告，主agent独立生成规范机器表，并与Luna草表逐一比对69个唯一键及case、类型、状态、可用性、负控资格，全部一致；全部来源SHA已复核。草表说明字段存在编码问题，规范表采用无乱码字段，冗余未提交草表在核对后移除并保留其SHA。见[验收记录](../../artifacts/research_checks/2026-09-27_dev_reference_eligibility/root_acceptance.json)。44个有输入槽均无可用波形保真指标；13个角色负控槽的能量比基准非零。
