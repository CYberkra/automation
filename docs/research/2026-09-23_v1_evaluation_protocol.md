# 首版评价协议草案：背景抑制、增益及自动配置

日期：2026-09-23。状态：定义与实验建议；尚未冻结验收阈值，未运行正式仿真或训练。范围只包含用户确认的两类处理。

当前应用范围已调整为现有非显性滑坡项目的场景特化，泛用性延期，见[最新范围决定](2026-09-23_v1_scope.md#7-最新决定先完成非显性滑坡场景特化)。本协议的保真、干扰、增益与配置评价原则保留；具体 ROI、结构类别和误差容限围绕本项目定义。通用模型对照、多模式切换与跨测区/系统泛化不作为首版验收要求；本场景内独立验证及无目标对照仍保留。

文献编号 E01–E13 均对应[跨领域研究证据表](2026-09-23_cross_domain_ml_evidence.md#2-原始来源与实际阅读范围)。下文区分论文采用的指标、数学性质，以及本项目提出的评价组合；后者不称为行业标准。

最新数据安排：当前只做仿真研究与评价设计，现有测线留到后期，不参与训练、调参、奖励或 ROI 制定；本文实测/钻孔条款留作后期规则。新增 gprMax 原文依据、MRE/IF 定义差异及两层仿真参考设计见[第三轮研究](2026-09-23_gprmax_simulation_first_evidence.md)。当前不默认全波仿真都有完整 clean，也不以无损介质响应作为增益必能恢复的真值。

## 1. 三个问题分开回答

1. **背景抑制：**指定干扰减少多少，真实地下结构损失多少？
2. **增益：**在控制噪声放大和幅度失真的条件下，是否实现了约定的补偿或可辨性目标？
3. **自动配置：**相对独立选出的固定流程，输出是否更可靠，并节省多少人工和计算时间？

禁止用一个混合分数掩盖某种结构被删除；暂不指定任意权重把所有指标相加。先报告各项与失败类型，再在验证集上确定约束或权重。

## 2. 评价对象与真值

记输入为 `X ∈ R^(时间样本×道数)`，背景处理结果为 `Z = Bθ(X)`，增益后为 `Y = Gφ(Z)`。若采用乘性增益，保存实际使用的正值矩阵或曲线 `g`，满足 `Y = g ⊙ Z`，并记录是否存在截幅等额外操作。

### 2.1 不同来源的标签不能互换

| 数据/标签 | 可以回答 | 不能据此回答 |
|---|---|---|
| 可控数值混合 `X = S + C + N`，各成分已知 | 算法与指标的基本行为、已知信号损伤 | 电磁仿真真实性及 UAV 实测泛化。该分解是此类实验的构造条件。 |
| gprMax 正演及明确的场景对比 | 到时、结构响应、指定变化带来的波形差异 | 自动获得唯一的“无杂波完整地层真值”。改变介质/界面后，散射与传播也会改变。 |
| 营山/雅安实测数值 B-scan | 固定 ROI 的 proxy、人工盲评、处理稳定性 | 未测得的 clean 波形、真实 SNR、地下全部结构正确与否。 |
| 钻孔与解释约束 | 与指定界面及不确定性相容与否 | 逐像素 clean、所有水平反射均正确/均是杂波。 |

`S` 必须包含本实验要保留的层状界面、局部目标及弱反射。不能将只保留管线而删除地层的标签原样迁入本项目。此差别在 CR-Net 多层案例中已有明确实例 [E06]。

所有 ROI、时间窗、目标类别、幅度参考和无目标区，在查看候选输出前确定；记录由仿真标签、输入或独立标注中的哪一种产生。不得挑选处理后最好看的 ROI。

### 2.2 通用比较条件

- 使用带符号数值波形。误差在相同轴、相同单位、同一幅度参考下计算，不对每个候选单独拉伸或峰值归一化。
- 图像类指标是辅助。PSNR/SSIM 明确 `data_range`、窗口与归一化；实数雷达幅值不能自动套 8 位图像的 255 [E13]。
- 先分母模型/完整测线/测区，再裁窗与生成变体。同线功率复测、重叠窗口、同母模型派生项保持同组。
- 超参数、指标权重、增益上限、ROI 规则和候选算法选择全部属于模型选择；不得根据最终测试集反复调整 [E12]。
- 分层状、局部、弱目标、混合及无目标场景报告；统计不把同线大量像素当作独立样本。分组汇总及按组估计不确定性是本项目的实验设计建议。

## 3. 背景抑制指标

### 3.1 已知参考时的主要指标

| 维度 | 本项目拟用定义 | 适用条件与防误用 |
|---|---|---|
| 波形保真 | `NRMSE = ‖Z−S‖F / ‖S‖F`；另报 MAE | 整幅及保护区域分别报告。`S=0` 时 NRMSE 不适用，改报绝对残差。定义参考 [E13]。 |
| 结构幅度 | 保护窗内 `a = <Z,S>/<S,S>`，并报残差 `‖Z−aS‖/‖S‖` | 项目自定诊断；`a` 应接近 1。拟合系数只用来暴露衰减/放大，不用它修正后取代原始误差。 |
| 到时与极性 | 预定事件窗的相关峰延迟、零延迟相关、极性/符号一致性 | 相关性必须与幅度误差同时看；零输出和低能量窗标为不可定义。先用样本单位，时间轴核实后再用 ns。 |
| 干扰降低 | 已知纯干扰 ROI：`R_C = 10 log10(E_X / E_Z)`，`E` 为同一 ROI 的平均平方幅度 | 项目自定残余能量诊断；仅当该区没有需保留信号才可归因于干扰。混合区不能由输出能量减少推断目标未受损。 |
| 文献可比性 | `PSNR = 10 log10(L²/MSE)`，SSIM/MS-SSIM 可选 | `L` 与尺度固定并声明；相同真值和尺度下 PSNR 与 MSE 本质上重复，不计作两项独立成功证据 [E06、E13]。 |

所有比值声明零分母、空窗和非有限值规则；使用数值稳定项时记录其单位与大小，不能通过稳定项把无信号样本变成极高分。

干扰抑制与结构保留必须同时成立。把全部数据置零可以极大降低背景能量，却必须在保真评价中失败。对非线性/自适应算法，不能假设 `B(S+C)=B(S)+B(C)`；单独处理成分只是一项诊断，不等于混合输入中的真实分离效果。

### 3.2 无 clean 的实测指标

CR-Net 使用目标/杂波最大幅度比及其改善因子 [E06，第 8 页式 13–14]。为复现该类比较，可定义：

`SCR_amp = max(|Z| in R_target) / max(|Z| in R_background)`

`IF_amp = 20 log10(SCR_amp_after / SCR_amp_before)`。

本项目须称其为**指定 ROI 的峰值对比 proxy**，明确这里以绝对幅值实现。它对尖峰、背景窗选择及不同深度的增益敏感，不是已知信号/噪声分量的真实 SNR。幅度比用 `20 log10`，功率/能量比用 `10 log10`，不得混用。

可增加 RMS 比作为敏感性分析，但注明它是修改后的定义，不能继续沿用论文数值口径。实测还须看被去除分量、原有反射的连续位置和负控；未确认区域中的新亮点只叫可疑事件，不能直接宣布为假阳性或发现新目标。

## 4. 增益评价：补偿、可分性和代价

### 4.1 先明确增益做不到什么

对同一样本的信号 `s` 和噪声 `n`，共同施加非零增益 `g` 后，

`(gs)²/(gn)² = s²/n²`。

若同一 ROI 里的增益为常数，整体能量 SNR 也不变。随时间变化的增益可能改变整幅加权统计，因为不同位置权重变了，不能因此声称在原始信息中获得了新的探测深度。这是代数性质，不依赖某篇论文的性能结论。

所以增益的成功可以是实现一个有根据的幅度补偿目标，或减少人工调节成本；**不要求每次加增益都提升同深度局部 SNR/gCNR**。否则评价会错误地惩罚正常增益，或奖励伪造结构。

### 4.2 两种不同的补偿目标

**有已知衰减模型的受控实验。** 构造 `Z(t,x)=a(t)S0(t,x)+N(t,x)`，其中 `a(t)>0` 已知，评价 `Y` 相对 `S0` 的误差、相对幅度及噪声放大；需要时比较预测曲线与 `1/a(t)`。这是可验证的简化模型实验，不代表实际 GPR 中所有传播、色散和几何扩散都可用一个标量函数逆转。恢复信号与限制噪声可能冲突，理想逆曲线只是一个参照。

**未知物理衰减的实测。** 时间幂、指数或 AGC 首先称经验增益。不能把使各深度 RMS 相同的曲线当作真实吸收补偿，因为地下本身可能有弱反射层和无目标区域。未经标定，不宣称恢复了反射系数或介质衰减参数。

### 4.3 增益的最小指标组

| 维度 | 评价内容 | 依据与边界 |
|---|---|---|
| 已知补偿目标 | 与 `S0` 的 NRMSE、指定事件的相对幅度误差 | 受控实验定义；没有该真值的实测不计算这类误差。 |
| 可分性 | 预定同深度/窄时间窗的目标与背景分布，试验 gCNR | 来自超声 [E08–E09]；须先验证 GPR 适用性，不作为首轮唯一奖励。 |
| 响应形态 | 到时、极性、波形误差；对孤立响应可观察宽度 | TGC-Net 摘要列出 FWHM [E08]，但未取得其实现。未成像 B-scan 的事件宽度不自动等于成像分辨率；不得追求越窄越好。 |
| 噪声/杂波放大 | 在预定负控窗报告 `10 log10(mean(Y²)/mean(Z²))`、高分位幅度及最大增益 | 本项目风险指标；已知无目标时可解释为干扰放大，否则只叫该窗总能量变化。 |
| 数值及保幅代价 | 增益曲线、上限触发比例、截幅比例、非有限值、相邻道幅度关系变化 | 项目算子契约；阈值从允许的动态范围及验证数据确定。 |
| 使用价值 | 固定显示条件下的盲评一致性、保留事件可辨程度、人工调节时间 | 后续实测实验建议；随机化展示顺序并记录分歧，不以好看替代正确。 |

正值乘性增益且没有截幅时，可检查 `Y/g ≈ Z`。这只是记录与实现的一致性检查，不能证明所选增益好；错误的大增益同样可能通过。

### 4.4 gCNR 的用途与限制

来自 [E09] 的定义为：

`gCNR = 1 − ∫ min(p_target(u), p_background(u)) du`。

本项目可在预定 ROI 上，用明确的幅度统计量（例如 `|Z|`，不得默默混换为包络/功率）估计两种分布。使用相同的一一映射时，理论上的分布重叠不变；同一常数增益不应被计作新的可分性。不同位置施加不同增益不满足这一共同映射条件。

这是候选迁移指标，尚非 GPR 验收标准。它不包含目标几何和事件位置，有限样本、直方图分箱/密度估计也会影响结果；必须固定估计规则、检查常数增益反例，并与结构指标联合使用。均衡先验下理想像素分类正确率为 `(1+gCNR)/2`，不能直接把 gCNR 当作完整地下目标的检测率。

## 5. 自动配置与网络的评价

沿用逐实例算法选择 [E03]，先比较以下同输入、同算子库、同执行环境的方案：

1. 不处理；仅背景；仅增益；两类组合。
2. 在训练/验证数据上确定的最佳固定完整配置。
3. 简单规则、有限在线搜索、轻量 ML、候选小 CNN。
4. 预先冻结候选集合内的逐实例最佳结果，作为事后诊断上界，单独报告搜索代价。

第 4 项若使用测试真值，只能在最终评价时计算；它不是可部署方法，结果不能再用于调权重、改库或训练。有限集合中最好也不等于全局最优。

选择器首先输出各候选的保真、干扰、增益风险及耗时预测。建议先用保护约束排除损伤明显的配置，再比较收益与成本；允许跳过。约束边界由验证集与可接受任务误差确定，当前不填无依据数字。

只有评价目标冻结后，才计算选择损失。例如令预先定义的越大越好效用为 `U`：

`regret_i = max(c ∈ C) U_i(c) − U_i(c_selected)`。

这一定义是本项目对算法选择问题的形式化，不声称某篇 GPR 文献已验证该效用。若尚不适合标量化，就报告各维度差距与受支配比例；不能用临时凑出的总分生成训练标签。

还需报告最差类别退化、回退比例、失败率、选择耗时、算子耗时、峰值内存及人工操作时间。专家选择一致率、分类准确率、参数回归误差只是辅助；不同配置可能等效，与专家一致也可能一起误删结构 [E11 的指标只提供参照]。

## 6. 评价本身的最小反例检查

这些是建议先建立的契约例子，不是已经完成的物理实验：

| 反例 | 评价应呈现什么 |
|---|---|
| 不处理已知干净信号 | 波形误差为零；不能因未降低背景就错误判失败。 |
| 全部置零 | 可降低背景能量，但保护目标误差/幅度失败。 |
| 全体乘以很大常数 | 同 ROI 的真实 SNR 不变；误差与放大代价应识别变化。 |
| 删除横向连续弱地层 | 即便局部目标更醒目，地层保留项也必须失败。 |
| 整体反号或错移一个样本 | 不能被绝对值图或较高 SSIM 单独判定为完全保真。 |
| 只含干扰、无深部目标 | 不应凭增益制造可接受的目标；独立负控约束必须起作用。 |
| 两个数学上等效的处理顺序 | 评价和配置标签应等效，避免虚假的顺序学习收益。 |

## 7. 冻结前仍需确定

- 首批输入 B-scan 的前序背景/增益状态、幅度尺度和可用时间参考。
- 保留信号的受控构造，以及 gprMax 场景中可以可靠评价的结构/事件；不假设已有完整 clean。
- 参数范围、保护误差上限、最大增益、负控窗与统计单位。
- gCNR 在振荡实数波形上的估计稳定性；若不合适，保留其他指标，不强行采用。
- 何种收益值得使用 ML：相对固定配置的效果、人工时间和运行成本，均须有实测或实验依据。

上述未定项通过小样例与开发/验证数据逐步确定。对基础公式的数学/代码检查、gprMax 物理检查、独立实测检查分开记载；任何一层通过均不替代下一层。
