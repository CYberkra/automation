# 契约化自适应处理管线（Contractual Adaptive-ISP）任务定义提案 v0.1（草案，未冻结）

日期：2026-10-01
性质：**纯设计文档（B1 任务定义提案）**。不新建/修改任何冻结契约、目录、阈值或脚本；不运行仿真、不训练；G4 维持未解除。冻结需用户在过目后明确确认。
背景：用户于 2026-10-01 指示吸收 AdaptiveISP（NeurIPS 2024, arXiv:2410.22939）思路。本文档把该思路改造为符合本项目审计纪律的任务定义，作为后续冻结的底稿。

## 1. 任务定义（一句话）

**对每一条输入道集/B-scan，由轻量策略网络逐阶段选择处理算子及其参数档，使冻结契约奖励最大化**——即"逐输入自适应选型"，取代现行"每场景族全局唯一选型"（协议首跑 S2X/S2TZX→B9、C3mX→B7 的粒度）。

## 2. MDP 形式化

| 要素 | 定义 | 说明 |
|---|---|---|
| 状态 $s_t$ | 第 $t$ 阶段处理后的道集特征表示 + 阶段计数 $t$ + 已用算子 one-hot 历史 | 网络实际输入为当前 B-scan 图像 + 额外通道（EC），沿用 AdaptiveISP 的 EC 设计 |
| 动作 $a_t$ | （算子 ID, 参数档）或 STOP | 动作空间 = 算子目录 v0.2 的 30 项 × 各自参数档 ∪ {STOP}；identity（B0_G1_BG）恒在动作空间内，作为结构锚 |
| 转移 | $s_{t+1} = \mathrm{Op}(a_t)(s_t)$ | 算子为确定性数组运算（mean λ / SVD k / 局部均值 / RPCA λ 轴 / 增益类），无随机性 |
| 终止 | 策略输出 STOP，或 $t = T_{\max}$ | $T_{\max}$ 草案值 = 4（依据：AdaptiveISP 实测多数输入 2–3 阶段即达收益饱和；本项目处理链语义阶段数为直达波去除 → 背景抑制 → 增益） |
| 奖励 $R$ | 见 §4 | 终端奖励为主，阶段奖励为零（稀疏奖励） |
| 折扣 $\gamma$ | 1.0 | 有限短程 MDP，无折扣 |

## 3. 与算子目录 v0.2 的映射

- 动作空间直接由 `configs/research/operator_catalogue_v0.2.json`（30 项，SHA `8ac17b07…` 所属版本族）枚举生成，**不新增任何目录外算子**；目录升级时动作空间随冻结版本同步更新。
- 每算子的"参数档"沿用目录内已定义的离散档位（如 RPCA 的 λ 轴 B7/B8/B9），**不引入连续参数预测头**——理由：离散档已全部经过损伤阶梯/增益效果表标定，连续参数会绕过既有容差校准证据。
- 不可用动作的屏蔽规则沿用算子契约（如截断简并拒绝、掩码限制、增益溢出），不可行动作在 softmax 前置 −∞。

## 3.5 算法族扩展规范（为后续预留空间，不预建实现）

用户于 2026-10-01 指示：自动处理的覆盖范围应从"背景抑制 + 增益"扩展到后续各算法族，但当前只预留空间、不过度设计。为此约定新算法族的入场流程（五步，全部沿用仓库既有纪律，不新增机制）：

| 步骤 | 内容 | 沿用依据 |
|---|---|---|
| ① 目录升版 | 新族以 `operator_catalogue_vX.Y.json` 新版本登记，含组合 schema（该族在序列中的合法位置/互斥关系）评审 | 沿用 v0.1→v0.2 的升版惯例（版本冻结 + SHA） |
| ② 机制阶梯标定 | 新族每个算子先走损伤阶梯/增益效果表标定，产出离散参数档，与既有族同规格 | 沿用 RPCA λ 轴 B7/B8/B9 的标定先例 |
| ③ scope_limits 登记 | 新族的未覆盖区、已知失效模式显式写入目录 scope_limits | 沿用 v0.2 scope_limits 字段惯例 |
| ④ 动作空间同步 | 策略网络动作空间随目录冻结版本同步扩列；新列的 softmax 输出初值统一置小常数（等价于新动作先验中性），**旧权重在新动作空间下继续可用**，无需从零重训 | 动作空间 = 目录枚举生成（§3），扩列是索引追加而非重构 |
| ⑤ 序列求值规则覆盖 | 契约奖励对新族的求值语义（该族处理结果与哪类配对参考比对、硬约束是否适用）在容差/权重契约的下一版本中显式登记 | 沿用契约升版惯例，杜绝"新算子绕过奖励审计" |

两点显式不预留（避免过度设计）：不预留连续参数头接口（离散档纪律不变，见 §3）；不预留多目标奖励结构（成本项 λc·cost 已覆盖精度/时延权衡，新增目标须走契约升版评审）。

## 4. 奖励定义（契约化改造的核心）

AdaptiveISP 的奖励 = 冻结下游检测器的 mAP（任务性能代理，Goodhart 风险最高形态，见 AlphaD3M 对照文档第 2 条）。本项目不采用任务代理，奖励直接由两份已冻结契约计算：

$$R = R_{contract} - \lambda_c \cdot \mathrm{cost}(a_{1:T})$$

- $R_{contract}$：由冻结的容差契约 v0.2（τ_A=0.20 / τ_D=0.95 / ε=1.5）与权重契约 v0.2 对"处理结果 vs 配对参考（BG/NC/TGT）"求值，含 D 保真项、N_b 惩罚项、截幅项；identity/oracle 结构锚保持不变（identity 恒读 −due、oracle 恰读 +due），任何退化配置无处藏身。
- $\mathrm{cost}(a_{1:T})$：各算子的实测墙钟成本（已有批次遥测数据可提供初值）；λc 为推理期可调旋钮，无需重训即可切换"高精度/低时延"模式（吸收 AdaptiveISP 的动态权衡设计）。
- **硬约束优先于标量奖励**：违反容差硬约束的序列 R 直接钳制到 identity 锚之下（排序语义："不如不处理"），与现行协议语义一致。

## 5. 网络架构（初版，草案值）

沿用 AdaptiveISP 已验证的轻量结构，按 B-scan 输入尺寸适配：

| 组件 | 结构 | 备注 |
|---|---|---|
| 特征骨干 | 4 × [Conv 4×4/s2 → BN → LReLU(0.2)]，通道 32→64→128→256 | 与 AdaptiveISP 相同；输入 = 当前 B-scan（dB 刻度，固定尺寸）+ EC 通道 |
| 全连接 | FC-128 | 策略头前置 Dropout(p=0.5) |
| 算子选择头 | softmax(30 + STOP) | 输出算子 ID |
| 参数档头 | 每算子一个 softmax（档位数 = 目录离散档数） | 共享骨干 |
| 价值头 | FC-1，标量 $v(s)$ | 供 PPO 基线/优势估计 |
| 参数量 | 约 1–2 M（量级估计） | 单阶段推理目标 ≤ 数 ms（AdaptiveISP 实测 1.2 ms/阶段） |

## 6. 训练方法

- **算法**：PPO（策略梯度类，奖励无需可微——契约奖励是非可微标量，RL 天然兼容）。
- **回合**：每个 episode = 从训练场景族采样一条仿真道集 → rollout ≤ T_max 阶段 → 契约奖励结算。
- **数据纪律**：训练只用开发族（沿用 {C1,C3} 传统）；测试族 {C5,C8} 零接触，直至一次性评价。
- **复现纪律**：固定种子、确定性算子、r1/r2 双遍；训练配置（超参/采样权重/奖励版本哈希）按仓库惯例冻结为契约 JSON 后方可启动。
- **监控**：训练/验证奖励曲线、逐算子选择频率分布（检测策略坍缩，如恒选 identity 或恒选最强算子）、多次重复训练报标准差。

## 7. Goodhart 护栏清单（冻结前必须逐条核对）

1. 奖励四项系数保持 dB 恒等式构造（=1），禁止从策略网络的训练表现倒推调整任何契约参数。
2. 阈值 τ_A/τ_D/ε 只随机制阶梯重校准更新（当前待决：S1/S3 新族容差重校准），不因训练结果改变。
3. identity/oracle 锚每个 episode 同步评价，作为奖励尺度的在线校准。
4. 策略坍缩检测：算子选择频率的熵低于界限时报 diagnose 而非判优。
5. 测试族一次性评价（S5 式纪律），禁止重复应用测试阈值调参。

## 8. 与 AdaptiveISP 原文的差异对照

| 维度 | AdaptiveISP | 本提案 |
|---|---|---|
| 处理对象 | 相机 RAW → ISP 模块链 | 仿真道集/B-scan → 算子目录链 |
| 奖励 | 冻结 YOLO mAP（任务代理） | 冻结契约奖励（审计锚定，含硬约束） |
| 参数 | 连续参数预测 | 离散参数档（沿用目录标定档） |
| 可微性 | 依赖可微 ISP 模块（其自述局限） | RL 路线，不要求算子/奖励可微 |
| 验证 | 视觉基准（LOD/OnePlus/COCO-raw） | 开发/测试族隔离 + 零翻转规则 + 物理验收（20–170 MHz 全带 3D）在前、实测钻孔在后 |
| 成本权衡 | λc 动态权衡（吸收） | 同左，成本初值取自已有批次遥测 |

## 10. 验收标准（草案）

合成测试族一次性评价中，策略网络的契约奖励需同时满足：① 显著优于 identity 基线；② 不低于现行协议首跑的全局赢家（S2X/S2TZX→B9、C3mX→B7）在同族上的奖励；③ 选择频率分布无坍缩报警。三条任一不满足记 undetermined，不判负、不迭代测试族。
