# 持续研究任务书

更新日期：2026-09-24。用户要求在当前会话每五小时自主推进研究、初步实验计划及各类结构的学术严谨性。用户已自行设置 `gpr-agents` 定时任务，并明确要求不再处理调度；本地备用派发配置已禁用，未注册 Windows 备用任务，不新增或修改触发器。

## 固定目标与边界

- 工作区：当前仓库根目录（初始机器为 `D:\自动处理`）；当前机器的调度返回当前会话，不自行新建平行会话。用户在另一台电脑克隆后可从新会话接续，先读最新用户指示、`AGENTS.md`、[版本管理说明](../WORKFLOW.md)，再读本文件与进度记录。
- 先做非显性滑坡场景特化，仅研究背景与相干杂波抑制、增益与衰减补偿，以及对应算法、参数和必要顺序的配置选择。
- 营山/雅安测线及钻孔继续留待后期。不读取其数值或解释来调参、选择评价区域、构造奖励、提取杂波或拟合仿真母模型。
- 当前已授权研究、文件编写和可逆检查。计算权限问题尚待用户答复：在取得进一步授权前，不运行 gprMax 正演、训练、远程计算或付费任务。可以准备可审查的输入、代码、算子与评价契约。
- 用户消息中的 `dendritic` 含义待澄清；不得据此自行增加树枝状结构假设、网络或独立研究模块。已明确的地质结构、算子与网络严谨性核查可继续。

## 每轮怎样推进

1. 从 `continuous_research_status.md` 的未完成项接续，检查是否被用户后续决定改变。不要重新审计原始资料，不重复生成已有综述。
2. 选择一个能形成具体产物的研究问题。针对原论文、官方文档或作者实现检索并读取，记录版本、日期、阅读范围和页/节/式；把作者声称、数学推导、迁移假设、数值验证和实测支持分开。
3. 对每个结构同时检查：地质合理性、电磁参数与尺度合理性、本频带可辨性、仿真参考是否合法、背景/增益操作可能造成的损伤。不能从“存在裂隙”直接推出“必有可辨雷达事件”或“已确定滑动面”。
4. 持续完善初步实验计划：科学问题和可证伪假设、母模型族、干扰和负控、材料参数来源、采集/导出假设、网格与边界检查、数据划分、强传统基线、消融、评价定义、资源预算与停止规则。
5. 有充分依据后再准备最小实现或仿真输入。先检查全零、常数增益、弱层误删、极性翻转、到时偏差、伪连续及无目标放大等反例。实际计算严格遵循最新已确认权限。
6. 将新增证据和决定写入项目文档，更新进度记录中的完成项、改变的判断、仍有的缺口和下一步。阶段性成果再输出 Word/PDF，不为微小更新反复排版。

## 优先工作包

| 工作包 | 预期产物 | 完成条件 |
|---|---|---|
| R1：结构证据卡 | 覆盖层/基覆界面、风化过渡、含水变化、裂隙/松散区等逐项证据与反例 | 每项明确来源、成立条件、迁移限制及可辨性；缺证项降级为假设或延期 |
| R2：材料与采集假设 | 材料参数来源表、频带/激励/导出假设及不确定性范围 | 不从 ERT 阈值直接推算全频电磁材料；不混同 Ricker、冲激与 SFCW |
| R3：参考与指标 | clean 定义、ROI/事件窗口规则、指标公式和反例清单 | 明确哪些场景有全波形参考，哪些只可评价指定物理差异；亮度不能获得虚假收益 |
| R4：初步实验计划 | 分阶段母模型、划分、基线、消融、预算和停止规则 | 从机制控制到完整正演，先验固定测试；规模有估算，未知量明确列出 |
| R5：算子与配置模型 | 最小算子契约、合法配置集合、基线与选择器比较设计 | 不削弱传统基线；先验证自适应是否必要，再考虑 CNN 或 RL |

不要求一轮完成所有工作包；但每轮应消除具体不确定性或提交可审查产物，不能只写“继续调研”。遇到全文访问失败，记录缺口并推进独立工作，不反复重试同一失败入口。

## 通知与停止规则

- 通知偏好待用户答复。在此之前按“重要新结论、阶段成果完成、需要用户决策或执行失败才通知”执行；普通进度落盘，不发送无变化播报。
- 不向他人发送消息，不对外发布、上传项目原始资料或开支。
- 当前阶段目标是形成学术依据清楚、可执行且可审查的初步实验方案。完成后明确报告，后续轮次仅处理新增证据、剩余问题或用户新授权，不为保持忙碌反复改写。
- 同一外部障碍重复出现时不要重建任务、添加更多触发器或扩大权限；记录并请求必要信息。
- 用户要求停止或暂停定时任务时，停用对应任务计划条目，并报告实际状态。
