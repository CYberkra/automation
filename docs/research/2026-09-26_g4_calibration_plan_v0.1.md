# G4 阈值校准执行方案 v0.1（设计提案，不执行校准、不产生任何阈值数值）

日期：2026-09-26。入口：用户 19:43 "继续"（批准起草 G4 阈值校准执行方案）。本文把 [评价协议 v0.2 §9](2026-09-24_evaluation_and_labels_v0.2.md) 的四步+锁定程序落到本仓库现有产物上：**逐步盘点输入、定义可执行层、标明哪些决定需要用户**。本文不产生任何阈值数值、不解除 G4、不生成任何标签；方法结构参照 [G4 文献核查](2026-09-26_g4_threshold_calibration_literature.md)（POD/MAPOD 框架与 gprMax 参考校准先例，设计建议级）。

## 0. 总原则

- G4 解除前：`physical_acceptance_threshold=null`、一切候选 `undetermined`、不排名不选优不训练——本方案不改变这些常量。
- 阈值的**形式与推导程序**可以先冻结；阈值的**数值**只能从校准程序产出，不得从"候选都不过"倒推（v0.2 §9 第 3 步明令）。
- 仿真域标注：所有由此产出的阈值只带仿真域合法性，G6/G7（实测外推）未解除前不得外推实测（文献核查结论 2）。

## 2. 第 1 步执行设计：参考校准报告 v0.1（可立即执行）

- **内容**：从已归档数据汇总每个事件窗的参考不确定性量级表——网格链（E6 粗→细→ZFINE2 相邻差）、维度差（E7 2D/3D 时域互相关/幅度趋势差）、档间方向一致性（fine2）、误差预算（数值可辨识性边界）。
- **产出形式**：`reference_uncertainty_budget` JSON：每个事件窗 × 每类指标（到时类/形状类/幅度类）的不确定性区间；**幅度类单列并标注 G1/G6 限制**。
- **判定规则（预注册）**：算子间指标差异 ≤ 对应窗参考不确定性 ⇒ 该差异记 `undetermined`，不得进入排序。这与 S4/B.4"存在稳定差异"判定同一把尺子。
- **结论状态**：报告不改 `reference_state`；参考升级只走 v0.2 §9 四步全部完成后。

## 3. 第 2 步执行设计：FDTD 道集上的损伤阶梯 v0.1（可立即执行，开发组内）

**认识论边界（先写死）**：阶梯的参考是**施加损伤后的输入本身**（闭式构造、逐位已知），不是物理 clean 真值。因此阶梯回答的问题是"算子在已知扰动下的行为"（保真/删除/放大的机制证据），**不构成现场可探测性声明**——与 2026-09-24 构造数组试验同一认识等级，只是载体从合成数组换成归档 FDTD 道集。

- **载体**：MT 33 道与 CO 11 道归档道集的冻结事件窗（同一事件表、同一"原样施加不平移"映射；两几何分层、不合并不跨配对）。
- **范围**：仅开发组 {B2D-C1m, B2D-C3m}（沿用 S4 冻结划分；测试组 C5/C8 冻结至阈值锁定后）。
- **损伤类型与级别（设计起点，冻结前可调）**：
  | 类型 | 级别起点 | 闭式可知量 |
  |---|---|---|
  | 幅度下降 | 因子 {0.9, 0.5, 0.1} 乘事件窗内局部段 | 精确缩放 |
  | 极性反转 | 事件窗内局部段 ×(−1) | 精确反号 |
  | 样本偏移 | {±1, ±4, ±16} 样本延迟局部段 | 精确移位的解析 D（如损伤试验的 D=√(k/N) 关系） |
  | 局部弱层删除 | 道子集 {1, 4, 8} 道 × 事件窗 | 精确删除 |
  | 负控放大 | 增益 q∈{2,4} 施加于 nc_zero/bg_absent 窗 | 精确增益曲线 |
- **算子集**：27 项目录 + S4 冻结的 L/R 基线（同等动作集合纪律照录）；identity 作保真锚。
- **指标**：对损伤输入，以 identity(损伤输入) 为已知参考计算 D/A/H/ρ（**这在本阶梯内合法**——参考由闭式构造给出，与 `numerically_unresolved` 的物理参考状态不冲突，报告须逐条标注"constructed reference, not physical truth"）；N_b 负控行同既有口径。
- **产物**：阶梯记录 JSON（r1/r2 字节一致验收）+ 机制报告；仍不排名不选优。

## 4. 第 3 步执行设计：任务容差模板与**需要用户输入的清单**

POD 域映射（文献核查登记的缺口要求显式写出）：

| POD/MAPOD 概念 | 本仓库映射 |
|---|---|
| 缺陷尺寸 a | 损伤阶梯级别（幅度因子/移位样本数/删除道数） |
| 信号响应 â | 第 2 步选定的评价指标（分类型：到时类/形状类/幅度类分列） |
| 检测门限 â_th | 任务容差（损伤上限）与最小有效收益 |
| a90/95 能力表述 | "在该结构族与参考可信度内，能区分不可接受损伤的能力值 + 保守界限" |
| 误报率 | 负控窗 N_b 约束（与检出并列必报，文献核查结论 4） |

**须用户敲定的输入（阻塞第 3 步，不阻塞第 1/2 步）**：
1. 任务上最小需要辨认的损伤是什么（滑坡场景下不可接受的异常幅度/尺度/深度下限）；
2. 可接受的误报代价（负控窗允许的风险水平）；
3. 能力表述的保守程度（是否采用 a90/95 式保守置信，及理由）；
4. 容差适用的结构族范围（是否四族统一还是分族）。

**预注册纪律**：容差数值只能从"阶梯数据 × 用户任务输入"导出；数值不确定性（第 1 步预算）与验收容差分开记账；不得从候选表现反向调整（v0.2 §9 第 3 步）。

## 5. 第 4/5 步程序（预注册）

- **敏感性检查**：对冻结 τ 做 ± 参考不确定性扰动与窗界 ±Δ 扰动，统计候选两两偏序翻转率；翻转频繁 ⇒ 保留集合/`partial_only`，不制作单标签（v0.2 §9 第 4 步）。
- **锁定**：指标定义、阈值、掩码程序、候选集、特征、划分同版本冻结（哈希链），测试只做一次冻结协议下的评价（第 5 步）。

## 6. 执行顺序与门禁

1. **立即可执行（自主）**：第 1 步参考校准报告；第 2 步阶梯实现与开发组运行。均为 CPU 只读+构造扰动，不启动 FDTD，符合 18:48 自主权范围。
2. **等用户**：第 3 步四个输入（§4 清单）。
3. **随后**：第 4/5 步。

## 7. 纪律照录

`reference_state=numerically_unresolved`、阈值 null、`training_eligible=false`、无物理/训练标签、不跨族/跨档差分、负控不并入目标行、BASE 档、G1（A0 待用户敲定）/G5 维持；CO/MT 分层不合并不跨几何配对；构造参考≠物理真值的标注随每条阶梯记录携带；N_b 与一切比值是诊断量，不是 SNR/可探测性/阈值。
