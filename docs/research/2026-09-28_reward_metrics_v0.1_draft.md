# 奖励与评价指标落量草案 v0.1（仿真锚定）

日期：2026-09-28。状态：**未冻结草案**，供用户过目；不构成执行契约、不产生训练标签、不改 v0.2 任何定义。

本文接续 [评价与标签协议 v0.2](2026-09-24_evaluation_and_labels_v0.2.md)。v0.2 冻结了指标定义（D/A/H/ρ/R_c/N_b）、参考五状态、区间偏序与标签逻辑，其 §9 把物理阈值留为 null 并规定了校准程序。本文做的是该程序的**第 0 步落量**：把 2026-09-26 至 2026-09-28 各仿真批次的实测量级整理成奖励设计可用的锚点，提出首版两个处理类（背景抑制、增益补偿）的正向/负向指标组成。**阈值与权重仍按 v0.2 §9 程序校准（损伤阶梯），不由本文直接给定。**

## 1. 实测锚定量（全部为仿真属性，注明出处批次）

### 1.1 事件电平（锚点道 t17，官方 SFCW 链，Hann 谱窗，相对直达波）

| 事件 | t3 S2X 坡地 | t3 S2TZX 坡地+过渡带 | t3 C3mX 水平 | 出处 |
|---|---|---|---|---|
| 直达（参考 0 dB） | 4.16 ns | — | — | batch2d_slope_t3_co |
| 地表反射 | 99.80 ns，−17.5 dB | — | — | 同上 |
| 基覆界面回波 | 172.99 ns，**−49.0 dB** | **−54.1 dB** | **−62.6 dB** | 同上 |

- 界面回波比直达弱 49–63 dB、比地表反射弱 31–45 dB：这是 15 m 航高几何 + 当前材料假设下的仿真量级。**任何线性显示或能量型总指标都会被强事件主导**，这是奖励设计必须按事件分项（v0.2 §4）的实测理由。
- 谱窗底座：Hann 窗下 −93/−108 dB（PML 敏感性批），界面回波高出底座 30–40 dB——**数值可信区间充足**；旧 gaussian σ=0.2 窗底座 −60 dB 曾淹没界面（勘误史见 decision_log 2026-09-28）。

### 1.2 参考构造精度（费马几何预测 vs 实测峰，33 道最大偏差）

| 模型 | 最大偏差 | 含义 |
|---|---|---|
| t3 水平对照 | **0.46 ns** | 链路与速度选择认证 |
| t3 S2X | 2.30 ns | 带心恒速近似残差（未拟合修正） |
| t3 S2TZX | 3.13 ns | 同上 + 过渡带 |

→ 事件窗可以由**模型几何 + 费马预测**在候选运行前冻结（v0.2 §2 的硬性要求），不需要从处理输出反找峰。建议窗半宽：直达/地表 ±5 ns（精确线），界面 ±10 ns（覆盖 3.13 ns 残差 + 子波宽度）。

### 1.3 数值与模型不确定度下限（阈值校准的输入）

| 来源 | 量级 | 性质 |
|---|---|---|
| 网格 2.5cm vs 5cm（锚点） | 到时 0 ns，幅度 0.97 dB | 数值分辨力下限 |
| 2D vs 3D（同几何同材料） | 到时 0.00 ns（反射事件）；界面−地表级差 2.1 dB；跨路径绝对电平差 = 扩散律（13.1 vs 理论 13.7 dB） | 维度代表边界 |
| 色散材料假设（常数↔Debye） | 界面到时 +2.5 ns，幅度 −3.3~−6.6 dB | 材料模型敏感性 |
| 直达波峰 2D vs 3D | 0.83 ns | 源型子波差异，不传播到反射事件 |

→ **阈值设计含义**：事件保真阈值若小于 ~1 dB/1 ns 将低于数值分辨力，应判 `numerically_unresolved`（v0.2 §9 第 1 步）；到时类、形态类、近等程事件比类指标在 2D 批量中可直接用；**跨路径长事件的绝对电平比不可用作奖励**（2D↔3D 差一个扩散律，xcheck 批实测）。

### 1.4 背景抑制可行性的直接仿真证据

- 均值道去除（最小背景抑制算子）界面/底噪对比（峰值/中位底噪，±12 ns 事件窗，240–280 ns 底噪窗，33 道中位）：旧 gaussian 窗链数字 7.6 → 28.4 dB（t2 S2 BG）已被 **Hann 链重测**取代（`hann_bg_suppression_readout.py`，本地）：

| 模型 | 去除前 | 均值道去除后 | 解读 |
|---|---|---|---|
| t3 S2X 坡地 | 16.2 dB | **80.0 dB** | 倾斜界面到时逐道变化，不被均值道吸收，底噪（道间不变）被消去 |
| t3 S2TZX | 12.4 dB | 75.4 dB | 同上 |
| t3 C3mX 水平 | 6.1 dB | **30.6 dB** | **警戒例**：水平界面到时逐道不变，被均值道一并扣除——"对比提升"大幅缩水的部分正是被误删的地层 |

- 底噪为道间不变分量（PML/几何共有，PML 敏感性批认证与 PML 厚度、地层无关）——这定义了首版合法的"指定干扰"：**道间不变背景分量**。注意地表反射也是道间不变强分量，但按项目约定它是航高/几何信息载体，**不属于可删除干扰**（AGENTS.md 处理与信号保真 §直耦波/空气传播时延/地表反射/地下反射四分）。
- **奖励设计的直接教训（实测）**：R_c 类"干扰下降"奖励在水平对照上会奖励一个把地层一起删掉的算子——v0.2 的"收益不能抵消必保事件损伤"硬约束不是理论洁癖，是本场景实测成立的必要性。水平族因此是背景抑制算子的**必备负控场景**。

## 2. 奖励组成草案（首版两个处理类）

v0.2 的决策层（区间偏序、可行四状态、不强制唯一编号）保持不变。以下标量奖励形式仅为 **RL/配置选择训练的提案**，阈值 τ 与权重 w 一律 TBD（§4 校准程序），约束项优先于收益项（硬门）。

### 2.1 背景抑制类

**保护对象**（正）：声明的基覆界面事件 e_if（参考状态见 §3.1）；后续族的弱/断续/局部响应按各自事件编号扩展。

**指定干扰**（负）：道间不变背景分量（不含地表反射带的物理信息角色；直达/地表带的处理角色另列——当前假设它们是几何/航高信息，删除需单独论证）。

| 角色 | 指标（v0.2 定义） | 奖励方向 | 实测锚定 |
|---|---|---|---|
| 正向收益 | 干扰残余 R_c 下降比 `R_c,in/R_c,out`（纯干扰窗 M_c 合法时） | 越大越好，取 log | 均值道去除使对比 7.6→28.4 dB（待 Hann 重测） |
| 正向收益 | 界面/背景对比提升（proxy：事件窗能量 / 同道间不变分量残余能量） | 越大越好 | 同上 |
| 硬约束 | 界面事件 D_e = \|\|M_e(Z−S_e)\|\|/\|\|M_e S_e\|\| | 必须 ≤ τ_D（TBD） | 数值下限 ~1 dB 等效 |
| 硬约束 | 幅度保护 A_e = \|a_e−1\| | 必须 ≤ τ_A（TBD） | 反号/缩放反例见 v0.2 §5 |
| 硬约束 | 到时漂移（事件峰 vs 费马线） | 超窗即失败 | 窗 ±10 ns；数值分辨 <1 ns |
| 负向罚 | 负控窗能量比 N_b,out/N_b,in | >1+ε 即过度处理 | 负控窗设计见 §3.2 |
| 负向罚 | 未知响应删除 | 不给删除奖励 | v0.2 §2 |
| 成本 | 耗时/内存/失败 | 超限失败 | — |

提案标量形（仅提案）：`R_bg = w_c·log(R_c,in/R_c,out) − Σ_e [max(D_e−τ_D,0)+max(A_e−τ_A,0)]/τ_scale − w_b·max(log(N_b,out/N_b,in),0)`，约束违反时整例 `infeasible` 不参与奖励比较。

### 2.2 增益补偿类

按 v0.2 §6：**只有已知乘性衰减控制例才有质量标签**。实测锚定给出的补偿量级：界面相对直达 −49~−63 dB、相对地表 −31~−45 dB——若目标是让界面相对强事件可读，所需补偿是**数十分贝量级**，这正好放大了 v0.2 的风险条款：

- 正向（仅控制例）：相对 S0 的 D/A/H（补偿目标明确时）。
- 负向：负控窗增益后能量比（>1+ε 即纯放大噪声）；截幅；增益曲线异常（记录 max、曲线、异常）。
- 明确禁止（实测支撑）：常数增益/AGC 提高的是显示亮度不是 SNR——本场景界面与干扰同源衰减，任何"越亮越好"的奖励都会在 −49 dB 界面与 −65 dB 底噪上同样放大，对比不变。**增益奖励必须绑定事件信杂比变化，不能绑定能量/亮度变化。**

### 2.3 顺序与组合

BG→G 与 G→B 分开评价（v0.2 §4/§6）；组合配置只有两类标签都成立时才有完整标签，否则保留分项与诊断。

## 3. 参考与窗口的具体构造

### 3.1 t3 族可用参考状态（提案，待用户确认）

| 事件 | 提议参考类型/状态 | 依据 | 限制 |
|---|---|---|---|
| BG 界面回波（S2X/S2TZX/C3mX） | `isolated_event` / isolated | 窗内无其他事件；Hann 底座低于事件 30–40 dB；费马吻合 0.46–3.13 ns | 参考 S_e 的波形本身仍含色散模型假设（±3.3~6.6 dB 族敏感性） |
| 直达/地表 | 精确几何线（非参考波形） | 解析式 | 不作保真评分对象，作时间基准 |
| 道间不变分量 | `paired_contrast` 诊断 | 均值道去除实验 | 不是可整幅删除的"clean 背景" |
| 深部（界面以下）窗口 | `negative_control` | BG 模型界面以下无声明响应（基岩均匀） | 底噪仍在，分母非零 |

差分型参考（TGT−BG）暂不用于奖励：目标体已按 2026-09-27 消融决定暂停；恢复时按 v0.2 §3 接入判据另行论证。

### 3.2 窗口冻结程序

1. 由母模型几何 + 费马预测生成各事件中心线（脚本化，随契约冻结，哈希登记）；
2. 窗半宽：直达/地表 ±5 ns、界面 ±10 ns、负控窗取界面带之后 250–400 ns（避开事件、在 1200 ns 记录内）；
3. 候选运行后**不重找峰、不重画窗**（v0.2 §2）；到时漂移作为独立诊断量报告。

## 4. 阈值与权重的校准程序（冻结前的路线）

按 v0.2 §9，顺序如下，全部只用开发族（t3 BG 族及其损伤派生），不碰测试族：

1. ~~Hann 窗下重测背景抑制证据~~ **已完成**（见 §1.4 表）：S2X 16.2→80.0 dB、S2TZX 12.4→75.4 dB、C3mX 6.1→30.6 dB（含水平族误删警戒例）。这是 R_c 类奖励的第一个合法刻度。
2. **损伤阶梯**：对 t3 BG 参考施加已知损伤——幅度 −1/−3/−10 dB、极性反转、样本移位（1/2/4 样本 ≈ 0.06–0.24 ns 级）、界面整带删除、负控窗 +6/+20 dB 放大——记录 D/A/H/ρ/N_b 响应曲线，标出最小可辨损伤。
3. **任务容差**：结合 §1.3 不确定度下限（~1 dB / ~1 ns 数值分辨力），给出 τ_D、τ_A、ε 的提案值与理由；验收容差与数值不确定性分开报告。
4. **敏感性检查**：阈值 ±50% 扰动下候选排序翻转率；频繁翻转则保留 partial 标签（v0.2 §9 第 4 步）。
5. **权重**：只在阈值冻结后，用开发族上的配置效果表标定 w 的相对量级；**不从候选表现倒推**（Cawley–Talbot 条款）。

## 5. 明确的边界（实测支撑的新表述）

- 本文所有 dB/ns 数字是**指定仿真族 + 指定材料假设**的属性；不外推为实测数据的信噪比或可探性结论（AGENTS.md 工作原则 2）。
- 2D 批量结论的使用边界以 xcheck 批为证：到时/形态/近等程事件比可用；绝对电平比不可用（扩散律）。
- 界面回波 −49 dB（S2X）等量级依赖色散材料假设（±3.3~6.6 dB）；色散实测数据调研完成前，奖励阈值不得在单个材料假设上收得比该敏感性更紧。
- PSNR/SSIM/显示清晰度/gCNR 不进入主要标签（v0.2 §4 维持）。
- 本草案不冻结任何数值；冻结按 §4 程序另立契约。
