# 第三次续研：传统自适应基线与自动选秩的适用边界

日期：2026-09-24。阅读范围与本地来源见[来源台账](2026-09-24_cycle03_source_ledger.json)。本轮问题是：**怎样让 ML 与足够强、同样保护地层的传统方法比较，而不是只战胜一个随手选的固定流程？** 以下分开记录原文事实与本项目提案，尚无性能试验。

## 1. 自动选秩不等于自动识别杂波

Henninger 等的 SCRAP 从历史杂波子空间与新采集构造更新矩阵；其奇异值门槛建立在复白高斯噪声假设上。作者明确把对更新混合矩阵的门槛称为启发式，仿真初始采集无目标，还限制最大杂波阶数以减少目标混入。定位：PDF pp.2–4，§III-A/B/C、式(4)–(9)、§IV-A。阅读了这些相关页，未通读其余实测结果。[原预印本](https://arxiv.org/abs/2402.11939)

迁移判断：这支持“参考采集＋子空间更新”是一种可研究的传统自适应方法；它不支持从我们的单条 B-scan 中仅凭大奇异值区分直达波、层间反射和滑坡相关结构。我们当前没有可用且不含保护层的历史杂波库，也不提取保留测线杂波，因此暂不纳入 SCRAP 的直接实现。该限制是本项目输入条件差异，不是原文方法无效。

Gavish 与 Donoho 研究的是低秩信号在独立同分布零均值噪声中的矩阵恢复；保留足够大的奇异值、丢弃较小者。方阵/非方阵的系数不同。定位：arXiv v3 pp.1–2，§I、式(1)–(3)；只读这些页，未核验全篇证明。[原论文预印本](https://arxiv.org/abs/1305.5870)

迁移判断：其“最优”有明确目标和渐近条件。把这个去噪门槛反过来用于删除 GPR 最大奇异值，不能继承原论文的误差保证；连绵地层本身也可能构成低秩结构。首版去噪延期，因此本项目不新增这个去噪算子。可借鉴的是认真写清噪声模型、矩阵形状和优化目标。

进一步的直接推导：若只观察 `X=S+C`，而允许 S、C 都是低秩且没有独立约束，把两者的语义互换仍可得到同一 X。因此“总能从数值矩阵识别有用地层”的命题缺乏可辨识性。配置模型需要公开场景假设、可用元信息和拒绝判断机制；不能让神经网络掩盖标签缺口。

## 2. 滑动均值：成熟方法也有必须冻结的实现选择

锁定作者仓库提交 `36a26df1bcce8ccbcf60bc6326e41a7200689132`。`readgssi/filtering.py:bgr` 第 11–40 行：先扣除每行全局均值；合法局部窗再作用于这个结果，使用零值边界；窗口还会调整为奇数。README 的“2B/2C”介绍全局与局部平均，并提示局部操作的侧向拖尾。[作者实现](https://github.com/iannesbitt/readgssi/blob/36a26df1bcce8ccbcf60bc6326e41a7200689132/readgssi/filtering.py#L11)

项目选择：以**不预先全局扣均值、边缘按实际道数归一化**的单步局部均值作为可解释参照，单独命名、单独记录；它不声称与 readgssi 数值一致或是更好的算法。原因是要分别检验全局背景估计、局部非平稳背景估计及边界伪影，避免隐含复合操作污染比较。式与反例见[算子契约 §7](2026-09-24_cycle03_operator_contract.md)。这项变体是我们的实验定义。

物理道距未确定时，窗口单位只写“道”。未来有可靠坐标后再研究物理长度窗口，当前不以窗口处理的名义增加几何重采样。滑动均值虽从输入局部估计背景，仍不能保证横向连续层被保留。

## 3. RPCA/WNNM 为何先作为条件性参照

Liu 等（Sensors 2023, 23, 5078）的 §2 把低秩分量定义为杂波、稀疏分量定义为目标；§2.2 明确把层状介质界面纳入大奇异值的解释。§3 的仿真参考由有目标与无目标数据相减；§3.2 的 EMA/RPCA/RNMF/WNNM 参数通过最大化 IF 选择。本轮复读这些定义及 §3.1.1 的参数讨论，沿用此前正文阅读记录。[期刊原文](https://www.mdpi.com/1424-8220/23/11/5078)

对本项目有三项约束：

1. 我们要保留的部分连续层可能进入它的低秩分量；直接只输出稀疏项，任务定义便改变了。不能以减少这部分回波的 PSNR/IF 收益作为本项目成功。
2. 逐案例优化评价指标得到的结果，是有对应评价信息时的优化参照；不自动成为部署时无需真值/区域信息的自动方法。不能把论文报告值当作现成可迁移的零调参基线。
3. 公平比较时，两者都应获得同样的开发调参机会，并接受共同地层保留约束。若输出形式改为 `X−L`，则其中的残差与论文的 `S` 可能不同，必须标记变体；不能再称原方法等价复现。

当前没有实现 RPCA/WNNM，也没有逐式复核排版原稿与作者数值实现，不宣称复现。待场景参考合法后，可把原方法作为“稀疏局部目标导向”的条件性对照，分结构报告损伤；若改变保留项，需要先给新目标函数、实现与验证。不能因为可能不适用就故意不给充分调参。

## 4. 建议的比较层级

这是一份实验提案，尚未冻结质量阈值或运行任何一组性能实验。

| 比较对象 | 如何获得配置 | 测试时允许使用的信息 | 作用 |
|---|---|---|---|
| identity | 固定不处理 | 输入 | 保真和操作收益参照 |
| 最佳固定流程 F | 在开发组内比较全部合法候选，按预先约定的保护约束和指标选择一个配置 | 同一固定配置；输入合法性检查 | 防止只比较随手选的均值/SVD |
| 局部均值基线 L | 开发组选择窗口与强度；运行时从当前窗口估计局部背景 | 当前 B-scan；已冻结窗口 | 非平稳背景的传统自适应参照 |
| 输入统计规则 R | 输入奇异谱决定是否及删几项；门槛在开发组内校准 | 当前输入的谱，不看 clean、测试 ROI 或处理后收益 | 无训练或低参数的选择参照 |
| 小型选择/排序模型 M | 仅用训练母模型的真实算子效果学习，开发母模型选超参数 | 同等输入与已冻结元信息 | 测试 ML 是否额外获益 |
| 候选内离线最优 O | 评估每个合法候选后用仿真真值选取 | 真值仅用于报告这个参照 | 估计候选库内的选择空间，不是可部署基线 |

F、L、R 都能“自适应”，但适应的对象不同：F 中 SVD/均值的数值估计仍随输入变化；L 在空间上适应；R 进一步选择操作参数；M 学习跨实例选择规则。不要将前三类笼统写成完全不自适应的传统算法。

### 参数与规则的具体提案

- L：λ∈{0.25,0.5,1}，奇数窗宽 w∈{5,11,21} 道，与同样的 q∈{1,2,4} 增益组合，共 27 项外部参照组合。道数不够则该窗不可用，不自动缩短；这些参数是覆盖小/中/较大窗口的开发起点，不是最优或实测适用范围。
- R：在可用 k∈{1,2,3} 内计算 `d_k=(σ_k−σ_{k+1})/σ_1`，取最大者；若最大间隙小于预先校准门槛则 identity，并保留 k 并列和数值截断拒绝规则。候选门槛 {0.05,0.1,0.2} 只是开发搜索起点；须在弱层和无干扰情形检查误删。这里的门槛是统计启发式，与防止数值简并的 10⁻⁸ 完全不同。
- R 的 q 先用开发组统一选择，不让它通过观察测试期输出亮度不断加增益。为了分开估计背景自适应的贡献，先在 q=1 做消融，再比较完整配置。
- L 与 R 的背景估计、排序、特征和参数尝试都计入耗时。没有实际运行，不报告毫秒数或省时百分比。

**27 个初始配置不是最终性能比较的完整候选库。** L 的外部组合若带来额外收益，应先扩充动作集合，并对所有选择器重新进行同等的开发与冻结。不能让传统参照使用额外的动作，再把仅限旧 27 项的离线最优称为全局上限；反之也不能让 ML 独享更强算子后把收益全归于学习。

R 当前是待实现的启发式提案；不能引用 SCRAP 或最优奇异值去噪论文声称这条特定规则已获验证。L 只有机制函数与两个控制例通过，尚无性能优势证据。

## 5. 评价与数据划分怎样避免错误结论

先按地质母模型划分，再派生窗口、干扰和增益压力条件。同一母模型的所有变体同组；F/L/R/M 使用相同组划分及可用输入。此前 P2 的 18 个开发母模型只是试点设计，不应立即拆成很小的“正式独立测试”并据此宣布泛化成功。

每个实例保存：配置可用性、参考状态、受保护事件带符号误差、干扰残留、位置/极性异常、负控残差与资源成本。多指标先分开，保护约束与排序方案在查看测试前冻结。未形成合法单目标效用 U 时，只报告可行集合与 Pareto 关系，不强行给唯一 oracle 标签或单一胜率。

若以后得到预先冻结、越大越好的 U，并定义相同可行候选集合 A，可报告 `regret_i=max_{a∈A_i} U_i(a)−U_i(â_i)`。缺乏合法参考的项不随意补零；违规、不可用、回退与不可评价率另报。这个定义是本项目的选择误差指标提案，不是已经验证的雷达质量指标。

M 与 F 的差异给出按母模型配对的效果及区间，并分结构族报告；不能让成百上千相关裁窗充当独立样本。单个母模型内置信区间不代表场景总体不确定性。原始/处理图固定共同色标，输出既保存增益后，也保存可比较的背景结果。

离线 O 与 F 若几乎没有质量差异，或差异小于数值/评价不确定性，应暂停增加网络复杂度，先检查动作库和标签。只有合法、可重复的差异存在，且简单规则无法有效取得这些差异，才继续小型选择器。上述判定仍待定义具体效用和不确定性界限，不能现在宣布需要 CNN 或 RL。

## 6. 本轮改变与后续未闭合项

本轮将“强传统基线”具体化为开发选出的固定流程、边界明确的局部均值，以及需验证的输入谱规则；不把自动选秩与杂波语义等同。27 项初始动作已有数组契约，但正式比较还需共同评价表、效果标签生成规则、母模型划分及异常计分。

后续优先完成评价与标签生成的预注册草案，再做局部/全局背景非平稳性及强弱层竞争的机制比较。材料反演、完整正演参考及实际求解器输入仍是并行待研究问题；不从本轮小数组成功推断材料或 SFCW 链已闭合。
