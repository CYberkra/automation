# 空气传播省算：本地八项诊断与适用边界

用户本轮明确要求“本地仿真研究一轮”，研究论文省算空气传播的方法及后续适用性。本单元完成 **8项本地官方gprMax4.0.1 CPU/原生FP64求解**，未改正式Line9几何、材料、采集、源或处理契约，未启动新泥岩测线、远程批次或训练。结论为：**可以借鉴解析传播加速的思想，但目前不能直接替换现有二维测线流程。**

## 论文实际做法

Wang2026，[DOI](https://doi.org/10.1109/MGRS.2026.3702334)，用户PDF第6页/印刷第7页，图4及式10–11：在空气—地表附近定义虚拟入射面，每点按发射器到该点的直线距离R生成

\[
u_{inc}(t)=u(t-R/c)/R.
\]

地下区域继续FDTD计算。省掉的是空白空气区的网格和逐步更新；传播时延R/c、空间扩散及各位置不同的入射仍保留。以8m垂直空气路径为例，单程26.685ns，双程53.370ns；不是把高空天线换成贴地天线。逐道平移时间零点也不能产生同样的加速。

作者引用[Asahi2021](https://doi.org/10.1109/JMMCT.2021.3101493)与[Laisne2001](https://doi.org/10.1109/MWSYM.2001.967035)。两篇原文未取得，仅核对引文和元数据。另阅读同一研究团队的[2021年六页公开报告](https://www.ss.cc.tohoku.ac.jp/sscc/refer/pdf_data/v54-4/v54-4_p16-21.pdf)：第17页式2通过闭面上的场及等效电磁流、自由空间Green函数连接两个区域，并明确积分成本；不能把多域方法理解为删除返回传播。

Wang正文没有完整给出虚拟面上的矢量E/H注入、有限边缘闭合、散射场返回天线及再耦合的实现。作者CodeOcean代码此前未能取得；本轮不是其求解器复现。其RTM爆炸反射面模型的半速/双衰减属于成像条件，不能作为正演材料或空气传播的改动。

## 官方支持与本轮实验

依据[官方4.0.1输入命令](https://docs.gprmax.com/en/latest/input_hash_cmds.html#ksir-time-rx-and-ksir-time-rx-spherical)、[KSIR原理](https://docs.gprmax.com/en/latest/features.html#ksir)及[输出时轴与有效长度](https://docs.gprmax.com/en/latest/output.html)：闭合面采样后，可在FDTD域外解析重建有限距离场，保留延迟和近场项。它要求三维及均匀、无损、非色散的外部；不是地下入射面的通用耦合器。

本轮选择纯空气、z向理想电流元，源逻辑位置(2,2,2)m；Ez实际Yee位置z=2+dl/2。两观察点与源的距离为4/8m，KSIR位置与直接Ez的物理位置一致，不作拟合幅度或时间对齐。两点不是移动天线B-scan，也不是4/8m航高的地层仿真。

| 对照因素 | 设置 |
|---|---|
| 完整/缩小空气域 | 12×4×4m / 4×4×4m |
| 网格 | 0.1m / 0.05m，两种域内分别配对 |
| 闭合面 | 各轴1.4–2.6m，严格包围源 |
| PML | 物理厚度1m，两网格对应10/20格 |
| 时窗 | 120ns / 480ns，原短窗保留，长窗另冻契约 |
| 源 | 官方内置 `impulse 1 1 impulse`，起始0，保存激励首样本为1 |
| SFCW | 官方direct，20–170MHz/0.3MHz/501点，实际源时间偏移，无尾窗、无时间移位 |
| 图件 | 官方Gaussian σ=0.2、补零32的包络；下方完整频段相位图同时保留 |

完整域同时保存直接Rx及KSIR，缩小域仅保存域外KSIR。每次比较截取相同的绝对物理记录长度，不误用KSIR延长缓冲区中部分支持的尾部。原始文件、执行/输入哈希、完整支持长度和尾部标志均归档。源强随网格变化的电流元长度只在跨网格图上按保存的spatial_scale转换为单位电流矩；同网格指标不额外改标度。

## 本地结果及限制

所有8项退出码0，原始Ez为float64，保存激励为单冲激，输入/输出哈希闭合。24条处理路径各取6个频点独立显式DTFT并保留源/接收时间偏移，与官方direct最大相对误差2.750e−12，仅认证处理计算。八项进程墙钟合计544.540s；5cm/480ns完整域295.156s、缩小域94.767s。这是该纯空气诊断的约3.11倍，不能当作Line9加速预测；两种域网格数本来相差3倍。

相对完整域直接接收的复频谱L2差异：

| 网格/时窗 | 4m缩域重建 | 8m缩域重建 |
|---|---:|---:|
| 10cm/120ns | 6.58% | 14.42% |
| 5cm/120ns | 15.95% | 38.79% |
| 10cm/480ns | 5.05% | 6.25% |
| 5cm/480ns | 8.77% | 3.23% |

主包络峰基本重合，空气到时保留；复频谱尚未整体收敛。5cm/480ns缩域与直接接收在20–40MHz差异分别30.84%/10.97%，最坏逐频相位差约43.6°/13.6°。短→长窗的5cm直接接收谱变化24.86%/42.61%，证明有限记录长度会明显影响这组输入的谱估计；不单凭本轮认证其唯一原因。

480ns原始直接接收尾部仍约−28.5至−33.5dB，5cm缩域KSIR终端衰减标志仍失败；没有满足[官方SFCW](https://docs.gprmax.com/en/latest/inc_SFCW.html)约−60dB的建议。细网格并未使全部指标单调改善。本轮不通过正式应用验收，也不靠窗口或裁掉晚波掩盖该缺口。边界、积分面及未记录尾部的贡献尚未独立拆分；完整域直接接收同样不是已认证的无误差真值。

## 后续能否应用到Line9

1. 现有2D线源的传播核与3D点源不同；不能直接把论文的球面1/R扩散套在2D里。官方KSIR当前也仅支持3D。
2. 无界/接PML的地层使闭合面外部不再全是均匀空气。不能只在地表放一条线就声称满足官方闭面条件；官方层状Love变换给远场，不等同8m处有限距离Rx。
3. 必须保持原天线/源定义、实际入射角及足迹、收发位置、空气往返传播、地表及层内多次返回。只注入向下波而忽略回传或再耦合会改变问题。
4. 正确的省算应保留原来真实的反射和干涉；它主要减少计算成本，不应以强条纹消失作为成功标准。

当前新材料包H5有14,280,000体素，空气4,914,507个（34.4153%）。理想地全删空气、保持每步每格成本不变且忽略耦合开销，网格成本比最多约1.5247。实际需保留缓冲/PML/完整闭合并支付积分成本，不能承诺此收益，更不能据此缩短1200ns时窗。预算源及哈希另存line9_air_cell_budget.json。

建议下一单元先敲定一个平地单界面、相同理想偶极和收发距的完整域/多域方案，明确二维或三维、官方支持的入射及返回实现，再比较直耦、地表与地下回波的完整复SFCW，并逐项核查积分面/时窗收敛。该新物理实验及实现尚未获准、未启动；不替换正式测线。
