## 2. 阈值推导规则（公式化，不从候选表现倒推）

### 2.1 主检出约束（损伤保真）：D_th = ε_stratum

- **公式**：算子 X 在 stratum（geometry × family）通过任务容差，当且仅当它在**每一个任务档损伤级别**上的 `D_p80 ≤ ε_stratum`。
- **ε_stratum 来源**：翻转率 v2 已逐 stratum 冻结（= sqrt(2 × 该 stratum 事件窗 `deviation_from_unity` 中位数)，0.0300–0.0341），标定自第 1 步预算形状类直接证据——**与全链同一把尺**。
- **语义**："算子对任务档已知损伤的改动不超过参考不确定性量级" ⇔ "损伤在算子输出中保持在参考可信度内可辨"。这正是任务输入①（最小可辨损伤的窗内形状/极性保真）经梯子操作化后的定量形式。
- **不倒推条款**：若全部候选在某 stratum 不过，结论就是"该 stratum 无 admissible 候选"，**不得放宽 D_th**（v0.2 §9 第 3 步明令；预注册 POD 结构：门槛先冻结，达不到即如实报告）。

### 2.2 误报并列约束（负控）：N_th = 1.0

- **公式**：`N_b_energy_ratio_p80 ≤ 1.0`（nc_amplify q∈{2,4} 合并口径同能力导出）。
- **语义**：背景去除算子对鬼界/振铃带负控窗的增益不得放大（identity 锚 N_b=1.0；强去除算子 N_b<1 即压制）。N_b>1 的算子在负控带上放大能量 ⇒ 误报风险高于不处理，不采纳。1.0 是公式化常数（恒等基准），非调参。
- **并列纪律**：N_b 与检出并列必报，永不并入目标行（任务输入②；文献核查结论 4）。

### 2.3 能力表述（a80 式，无论过不过都报）

- 每 stratum × 候选输出：`D_p80` 能力值 + 显式系统偏差项（到时-深度换算的速度偏差项，仿真域内取网格链方向量；统计项与系统项不混合）。弱事件带级别**永不进能力头条**（保护条款）。

### 2.4 排序稳定（冻结规则的一次性应用）

- 对通过 2.1+2.2 约束的候选，按 `g4_fliprate_stability_rule_v0.1` 在冻结翻转率 v2 上建立 determined 两两关系：唯一稳定 top ⇒ 该 stratum 报 unique；否则保留集合/partial_only（对齐 v0.2 §7）。**本步只报告结构，不做部署选型**（选型是部署规则，不是质量事实）。
