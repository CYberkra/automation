## 1. 算子效果表（9 目录配置 + 1 目录外参照 × 3 族 = 30 行）

口径：D_e/a/A/H/ρ 为 v0.2 式事件窗电池，在**增益补偿后**输出（契约 `audit_before_gain`）上计算——固定共享增益本身不计为损伤；`a_raw_event` 显示配置实际施加给事件的幅度因子；对比度 = 20log10（事件峰 / 负控窗 250–400 ns RMS)（**与草案 §5 的 80 dB 不是同一量**：草案为界面/底噪绝对对比，此处为处理前后差值指标）；Nb_ratio = 负控窗均方比（出/入）。

| 配置 | S2X / S2TZX（坡地族） | C3mX（水平对照族） |
|---|---|---|
| B0_G1_BG（恒等） | D_e=0，Δ对比 0，Nb=1.000 | 同左 |
| B2_G1_BG（均值 λ=0.5） | D_e≈0.016–0.020，Δ对比 +5.8 dB，Nb=0.255 | **D_e=0.500，a=0.5**（事件被减半） |
| B3_G1_BG（均值 λ=1.0） | D_e≈0.032–0.040，Δ对比 **+22.0 dB**，Nb=0.006 | **D_e=1.000，a=0——界面被均值道一并删除** |
| B4_G1_BG（SVD k=1） | 与 B3 几乎相同（D_e≈0.032–0.040，+22.0 dB） | **D_e=1.000——同删** |
| B5_G1_BG（SVD k=2） | D_e≈0.31–0.32，A≈0.18–0.19（事件受损） | **不可用：svd_cutoff_gap_unresolved**（契约护栏触发） |
| B0_G2/G4_BG（纯增益） | D_e=0（增益已补偿不计损），Nb=1.128/1.273（负控窗能量被放大） | 同左 |

### 关键读数

1. **奖励设计正负两面的实测配对**：均值道去除 λ=1.0 / SVD k=1 在坡地族上界面保真 D_e≈0.03（几乎无损）且负控窗能量降至 0.6%（对比 +22 dB）；同一配置在水平族上 D_e=1.000、a=0——界面被完全删除。**同一算子在同一指标电池下给出"最优背景抑制"与"界面删除"两个极端**，这正是 v0.2"R_c 类奖励必须配 D_e 硬约束"条款的实测依据，水平族作为背景抑制必备负控场景的地位被再次确认。
2. **λ 部分扣除不是安全中间档**：λ=0.5 在水平族 D_e=0.500（a=0.5，事件被精确减半）——部分扣除按比例伤事件，不存在"温和即安全"的档位。
3. **SVD k=2 双向都坏**：坡地族伤事件（D_e≈0.31），水平族触发契约护栏 `svd_cutoff_gap_unresolved`（奇异值截断间隙在数值上不可分辨，配置合法不可用——按契约语义记录为不可用行，未修补）。
4. **纯增益的负向指标正确点火**：增益补偿后 D_e=0（增益不算损伤），但 Nb_ratio 1.13/1.27——负控窗能量被放大，N_b 独立成项再次必要（与损伤阶梯 nc_amp 行结论一致）。
5. **目录外局部均值参照**：坡地族对比提升最大（+24 dB）但事件被放大 ~9%（a≈1.09，过补偿），水平族仍删界面——自适应空间均值同样不是水平界面的解。
6. 水平族恒等到时使一切"道间不变分量"类算子（均值/SVD/局部均值）系统性失效；坡地族界面到时随道变化，同一批算子几乎不伤事件。几何（界面到时方差）决定背景抑制算子的安全性。

## 2. 容差 ±50% 敏感性（提案 τ_A=0.20 / τ_D=0.95 / ε(Nb 比）=1.5，未冻结）

判定规则：阶梯行 pass = A≤τ_A 且 D≤τ_D 且 Nb≤ε；算子行 admissible = 可用 且 A≤τ_A 且 D_e≤τ_D 且 Nb≤ε；best/族 = admissible 中 Δ对比最大者。单轴扰动 ×0.5/×1.5，翻转 = 判定与中心值不同。

| 扰动 | 阶梯翻转 | 算子翻转 | best 翻转 |
|---|---|---|---|
| τ_A ×0.5 (0.10) | 3（−1 dB 行转挂） | 2（B5 坡地两族转不可行） | 无 |
| τ_A ×1.5 (0.30) | 3（−3 dB 行转过） | 0 | 无 |
| τ_D ×0.5 (0.475) | 0 | 0 | 无 |
| τ_D ×1.5 (1.425) | 0 | 0 | 无 |
| ε ×0.5 (0.75) | 6（**含 identity 转挂**） | 9（**含全部恒等/纯增益行转不可行**） | C3mX |
| ε ×1.5 (2.25) | 0 | 0 | 0 |

### 读数

1. **τ_A 坐在阶梯 −1 dB / −3 dB 两级之间**，±50% 扰动必然移动过/挂边界——这是阶梯粗糙度的属性，不是提案值的错误；含义：τ_A 的有效分辨力受限于阶梯级距，冻结时应注明"−1 dB 过 / −3 dB 挂"即其全部刻度依据。
2. **τ_D 两侧零翻转**：移位行的约束其实是 τ_A 绑定（1 样本移位 A=0.395 已先挂），D 判定远离边界——τ_D=0.95 在当前证供集上稳健。
3. **ε 的结构性下限被实测锚定**：ε×0.5=0.75 时 **identity（零改动）被判不可行**——任何 ε<1 的容差都会禁止"不处理"，逻辑上不可接受。ε=1.5 的中心值给出 +50% 裕量，正好容纳纯增益行（Nb=1.27）在可行域内、同时把 nc_amp +6 dB（Nb=4.96）关在域外。
4. best/族在 6 个扰动点中仅 ε×0.5 的 C3mX 翻转——偏好排序对提案扰动基本不敏感。
