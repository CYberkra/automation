# gprMax 优先开发：相近文献、评价指标与实测留用安排

日期：2026-09-23。状态：第三轮定向文献研究与实验设计建议；没有运行正演、训练或实测处理对比。范围仍是非显性滑坡场景下的背景与相干杂波抑制、增益与衰减补偿。

用户最新要求：先研究依靠 gprMax 开展此项工作的已有依据；现有测线较少，留待后期使用。本文件据此调整开发次序，不将历史的“先做测线—钻孔对应表”作为当前前置任务。

## 1. 结论与证据强度

**可以先用 gprMax 建立处理与 ML 的仿真开发、验证和测试体系，已有接近的文献及可核查指标。** 证据分为三类：背景抑制网络使用 gprMax 数据；SVD 与时间增益组合使用仿真评价；滑坡相关结构使用 gprMax 构造学习数据。三类分别提供方法依据，不能合并声称已有一套完全匹配本项目的成熟方案。

本轮尚未核实到同时满足“UAV-SFCW、非显性滑坡结构保留、仅两类处理、自动选算法/参数/顺序、完全靠仿真开发”的直接文献。特别是自动增益参数选择的 gprMax 专项证据弱于背景抑制证据。这是本轮检索结果，不是不存在相关论文或本项目具有首创性的证明。

当前更合理的目标是：**先证明在独立仿真场景上，自动配置能在保留结构的条件下优于固定配置，或以更少搜索取得相近效果。** 仿真内通过以后，再用保留的测线研究实际适用性。尚不能承诺无需实测适配即可部署。

## 3. 这些论文的指标，哪些可以采用

### 3.1 有明确参考波形时

S01、S02、S04 支持使用误差和结构相似性指标。设参考为 `S`，候选输出为 `Z`，元素数为 `n`：

- `MAE = sum(abs(Z−S))/n`；`MSE = sum((Z−S)^2)/n`。
- `NRMSE = ||Z−S||F / ||S||F`。S02 式 (12) 的 MRE 是这一归一化误差乘以 100%，不是逐点相对误差 MAPE。零参考场景应另报绝对误差/输出能量，不对零分母硬算。
- `PSNR = 10 log10(L²/MSE)`，其中 `L` 为预先规定的数据动态范围。S01 的单位范围公式有其归一化前提；不能把不同候选各自归一化后再比较，也不能对带符号雷达数据默认使用 255。
- SSIM 或 MS-SSIM 作为形态辅助量，明确窗口、轴方向、数据范围。它们不能独立保证深部弱反射和极性保真。

指标实现可参照 [scikit-image 官方定义](https://scikit-image.org/docs/stable/api/skimage.metrics.html)；库函数定义不证明这些指标能单独代表地质解释质量。背景抑制的参考误差优先在**增益前**计算，以免把有意的幅度补偿当成背景恢复误差。

### 3.2 杂波改善：同名 IF 也可能不是同一个量

S01 的 SCR 以目标与杂波区的峰值幅度比定义，并采用 `20 log10(SCR_after/SCR_before)`。S04 使用目标/杂波区域平均平方幅度之比，并以 `10 log10(SCR_after/SCR_before)` 表示改善。两者不能不看定义就拼接比较。

本项目可先采用预先固定 ROI 的平均功率口径：

`SCR_P = mean(Z_target²) / mean(Z_clutter²)`；`IF_P = 10 log10(SCR_P,out/SCR_P,in)`。

但目标 ROI 内可能同时存在杂波，**这仍是区域对比指标，并非自动取得真实 SNR**。仿真若给出可分离的确切成分，可另外报告成分级 SNR；不与 ROI 代理量混用。ROI 必须由场景定义或候选处理前的规则确定，不能根据输出挑区域。

### 3.3 无参考指标只能作为辅助

S02 正式版式 (13) 的 IQS 是两个局部 SSIM 图之间 Pearson 相关系数的负值：一个比较输入与预测杂波，另一个比较输入与恢复输出。它不是一般意义上的“雷达清晰度”，也不独立证明地层正确。

本阶段不需要为了使用无参考指标而放弃仿真可提供的参考约束。IQS 可留作后续候选；只有先通过“删掉弱界面、全部清零、仅加亮”等反例检查，才考虑进入配置评分。gCNR 同理，来源是[超声可分性研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC8354776/)，不是现成的 GPR 行业验收标准。

### 3.4 增益必须另设评价问题

S03 提供 SVD 与增益组合的依据，但未为我们的保层需求直接解决增益目标。建议分开两种实验：

1. **已知乘性衰减的数值实验：**构造 `Z=a(t)⊙S0+N`，记录已知正值 `a(t)`，评价 `g⊙Z` 对 `S0` 的误差、相对幅度偏差、增益曲线及噪声放大。应另做 `N=0` 的可恢复性对照；有噪声时不能只奖励逼近 `1/a` 而不检查噪声代价。这是本项目可控实验设计，不等同于完整电磁介质吸收模型。
2. **实际有损介质的全波仿真：**检查弱响应的可辨性、结构损伤、放大风险和负控。改变电导率/损耗可能同时影响传播、相位与反射，不能直接将无损介质波形当作仅靠时间增益必能恢复的 clean。

共同报告：增益上限及达到上限的比例、固定晚时窗噪声/干扰功率变化、关键响应幅度比与到时变化。常数增益是必要反例：同一位置的信号和噪声等比例放大，不应被评价为真实 SNR 提高。逐道 AGC 可改变幅度关系，不能仅凭图更均匀就称为物理衰减补偿。

## 4. 最需要重新设计的是 clean，而不是先选大网络

S01、S04 用“有目标响应 − 无目标响应”定义参考，适合指定埋物的差异响应。若无目标场景还含有我们希望保留的地层，这些共同地层会在相减时被扣除。S01 的多层案例还明确将层间反射作为去除对象。因此不能原样继承其标签，再用高 PSNR 声称保留了地下结构。

gprMax 给出已知几何、介质和电磁响应，**不自动给出唯一的‘完整有效地下信号/无用杂波’分解**。建议建立两层证据：

| 试验层次 | 构造与参考 | 可以证明 | 边界 |
|---|---|---|---|
| A：已知成分的控制实验 | 从明确定义的 gprMax 响应片段或解析回波形成保留信号 `S`，再显式加入已知相干分量/噪声或乘性衰减；保存各成分。 | 算子机制、参考误差、弱结构误删、指标是否被亮度/清零欺骗。 | 成分相加是实验条件；不能声称覆盖真实电磁耦合。若直接以含直耦的原始响应作参考，它只代表保留该响应的任务，不能冒充物理 clean。 |
| B：完整电磁场景 | 独立母模型含需要保留的界面、弱反射和结构变化；物理合理的对照场景仅用于解释指定变化；保护时窗及不确定性先定义。 | 处理对复杂响应的损伤及稳健性，检验 A 的简化是否失效。 | 无完整参考时不强行计算全图恢复 PSNR；成对相减只支持对应的对比任务，不能扩展为所有地下结构真值。 |

两个层次都包含：水平弱界面、倾斜/弯曲界面、真实断续或尖灭、局部响应、无深部目标，以及“无需抑制”的对照。它们用于测试本场景相关处理风险，不表示当前场地已经证实存在所有这些地质对象，也不把平滑连续性当作正确答案。

额外保护项沿用[评价协议](2026-09-23_v1_evaluation_protocol.md)：已知参考窗口内的幅度保留、到时偏移、极性、弱结构损失和负控输出。具体容限须依据输入带宽/采样、数值误差与仿真开发集确定，现阶段不编造通用合格阈值。

## 5. 纯仿真阶段的最小路线

以下是技术建议，尚未启动计算。

1. **先定义小型仿真基准。** 写清每种场景要保留什么、哪些是人为加入的干扰、参考成立条件、算子输入域及评分。先用少量案例检验指标是否拒绝全零、仅放大、删弱界面、极性翻转等错误输出。
2. **建立传统参照与搜索结果。** 在同一输入上运行跳过、均值/局部背景、SVD 和受限时间增益等已有首版候选。固定配置在开发/验证集上选择；逐场景有限搜索提供候选集合内参照，不称作连续参数空间的全局最优。
3. **确认自适应有收益，再训练选择器。** 标签是实际算子产生的质量/损伤/开销，可以先学习每种配置的表现，再受约束选择。先比较简单特征加树模型与小型 CNN；不因为 S02 用了扩散/GAN，就把生成波形设为首版目标。需要学习顺序前，先检查算子是否可交换。
4. **在独立母模型上评价。** 固定流程、规则、选择器和离线有限搜索使用同一测试输入与评价定义；报告各类场景收益、失败率、运行开销及相对有限搜索的差距。仅在目标函数固定后计算选择 regret；专家算法名称一致率不能代替输出质量。
5. **模型和评价冻结后，进入后期实测。** 首轮先运行冻结配置进行检查；如需调参/训练适配，另列适配实验和后续验证。仿真阶段只能统计配置次数、搜索量及计算时间，不能预先声称已节省某个比例的实际人工时间。

划分先于裁窗和增强：同一地质母模型、仅改变功率/干扰/衰减的变体、配对对照及重复仿真必须同组。独立变化的层序/几何/介质组合另作压力测试；不能把同一幅 B-scan 的多个窗视为独立场景来扩大样本量。配置空间、指标权重与阈值不根据最终测试结果反复修订；依据见 [Cawley 与 Talbot，JMLR 2010](https://www.jmlr.org/papers/v11/cawley10a.html)。

## 6. UAV-SFCW 与计算可行性的边界

- 文献中的 1 GHz/1.5 GHz、厘米级埋物、地面近距离天线只是各自条件，不宜移植为本系统的训练参数。滑坡相关场景相似不等于采集与导出链相同。
- gprMax 是电磁正演工具，见[原始软件论文](https://doi.org/10.1016/j.cpc.2016.08.020)及[官方文档](https://docs.gprmax.com/en/latest/inc_README.html)。先明确版本、激励、接收量与输出；机制验证可以从明确标注的时域假设起步，不能把 Ricker 响应、冲激响应、逐频 CW 与当前实数 CSV 当作同一种测量。
- 最终需要核对 SFCW 采集和导出对带符号 B-scan 的影响。当前频点/导出链信息不足只限制实测适用性结论，不要求现在启用实测测线调参；不能用 IFFT 包络替代带符号 A-scan 后声称域已匹配。
- 先小模型检查几何、到时、网格、PML、动态范围、数值精度和资源。二维用于早期筛选，有限目标/天线/侧向散射选取三维校核；不是所有母模型一开始就做大规模三维。
- 不把文献的 100/1,300/1,920 样本直接设为预算。根据学习曲线、分场景失败和独立测试覆盖决定扩展；扩散生成或裁窗不增加独立物理母模型数量。

## 7. 现有测线如何留到后期

**当前开发不使用营山/雅安测线训练、调参、构造奖励、选 ROI 或提取真实杂波用于混合训练，也不根据其处理图反复选择算子。** 这样可以先用仿真检验方法，再保留实测检查的价值。本轮未新增读取或处理原始测线。

此前初始化已做文件审计、数据格式核对及有限预览，不能在后期写成“从未看过的完全盲测”。本阶段不新增依据具体钻孔/解释剖面拟合母模型；场景类型先依公开文献与明确假设定义。后期如果采用项目地质先验进行适配，记录其作用及影响范围，与独立验证区分。

日后启用资料时，再据同线三功率、交叉线、重复测量与地质关联划分适配/验证角色；不把 18 份营山 CSV 计为 18 个独立场地，也不把钻孔当干净波形。

## 8. 本轮检索记录与下一份产物

检索围绕 `gprMax + clutter removal / machine learning / gain compensation / parameter optimization / landslide`，追溯 CR-Net、ULCR-Net、SGC、WNNM 原文及滑坡建模论文；补查自动配置与增益相关引用。采用作者/机构 PDF、期刊正文与官方摘要；没有以综述转述替代本表中的核心事实。网页访问受限的 SGC 明确区分预印本阅读与期刊摘要，未宣称完整复现。

下一份应形成的是**仿真场景—保留响应—干扰—参考定义—指标—预期反例**对应表及最小算子契约，随后才是少量试算与有限搜索。当前无需先消耗有限实测测线，也无需先搭建大型神经网络。
