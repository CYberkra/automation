# 增益类已知乘性衰减控制例设计（草案 v0.1，未冻结待用户过目）

日期：2026-09-29。起草依据：用户批准（"可以"）；缺口出处：评价标签契约 v0.2 `gain_metrics.no_target_defined = risk_diagnostics_only_no_gain_quality_label` 与 [奖励落量草案 §2.2](2026-09-28_reward_metrics_v0.1_draft.md)（"只有已知乘性衰减控制例才有质量标签"；"增益奖励必须绑定事件信杂比变化，不能绑定能量/亮度变化"）。

**本文件是纯设计草案：未冻结、未执行任何仿真/数组实验、不动任何冻结契约与测试族。**

## 1. 缺口定义与物理依据

增益类（增益与衰减补偿）目前只有风险诊断（截幅/曲线记录/N_b），**没有质量标签**——因为不存在"衰减真值已知"的场景。已有实测锚点（t3 开发族，色散材料假设）：

- 界面回波相对直达波 **−49~−63 dB**、相对地表反射 −31~−45 dB（草案 §1.1）；
- 所需补偿是**数十分贝量级**；
- 现有目录增益算子只有固定共享指数曲线 G2/G4（端值 +6/+12 dB，curve=g^(i/(n−1))）——**增益动态范围远小于实际需求**（差 30–50 dB），首版控制例会暴露这一档距空白（这本身是预期发现之一）；
- 纯增益实测配对（权重 v0.2 表）：G4 使 Δ对比 −0.5 dB、N_b=1.27——"亮度≠SNR"已实证，控制例设计必须让这种算子拿不到正分。

## 2. 控制例构造（认识论边界照损伤阶梯写法）

**已知乘性衰减 = 对事件施加闭式构造的乘性因子**；质量标签的参考 = **原始未衰减事件**（与背景类相反：背景类的参考是损伤后输入本身，因为"干净背景"不存在；增益类里衰减是我们自己施加的，原始事件已知——这正是"已知控制例才有质量标签"的落点）。逐条标注 `constructed_reference`，回答"增益算子在已知衰减下的恢复行为"，不构成现场衰减模型声明。

### 2.1 载体与衰减档

- 载体：t3 三族 BG CO 33 道签名雷达图（与 §4 完全同一加载链，官方 SFCW 链 Hann 窗）；
- 乘性衰减档（预注册，冻结后不可调）：**−3 / −6 / −10 / −20 / −40 dB**（线性因子 ≈0.708/0.501/0.316/0.100/0.010），覆盖从"微调"到"深部界面近乎淹没"的全带；−40 dB 档对应界面回波 −49 dB 量级的极端但物理合理的场景（强含水过渡带上方传播）；
- 衰减施加结构（三种，预注册）：
  1. `event_only`：仅费马事件窗内乘性衰减（纯控制，最简刻度）；
  2. `event_band`：事件窗 + 两侧各 20 ns 坡道带（模拟局部衰减体的边缘过渡，逼近滑带上方的物理真实）；
  3. `time_global`：衰减起点之后全时间轴乘性（模拟额外传播路径损耗，对照组——指数增益曲线理论上最对口的结构）。

### 2.2 负控设计（两类，预注册）

- `nc_untouched`：NC 窗（250–400 ns）不衰减——增益算子恢复事件时**不得**放大 NC（N_b 门复用 ε=1.5）；
- `nc_attenuated`：NC 窗施加已知衰减——"一视同仁恢复"才算合格补偿；只恢复事件不恢复 NC 的算子 = 选择性放大，须在奖励上显式劣于一致恢复（这是区分"真补偿"与"事件定向放大"的关键刻度，草案 §2.2 的风险条款落地）。

### 2.3 截幅模型（数组构造，非设备 ADC）

签名图幅度归一化到 [−1, 1] 后设硬上限 |y|≤1（构造性 clipping，标注 `simulated_full_scale`，不是设备量程声明）；补偿后越限量参与罚项与诊断。G4 纯增益 +40 dB 级曲线在强事件（直达/地表带）上必然截幅——截幅罚项的正确点火有保证。

## 3. 增益类评价电池与奖励落量（草案 §2.2 的具体化）

| 角色 | 指标 | 门/方向 | 说明 |
|---|---|---|---|
| 正向收益 | 事件恢复量 Δrec_dB = 实际恢复 dB − 应恢复 dB 的正部 | 越大越好，封顶于应恢复量 | 多补不奖励（防过补偿换对比） |
| 硬约束 | 恢复后事件保真 D_e、a（对**原始未衰减事件**） | D_e≤τ_D、a∈[1−τ_A, 1+τ_A]（复用冻结容差，跨类复用须显式论证，见 §5） | 补偿不许改波形 |
| 硬约束 | N_b ≤ ε（1.5，冻结值复用） | 复用 | NC 不得净放大 |
| 硬约束 | 截幅能量比 ≤ 阈值（新阈值，须从阶梯导出——见 §4） | 新冻 | 防 G4 式硬拉 |
| 负向罚 | 恢复欠额（应恢复−实际恢复，正部） | 罚 | 欠 3 dB 与欠 40 dB 同尺 |
| 诊断 | 增益曲线形态记录（max、曲线、异常） | 只记录 | 契约 v0.2 gain_curve_label 照录 |

**R_gain 提案形**（待 §4 阶梯刻度后定稿，不从候选表现倒推）：`R_gain = min(Δrec_dB, 应恢复) − 欠额罚 − 截幅罚 − max(10log10 N_b, 0)`，硬门不过整例 infeasible。明确排除项：增益后总能量/亮度/PSNR 类指标不入奖励（v0.2 §4 维持）。

## 4. 校准路线（镜像 §4，五步）

1. **增益阶梯**：三族 × 5 衰减档 × 3 结构 × 2 NC 态的已知衰减施加 + 恒等增益（锚：衰减后输入在恒等增益下应测得精确已知的欠额——闭式自洽检查，仿 identity 598/598 D=0）；
2. **截幅/欠额刻度** → 增益类任务容差提案（新阈值只有截幅一项，其余复用；用户确认后冻结进容差契约新版）；
3. **增益效果表**：候选 = 恒等、G2、G4（目录）+ 目录外大动态曲线（端值到 +40/+60 dB 的指数曲线，2–3 条，机制参照）——预期发现：G2/G4 欠额 30+ dB（档距空白实证）、大动态曲线截幅罚点火、`nc_attenuated` 下"事件定向放大"劣于"一致恢复"；
4. **±50% 敏感性**（新截幅阈值 + 复用项联动）；
5. **权重推导**（dB 恒等式同法，系数由构造定）→ 用户确认 → 冻结。

纯数组实现（gprMax 环境 numpy，无求解器）；规模约 3 族 × 30 阶梯行 + 效果表 ~15 配置 × 3 族 ≈ 数百行记录，分钟级；r1/r2 字节一致纪律照旧；测试族 {C5,C8} 不碰。

## 5. 显式论证与风险（审查预答）

- **跨类复用 τ_D/τ_A/ε 的论证**：三个阈值的几何意义是"处理不得改变事件波形/幅度、不得净放大干扰"——与处理类别无关，属评价层公理而非背景类属性；复用冻结值不违反 Cawley–Talbot（阈值非由本类候选倒推）。但截幅阈值是增益类**新**阈值，必须走完整校准+用户确认，不得沿用任何现有数字。
- **风险 1**：`time_global` 结构与指数增益曲线"对口"可能造成"指数增益看似最优"的结构偏置——缓解：奖励只认事件恢复+NC 一致+N_b，不认曲线形状；且 `event_band`/`event_only` 结构下对口性消失，三结构并列防单结构过拟合。
- **风险 2**：归一化 [−1,1] 是数组构造，实测设备的满量程/AGC 行为未知——截幅结论只在内部分数可比，不外推设备。
- **风险 3**：背景类契约（已冻结）不含增益类行——本设计全部产物走新 schema，不回填 v0.2 契约。
- **遗留缺口（诚实登记）**：真实滑坡中衰减的空间结构（含水滑带）比三结构更复杂；控制例闭合的是"协议层质量标签"，物理保真度靠后续色散/含水实测调研与场景族扩展补。
