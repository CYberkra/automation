# 评价与标签协议 v0.2

日期：2026-09-24。对应用户要求：“先确定评价和标签”。本文件接续并具体化 [v0.1 评价草案](2026-09-23_v1_evaluation_protocol.md)，是当前研究使用的指标与标签定义。**定义、缺失处理与标签逻辑已确定；真实电磁参考与数值验收阈值尚须小规模仿真校准。** 不把软件机制检查当作物理验证。

## 1. 本次确定的方案

1. **保留响应先定义**：保护场景中声明的地下界面、局部介电变化及弱/弯曲/断续回波；不把水平、连续或低秩当成杂波标签。
2. **背景与增益分开评价**：背景比较在相同输入幅度坐标；增益只有补偿参考明确时才给质量监督，否则只给放大风险等诊断。
3. **分项指标＋保护约束**：不采用预设加权总分。每个必保事件检查波形和幅度损伤，不能用强事件或干扰收益抵消弱层误删。
4. **标签来自算子实际效果**：保存每个配置的指标、有效性与约束结果，再产生可接受集合及明确的两两优劣关系。单一“最佳算法编号”只是充分证据下的特殊情况。
5. **证据不足就保留缺失**：零参考、事件混叠、数值不足、并列、权衡与算子失败分别处理；不补零损失，不强制唯一标签，不把回退到 identity 写成理想真值。

这里只研究处理配置选择，不增加滑坡分类、滑动面识别或直接生成 B-scan 的任务。用户此前关于“人为标定权重”的表述已撤回，不构成本协议要求。

配套：[机器可读契约](../../configs/research/evaluation_label_contract_v0.2.json)、[评价与标签研究代码](../../scripts/research_evaluation_contract.py)、[26 项检查结果](../../artifacts/research_checks/2026-09-24_cycle04_evaluation_labels_r2.json)、[本轮来源台账](2026-09-24_cycle04_source_ledger.json)。

## 2. 到底保护什么、抑制什么

| 评价角色 | 首版定义 | 不允许的自动推断 |
|---|---|---|
| 理想界面响应 | 仿真中预先声明的地下材料界面及其可分辨响应 | 不能直接命名为现场基岩顶、滑动面或某一岩性 |
| 弱界面/断续响应 | 较弱反射、真实几何或介电对比导致的断续；单独设事件编号 | 不以弱、断续为理由删掉；不奖励补造连续层 |
| 局部响应 | 当前场景中的局部介电对比及其合法事件参考 | 局部目标更清晰不能抵消共同层损伤 |
| 指定干扰 | 有独立依据的直耦/背景分量或纯干扰窗口 | 不统一清零浅层，不把全部地表/地下反射当噪声 |
| 负控 | 明确指定窗口/事件角色中没有应保留响应 | “局部目标不存在”不等于整幅无地下结构 |
| 未知响应 | 缺少合法归因的部分 | 不默认为杂波，不用于构造删除奖励 |

M02 的理想层和 M04 的共同层都属于保护对象。M04 去掉局部目标后得到 M02，M02 不是一张纯杂波图。首批角色来自公开研究和明确假设，不从保留的营山/雅安测线及钻孔补标。

每个事件保存：`event_id`、角色、来源母模型、参考类型/状态、样本与道范围或掩码、波形参考、轴/单位、数值可信证据、窗口哈希。到时/窗口在候选运行前冻结，不沿处理结果重新找峰或重画 ROI。

## 3. 参考类型与五状态：决定什么指标可以计算

**参考类型**回答“这个数值对象是什么”；**参考状态**回答“它当前能支持多强的解释”。二者不能只用一个 clean/not-clean 布尔值代替。

| 参考类型 | 用途与条件 |
|---|---|
| `complete_clean` | 已知成分构造中完整的应保留响应 S；所有要保护的层和局部目标都在其中。可评价全体重叠响应的重构误差，但不能把投影系数自动解释为某一个混叠物理成分的保留率 |
| `isolated_event` | 对应事件的绝对响应，经独立证据确认窗内污染与数值误差在界限内；允许事件保真评价 |
| `paired_contrast` | F1−F0 所定义的完整变化响应；是差异参考，默认只做配对变化诊断，不等同于 F1 的全部干净地下响应 |
| `negative_control` | 指定保护角色确实不存在；报告绝对残差、在分母非零时报告能量比，不做零参考 NRMSE |

| 状态 | 允许的监督 | 限制 |
|---|---|---|
| `isolated` | 证据合法时，事件波形/幅度监督 | 状态本身须有独立依据，不能由低分或好看的输出推断 |
| `mixed` | 有构造的完整 S 时可评价整体重构；有合法配对时可做差异诊断 | 未知 FDTD 混叠事件不产生纯事件 clean 标签 |
| `ambiguous` | 记录歧义，可保留有依据的其他指标 | 不给该成分确定保留/去除标签 |
| `absent` | 指定窗口的负控能量监督 | 分母为零不加任意 epsilon 伪造比值 |
| `numerically_unresolved` | 数值不可信状态与原因 | 不把数值零当成物理无目标，不给质量优劣标签 |

**对先前“mixed 不计算纯事件误差”的补充**：在人工构造 `X=S+C+N` 且完整 S 确知时，即便其支持与 C 重叠，`||Y−S||` 仍是合法的整体重构误差；它不意味着电磁仿真里也获得了该分解。这是参考来源的区别，并非放宽未知波场的归因要求。

### gprMax 的具体接入判据

对每个声明的开关对先检查几何、源、材料及其他不变量，计算 Δ=F1−F0。若准备在窗口 M 内把 Δ 当作 F1 中某个事件的绝对近似参考，至少要证明：该事件解释成立；F0 的窗内响应相对 Δ 足够小；Δ 本身不含需要另分的显著混叠变化；网格/PML/源采样敏感性低于预先约定的误差预算。`||M F0||/||M Δ||` 可作为污染诊断之一，不能独自证明物理成分纯净。污染界限目前未校准。

达不到上述条件就保留 `paired_contrast` 或 mixed，不生成完整 clean。P1 的三个锚点 A-scan 先解决这些物理问题，不能直接冒充训练用的完整 B-scan；进入 P2 后才按完整母模型/测线生成配置效果表。

## 4. 背景抑制的核心指标

对配置 a，背景比较量记为 Z_a。BG 顺序使用实际增益前结果；GB 顺序仅在已知正增益、无截幅时使用 `G⁻¹Y` 审计量，并另存实际步骤，不能称其为真实增益前中间量。[算子契约](2026-09-24_cycle03_operator_contract.md)

对合法保护事件 e 的固定掩码 M_e 和参考 S_e，使用原轴、原单位、原幅度，定义：

| 指标 | 定义 | 首版角色 |
|---|---|---|
| 波形误差 D_e | `||M_e(Z−S_e)||₂ / ||M_e S_e||₂` | 主保真指标，越小越好；零参考不定义 |
| 幅度系数 a_e | `<M_e Z,M_e S_e> / ||M_e S_e||₂²` | 诊断保留幅度和反号；保护约束使用 `A_e=|a_e−1|` |
| 形状残差 H_e | `||M_e(Z−a_e S_e)||₂ / ||M_e S_e||₂` | 仅诊断；不能先拟合幅度再代替主误差 |
| 带符号相关 ρ_e | `<M_e Z,M_e S_e>/(||M_e Z||₂·||M_e S_e||₂)` | 极性/形状诊断，零输出不定义；不单独当保真评分 |
| 干扰残余 R_c | `mean(Z[M_c]²)/mean(X[M_c]²)` | 只有 M_c 为合法纯干扰窗且输入能量非零才计为抑制指标 |
| 负控残差 N_b | `mean(Z[M_b]²)`，并保留输入基准 | 越小越好；单位为输入幅度单位的平方；不能直接称为目标虚警率 |

不做逐候选峰值归一化、不重对齐、不取绝对值后才算主误差。偏移一个样本会进入 D；到时的样本偏差可以另做诊断，但当前最小代码没有事件拾取器，不能宣称已完成自动到时评价。

`D_e²=(a_e−1)²+H_e²` 由正交投影直接成立，三项不是三份独立成功证据。a/H/ρ 用于说明错在哪里。强噪声或混叠时 a 仅为相对于参考的投影，不是物理成分分离证明。

**按事件约束，不只算整图平均。** 保存所有事件的 D/A；每个必保事件都必须通过。汇总同时给事件等权均值、最大损伤和各类有效/无效数量；不按事件能量加权后掩盖弱层。跨样本统计以母模型为单位，像素、道及重叠窗不是独立重复。

PSNR/SSIM、gCNR 与显示清晰度不进入首版主要标签。已有文献支持它们在特定任务中的用途，但它们不能同时证明幅度、位置、地层和弱目标保真。需要文献横向比较时才单列固定定义的辅助值，不叠加为多份独立证据。

## 5. 为什么主误差之外还需要幅度检查

Le Roux 等在语音分离评价研究中讨论了修改参考、整体缩放导致评价失真的问题，§2.2 给出信号与干扰等能量且正交时，整体减半会改善传统误差式 SNR 的例子；§2.3 的 SI-SDR 则明确容许比例变化。本轮读取 PDF pp.1–3，不迁移它的任务目标。[原论文](https://arxiv.org/abs/1811.02508)

本项目的构造反例也得到：`Y=S+N` 的 NRMSE=1，而 `Y=(S+N)/2` 的 NRMSE≈0.7071；但目标投影幅度从 1 降为 0.5。因此“重构总误差改善”未必满足保幅要求。另一个例子是 `Y=0.01S`，相关性仍为 1、形状残差近零，而 NRMSE=0.99。故本项目采用不重新缩放的 D 与显式 A，拒绝把尺度不变指标单独作为训练目标。

这些是数学/数组机制证据；并未声称所有幅度下降都不可接受。允许多少下降，要用独立开发场景和任务要求定出物理阈值。

## 6. 增益的标签：必须先有补偿目标

背景和增益各保存一组结果，避免增益掩盖背景删除。第一批背景标签固定 q=1；增益标签单独在已知控制模型中建立。

### 已知乘性衰减控制

定义 `X=a⊙S0+C+N`，a>0 是预先给定的乘性衰减曲线。背景目标为输入幅度坐标下的 `a⊙S0`，最终补偿目标为 S0。

- 对最终 Y 计算相对于 S0 的 D/A/H/ρ，保护对象与窗口保持一致。
- 在负控窗报告增益前后绝对能量与非零基准下的能量比；还保存最大增益、曲线、异常、是否截幅。
- `1/a` 作为已知生成曲线的参照元数据；有噪声/杂波时，它不必是有限候选里最好的处理，不强制网络预测它。
- 每个候选重新评估完整输出；不能用单独处理 S、C、N 后相加来代替自适应算子的实际输出。

四倍振幅增益使同窗残差能量变为 16 倍，不增加该点信号和噪声的比值。若数据没有衰减，同样增益可能只是过度放大；若明确构造了对应 a，则可恢复无噪声幅度。首版不能用“越亮越好”或“必须提高 SNR”作为增益标签。

### 完整电磁仿真或未知衰减

无损/有损介质的差别不只是一条增益曲线，没有独立补偿参考就不计算 `gain_quality` 的理想标签。可保留曲线、绝对残差、负控放大与数值失败标签。此时背景的合法标签可以照常保留，但**整个背景＋增益配置不能被宣称有完整的最佳标签**。

## 7. 标签的数据结构与生成规则

### 三层标签

1. **参考元数据**：事件角色、参考来源/状态、掩码与单位、可信度及缺失原因。由场景与独立证据生成，不是模型的输入特权。
2. **效果标签**：每个实际运行配置的指标向量、各指标有效掩码与不确定性描述、耗时/失败等。允许有的分项有效、有的分项缺失。
3. **决策标签**：可行性、可信的两两优劣关系、非支配候选集合，证据充分时才产生一个唯一编号。

每个输入 × 每个配置保留一行，不能只留下赢家。必要字段及禁止泄漏的字段已写入 [JSON 契约](../../configs/research/evaluation_label_contract_v0.2.json)。母模型 id、划分角色、候选版本、输入/参考/掩码哈希必须可追溯。最小代码实现的是指标和决策层逻辑；完整批处理元数据验证、参考构建和不确定性估计尚未实现。

### 可行性：四种状态

| 值 | 意义 |
|---|---|
| `feasible` | 所有必需保护约束和风险约束均有证据通过 |
| `infeasible` | 至少一项明确违反；即使另有缺失也保留这项失败 |
| `undetermined` | 没有明确违反，但至少一项参考/阈值/区间尚不足以证明通过 |
| `unavailable` | 算子不合法或运行失败；保留原因，不记成质量零分 |

阈值为 null 时必须为 undetermined。若指标有区间 `[L,U]`，上限型约束 τ 仅在 `U≤τ` 时通过、`L>τ` 时失败，其余无法确定。区间是来自独立敏感性分析的范围；未经统计建模不能叫 95% 置信区间。范围估计过程与阈值都不能使用测试候选的好坏反向调整。

### 集合与两两关系

同一评价上下文预先规定必需指标、约束和待比较目标，所有候选一致。所有目标统一为越小越好，不因某候选缺指标而删掉该目标。

对两个已通过全部约束的配置 a、b，只有各目标都满足 `U_a≤L_b`，且至少一项严格小于，才记 `a 优于 b`。这是本项目选择的保守区间支配规则，由不等式直接定义，不宣称某篇 GPR 文献给出了这一完整方案。

- 一个候选支配全部其他可行者，且没有未决候选，才生成 `unique_admissible`。
- 多个互不支配候选保留 `multiple_admissible`；真正等效、不同优劣取舍、区间重叠要分开解释，不能统称同一输出。
- 尚有未决参考/目标/约束时给 `partial_only`，可以保留有效分项和确定的两两关系，但不生成完整最佳编号。
- 所有候选均不合格或不可用时给 `no_admissible_candidate`。identity 是候选，不能自动伪造为质量合格标签；实际回退动作另记。

这意味着第一版网络若进入训练，优先学习**可用性＋分项效果/偏序**，而不是把 27 个编号硬编码为每例唯一类别。多项相近时选便宜配置可以是部署规则，但不是质量上更优的事实。

## 8. 配对差异为什么只能证明一部分保真

对固定同一个配置 a，计算 `ΔZ_a=T_a(F1)−T_a(F0)`，再与 ΔF 比较。SVD 即使 k 固定仍会重新拟合子空间，故这个指标评价两次实际运行的变化，不等于 `T_a(ΔF)`。独立选择器在 F1/F0 上选不同动作的结果另报，避免把动作变化混成物理响应变化。

本轮控制例中 F0 含共同水平层，F1=F0＋横向零均值局部响应。全均值扣除得到的 `ΔZ` 与 `ΔF` 完全一致，差异 NRMSE=0；共同层却被全部删除，事件 NRMSE=1。因此配对差异可以作为标签中的诊断项，**不能代替共同保护对象的绝对检查，也不能单独产生整幅质量赢家**。

## 9. 正式阈值怎样确定

以下项目在机器契约中保持 null：事件 D 上限、A 上限、负控能量上限、参考污染界限、最小有效收益与不确定性范围。不是把研究停在“以后再定”，而是规定下一步的校准输入和冻结程序：

1. **先校准参考**：使用开发母模型的独立网格、边界、源采样敏感性，记录每个事件与窗口的变化。若小到足以与算子差异混淆，先判 numerically_unresolved。
2. **建立损伤阶梯**：只用开发控制例，对已知参考施加可计量的幅度下降、极性反转、样本偏移、局部弱层删除及负控放大；标明最小需要辨认的损伤。它们是评价扰动，不是增加处理任务。
3. **确定任务容差**：在该结构族和参考可信度内，给出能区分不可接受损伤的阈值与理由；验收容差与数值不确定性分开。不得从“候选都不过”倒推放宽界限。
4. **检查敏感性**：阈值、窗口扩展或参考变化若频繁翻转候选排序，保留集合/partial，不急于制作单标签数据。
5. **锁定后再测试**：指标定义、阈值、掩码程序、候选集、特征及划分同时版本化。按母模型划分后才生成裁窗和扰动。测试只作一次冻结协议下的评价，新增开发修改使用新版本和独立验证。

Cawley–Talbot 说明模型选择过程本身也会过拟合，性能评价需包含完整选择流程；本轮读取论文 pp.2079–2080（PDF pp.1–2），未复核后续实验。该证据支持把参数/阈值选择与最终评价分开；具体的 GPR 母模型分组和容差校准程序是本项目设计。[JMLR 原论文](https://www.jmlr.org/papers/volume11/cawley10a/cawley10a.pdf)

代码检查中出现的 NRMSE 0.1、幅度误差 0.1 等仅为使各分支可验证的**数组夹具阈值**，不写入物理验收配置，不据此生成正式训练标签。
