# SFCW 载频 75 MHz 错误修复与开发侧重算（v0.2，2026-10-02）

基线 `eb9d1fd`；依据 [设计审查](2026-10-02_model_design_review.md) §2 的 P1 发现执行。本轮只做 CPU 后处理：新增加载器模块 + 三条受影响证据链的开发侧重算，**未修改任何冻结脚本、冻结契约、缓存与历史输出，未运行求解器，未接触测试族 {C5,C8}**。

## 1. 错误与修复方式

旧加载器（3 处同一表达式）用 `|env|·cos(2π·95MHz·t + ∠env)` 重建带符号波形，等于把复包络调制到带心 95 MHz；官方 gprMax 链（`reconstruct_time_response`，SHA-256 `adad556f…24a3b`）调制在**起始频率 20 MHz** 并取 2×实部。后果：物理频段被上移 +75 MHz 至 95–245 MHz（超出仿真有效带 20–170 MHz），且幅值只有官方一半。

修复为新增模块 [sfcw_official_loader_v0_2.py](../../scripts/sfcw_official_loader_v0_2.py)：**每条道只加载一次**（与旧链逐项相同：1200 ns 截断、同尾锥公式、501×0.3 MHz、zero_pad=8、Hann），从**同一复包络**派生两种表示（`signed_official` = `tr.real_bandpass`；`signed_legacy` 仅供差异对比），保证新旧差异纯粹来自载频，不混入加载漂移。

**反例验证**：80 MHz 单频输入 → 官方表示主峰 **80.1 MHz**，旧表示 **155.1 MHz**，峰值幅值比恰为 **2.000**。通过。

## 3. 影响范围（逐链）

### 3.1 t3 损伤阶梯 → **τ_D=0.95 冻结锚点需要重议**

载频不变的操作（幅值/极性/删除/NC 加噪/恒等）指标**完全不变**（D、a、H、ρ、Nb 逐位相同）。唯一实质变化在**移位族**：

| 移位 | D（旧95MHz） | D（官方20MHz） | ρ（旧→官方） |
|---|---:|---:|---:|
| 1 样本（0.83 ns） | 0.862–0.891 | **0.496–0.532** | 0.60–0.63 → 0.86–0.88 |
| 2 样本（1.66 ns） | 1.537–1.574 | **0.956–1.011** | −0.18…−0.24 → 0.49–0.54 |
| 4 样本（3.33 ns） | 1.867–1.901 | **1.644–1.703** | −0.74…−0.81 → −0.35…−0.45 |

机制：高载频下同样时移产生更大载波相位旋转，D 被放大；官方 20 MHz 载频下波形由包络主导。后果：冻结契约 τ_D=0.95 的旧锚点是"1 样本过、删除挂"；**官方载频下 2 样本移位（≈1.66 ns）恰好骑在 0.95 边界上**（0.956–1.011），"2 样本必挂"不再成立。容差契约的版本升级属于用户决策，本轮只登记差异不动契约。证据：[t3 重算 r1](../../artifacts/research_checks/2026-10-02_t3_ladder_carrierfix_v0_2_r1.json)（含 paired_delta 全表）。

### 3.2 S1/S3 参考窗 → 实测峰登记整体向费马到时收敛

4 族 132 道中 **99 道（75%）实测峰发生位移**，幅度 ≤±4 重建样本（≤3.33 ns）。关键：官方载频下实测峰与费马到时的偏差**全面收窄**——

| 族 | max\|实测−费马\|（旧） | max\|实测−费马\|（官方） |
|---|---:|---:|
| S1X | 2.385 ns | **1.417 ns** |
| S1TZX | 3.059 ns | **0.747 ns** |
| S3X | 3.623 ns | **0.649 ns** |
| S3TZX | 2.935 ns | **0.996 ns** |

旧表示把信号移出有效带导致波形失真、|峰|落点偏移；修复后实测与前向模型一致性显著提高——这是"修复方向正确"的独立物理佐证。冻结断言（max\|Δ\|<10 ns、NC 窗净空）在官方表示下依然全部通过。绝对 RMS 读数按载波相位在 1.45–2.82 倍间变化（2× 幅值约定 + 低频载波在 150 ns NC 窗内仅 3 周期、均方未收敛到 1/2 所致；比值类量不受影响）。窗口本体按契约为几何锚定、不因实测峰重锚；**契约中的 t_measured 登记列需要 v0.2 版本化更新**（待用户确认后另起冻结）。证据：[S1/S3 重算 r1](../../artifacts/research_checks/2026-10-02_s1s3_refwindow_carrierfix_v0_2_r1.json)。

### 3.3 B2 奖励试点 → 选择稳定，绝对分值不可跨表示比较

4 族 × 9 配置：**可行性翻转 0 起、选择翻转 0 起**（C1mX/C3mX 仍选 B7，S2X/S2TZX 仍选 B9）。D_e 变化 ≤0.003，Nb 变化微小。对比度与 R 的**绝对值**移动：平地族 B7 的 R 上移 +8.9 dB（C3mX）与 +15.7 dB（C1mX），坡地族各配置 ±0.1–0.9 dB。结论：**排名结论对载频错误鲁棒，但 R 绝对刻度只在同一表示内有效**；既往 52.4 dB 等绝对读数不可与修正后值直接对接。证据：[B2 重算 r1](../../artifacts/research_checks/2026-10-02_b2_reward_carrierfix_v0_2_r1.json)。

## 4. 未被本错误影响的资产

包络数组、已存 501 点复频响、一切比值/门控结论、算子排名、负控结构性结论（ε≥1 下限等）保持不变。需要版本化重建的只有：带符号波形本身、移位类指标刻度、实测峰登记、绝对 dB 分值。既往"赢家"不改判，与审查 §2"暂不能断言赢家必然改变"的开放表述一致地收敛为"赢家不变、刻度变"。
