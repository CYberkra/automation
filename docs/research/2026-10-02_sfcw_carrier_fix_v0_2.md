# SFCW 载频 75 MHz 错误修复与开发侧重算（v0.2，2026-10-02）

基线 `eb9d1fd`；依据 [设计审查](https://github.com/CYberkra/automation/blob/8f60fa0d7e992df9c76ab625d1eabafa2f641c36/docs/research/2026-10-02_model_design_review.md) §2 的 P1 发现执行。本轮只做 CPU 后处理：新增加载器模块 + 三条受影响证据链的开发侧重算，**未修改任何冻结脚本、冻结契约、缓存与历史输出，未运行求解器，未接触测试族 {C5,C8}**。

## 1. 错误与修复方式

旧加载器（3 处同一表达式）用 `|env|·cos(2π·95MHz·t + ∠env)` 重建带符号波形，等于把复包络调制到带心 95 MHz；官方 gprMax 链（`reconstruct_time_response`，SHA-256 `adad556f…24a3b`）调制在**起始频率 20 MHz** 并取 2×实部。后果：物理频段被上移 +75 MHz 至 95–245 MHz（超出仿真有效带 20–170 MHz），且幅值只有官方一半。

修复为新增模块 [sfcw_official_loader_v0_2.py](../../scripts/sfcw_official_loader_v0_2.py)：**每条道只加载一次**（与旧链逐项相同：1200 ns 截断、同尾锥公式、501×0.3 MHz、zero_pad=8、Hann），从**同一复包络**派生两种表示（`signed_official` = `tr.real_bandpass`；`signed_legacy` 仅供差异对比），保证新旧差异纯粹来自载频，不混入加载漂移。

**反例验证**：80 MHz 单频输入 → 官方表示主峰 **80.1 MHz**，旧表示 **155.1 MHz**，峰值幅值比恰为 **2.000**。通过。

## 3. 影响范围（逐链）

### 3.1 t3 损伤阶梯 → **刻度与裕量变化，未证明须改变 τ_D**

幅值/极性/删除/恒等的 D、a、H、ρ 在本次记录中不变；但不能推广为全部非移位指标不变。NC 加噪的 Nb 比值有变化，例如 S2TZX 的 +6 dB 档由 4.960311 变为 5.056014；到时诊断也会变化。移位族的主要变化如下：

| 移位 | D（旧95MHz） | D（官方20MHz） | ρ（旧→官方） |
|---|---:|---:|---:|
| 1 样本（0.83 ns） | 0.862–0.891 | **0.496–0.532** | 0.60–0.63 → 0.86–0.88 |
| 2 样本（1.66 ns） | 1.537–1.574 | **0.956–1.011** | −0.18…−0.24 → 0.49–0.54 |
| 4 样本（3.33 ns） | 1.867–1.901 | **1.644–1.703** | −0.74…−0.81 → −0.35…−0.45 |

机制：旧表示上移实际频段，在这些记录中放大了相同时移的失真；修复后的物理频段为 20–170 MHz，20 MHz 是复包络调制起点，不意味着波形由低频包络主导。**2 样本移位仍全部超过 τ_D=0.95**：C3mX=0.955661、S2X=0.998495、S2TZX=1.010644，D 门均拒绝，最小超限裕量 0.005661。1 样本通过、删除与 2 样本拒绝的 D 门结论没有翻转。应以官方表示重新登记刻度并复核敏感性；现有证据没有证明 0.95 必须改变，容差是否升级需依据任务损伤而非候选表现。冻结契约不改。证据：[t3 重算 r1](../../artifacts/research_checks/2026-10-02_t3_ladder_carrierfix_v0_2_r1.json)（含 paired_delta 全表）。

### 3.2 S1/S3 参考窗 → 实测峰登记整体向费马到时收敛

4 族 132 道中 **99 道（75%）实测峰发生位移**，幅度 ≤±4 重建样本（≤3.33 ns）。关键：官方载频下实测峰与费马到时的偏差**全面收窄**——

| 族 | max\|实测−费马\|（旧） | max\|实测−费马\|（官方） |
|---|---:|---:|
| S1X | 2.385 ns | **1.417 ns** |
| S1TZX | 3.059 ns | **0.747 ns** |
| S3X | 3.623 ns | **0.649 ns** |
| S3TZX | 2.935 ns | **0.996 ns** |

旧表示移出有效带，修复后峰值与费马到时更接近，属于同一模型内的一致性证据，不是独立物理标定。独立按冻结表复算，max\|Δ\|<10 ns、NC 窗净空均通过。NC RMS 官方/旧比值约 1.445–2.825：2×实部约定和载频引起的波形变化共同作用，不能只用 20 MHz 调制项的周期数解释带通信号，也不能推断比值类量全部不变。窗口仍为几何锚定、不因峰值重锚；t_measured 登记需另建版本，保留旧契约用于历史追溯。证据：[S1/S3 重算 r1](../../artifacts/research_checks/2026-10-02_s1s3_refwindow_carrierfix_v0_2_r1.json)。

### 3.3 B2 奖励试点 → 选择稳定，绝对分值不可跨表示比较

4 族 × 9 配置：**可行性翻转 0 起、top-1 翻转 0 起**（C1mX/C3mX 仍选 B7，S2X/S2TZX 仍选 B9），但完整排名有两族变化：S2X 的 B7 越过 B5；S2TZX 的 B8 越过 B4/B3。D_e 变化 ≤0.003。平地族 B7 的 R 上移 +8.9 dB（C3mX）与 +15.7 dB（C1mX），坡地族各配置分值也移动。仅能确认本次 top-1 与可行性稳定，不能确认排序标签不变。既往 52.4 dB 等读数不可与修正后表示混用。证据：[B2 重算 r1](../../artifacts/research_checks/2026-10-02_b2_reward_carrierfix_v0_2_r1.json)。

## 4. 未被本错误影响的资产

同一加载路径下包络数组和 501 点复频响不受载频修正影响；identity 的 Nb=1 等代数性质仍成立。本次 B2 四族的 top-1 和可行性未变。带符号波形的完整排序、比值、到时和绝对分值均应按表示版本核对，不能普遍宣称不变。旧增益阶梯、增益效果、全尺度/截幅及 v0.6 增广仍使用旧加载器，尚未由本轮三组复算验证；保留历史脚本，并在正式使用前新建开发侧证据，尤其不能用全局缩放抵消论证截幅判定不变。

## 5. 遗留与下一步

1. **官方表示的刻度与敏感性复核**：2 样本仍全部拒绝，仅裕量缩小；不预设必须升级 τ_D。若任务依据支持改动，再按新版本冻结。
2. **S1/S3 契约 t_measured 登记列 v0.2 更新**（窗口几何锚不变，仅更新诊断列）。
3. **3D 标杆 SFCW 产品图重出**：`plot_sfcw_bscan.py` 的 FFT 带通诊断图（90 格/1.666 MHz 间隔）应替换为官方 501 点链（`sfcw_official_loader_v0_2.trace_time_response` 直接可用于归档 t07 等 13 道），源半采样时偏由官方 `load_source` 自动保留。
4. v0.6 增广、完整背景排序及增益/全尺度/截幅链按新版表示重出开发侧证据，不能沿用未核验的旧排序标签。

复跑入口保持上述三个脚本名，验收加强后的输出使用 `carrierfix_v0_3_{r1,r2}.json`，拒绝覆盖既有文件。t3/B2 要求独立预先建立的 `--input-manifest`；S1/S3 使用冻结契约的逐道哈希及恢复目录。旧表示与归档失配、官方源码版本变化、输入身份不符或峰窗/NC 条件不满足均停止输出。旧 v0.2 六份 JSON 保持原字节；本机缺完整原始 H5，未生成完整 v0.3 科学结果，当前验证是归档验收与反例测试，见新增修复记录。
